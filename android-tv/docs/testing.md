# 测试与验收

本页用于验证代码、复现界面或播放问题。先按 [README](../README.md#从源码构建测试与安装)准备环境；运行演示时再连接设备并安装客户端。

> **命令约定：** 以下命令在 `android-tv/` 执行；Windows 将 `python3` 换成 `py -3`。

[自动检查与演示](#自动检查与隔离演示) · [真实后端验证](#需要验证真实后端时) · [观看模式](#验证儿童与隐私模式) · [真机检查](#验收边界与真机检查)

## 自动检查与隔离演示

### Step 1：运行自动检查

```sh
python3 tools/tv.py check
```

无需电视或服务器，覆盖工具测试、文档链接、Android JVM 单元测试、Lint 和两种 APK 构建。

**预期结果：** 终端显示“检查通过”。报告位置见 [README](../README.md#step-2一条命令完成测试和构建)。

局部修改可缩小检查范围：

| 修改范围 | 命令 |
| --- | --- |
| 仅文档 | `python3 ../scripts/check_docs_links.py --root android-tv` |
| 仅 Python 工具 | `python3 -m unittest discover -s tools -p 'test_*.py'` |

修改跨端协议时，另在仓库根运行关联后端或网页回归；普通 Android 界面修改不要求重跑整个服务器测试集。自动检查不操作遥控器，也不验证真实设备解码。

### Step 2：运行隔离演示

准备一台已连接且安装了客户端的电视或 TV 模拟器，以及本机已有的 FFmpeg。FFmpeg 需支持 `libx264` 和 AAC 编码；脚本从 PATH 或本仓库已下载的 `static_ffmpeg` 查找，也可用 `--ffmpeg /实际路径/ffmpeg` 指定，不自动下载。

```sh
python3 tools/tv.py demo
```

脚本自动选择唯一在线设备、设置 ADB 反向转发，并生成彩条、测试音和模拟海报。多个设备时加 `--serial 实际序列号`。

**预期结果：** 终端打印 `url` 和 `fixtures`。在电视连接页输入 `http://127.0.0.1:18888`，令牌留空，应能浏览并播放合成影片。

保持此终端运行。完成后先退出电视播放，再按 **Ctrl+C**；脚本撤销本次转发，演示服务删除临时媒体。若要保留请求记录，退出前复制打印的 `fixtures` 目录中的 `requests.jsonl` 到仓库 `output/android-tv/`。强制结束进程可能跳过清理。

同一端口一次只运行一个演示；已有端口映射时脚本会拒绝覆盖，可加 `--port 18890`，电视地址同步改成 `http://127.0.0.1:18890`。演示地址只在转发存续时有效，不是实际服务器地址。

### Step 3：选择需要复验的场景

停止当前演示后，以需要的选项重启；每次重启都会重置模拟进度。参数可组合：

| 参数 | 检查场景 |
| --- | --- |
| `--hls` | 完整 fMP4 HLS 的起播、续播、跳转与文本字幕 |
| `--require-token` | 空值、错误值和正确令牌的连接提示 |
| `--browse-stress` | 120 项选集的跨页、合并集、多版本和离线状态 |
| `--season-stress` | 多季、长季名和季图失败后的整剧海报回退 |
| `--no-show-poster` | 配合上一项，检查整剧也缺图时的文字占位 |
| `--card-stress` | 同片多库、长标题／库名和无评分卡片 |

例如：

```sh
python3 tools/tv.py demo --hls --require-token
```

认证模式使用固定演示令牌 `demo-tv-token`；先试空值／错误值，再试正确值。只读握手可访问，写请求须通过认证。

搜索复验可输入片名 `SQ`、演员 `ZXH`，应出现合成候选。进入详情再返回，检查输入与条目焦点保留；选集同样检查跨页后返回原集。

界面复验至少完成：连接 → 浏览／搜索 → 详情 → 播放 → 暂停／跳转 → 返回原条目 → Home 退出。播放时从按钮行按上键聚焦进度条，分别短按左右键确认每次 10 秒、按住确认逐步加速，再切换 1 分钟和 5 分钟步长，以短按检查远距离定位；再试确定跳转、返回取消及 10 秒按钮。已有预览缓存时核对目标时间与缩略图对应；没有缓存时在播放设置显式生成，检查未完成页不显示旧图片，旧服务端缺少预览接口时仍能跳转。应用数据占用达到 20 GB 时，电视浏览页应出现网页维护提示；旧服务端无占用接口时应正常浏览。检查图片和焦点，不只看文字是否出现。

## 需要验证真实后端时

上述演示的播放决策由参数固定，无法证明真实转码、能力判断或多设备会话正确。修改相关行为时，改用 [backend_fixture.py](../tools/backend_fixture.py)：它运行实际 FastAPI、SQLite、探测与转码代码，数据和配置隔离到临时目录。

### Step 1：启动临时后端

此路径供已有后端开发环境的开发者使用，在 Linux／WSL 下执行；先按[开发指南](../../docs/developer/development.md)安装仓库 Python 依赖，并准备 FFmpeg／FFprobe。仍在 `android-tv/` 运行：

```sh
../.venv/bin/python tools/backend_fixture.py --port 18889
```

**预期结果：** 终端打印 `base_url`、`root` 和两部合成影片。若找不到二进制，可加 `--ffmpeg /实际路径/ffmpeg --ffprobe /实际路径/ffprobe`；不会自动下载。

### Step 2：转发端口并播放

另开终端，用 SDK 的 `platform-tools/adb` 执行以下命令；若已加入 PATH 可直接用 `adb`。`SERIAL` 换成 `python3 tools/tv.py devices` 列出的序列号：

```sh
adb -s SERIAL reverse tcp:18889 tcp:18889
```

电视连接 `http://127.0.0.1:18889`，令牌留空。依次播放“直接播放”和“HLS 双音轨字幕”，检查首帧、时间推进、切音轨、字幕，以及按 Home 后会话释放。后者使用双 MP2 音轨，预期由真实后端生成双 AAC rendition。

### Step 3：停止与留证

在后端终端按 **Ctrl+C**，等待正常关闭及 FFmpeg 回收，再撤销转发：

```sh
adb -s SERIAL reverse --remove tcp:18889
```

`root` 下的 `fixture-info.json`、`requests.jsonl` 和 `playback-responses.jsonl` 用于核对片源、请求和时间轴；临时目录保留供复查，确认不再需要后可删除。此夹具不继承真实令牌、TMDB、AI 或 NAS 配置。

## 验证儿童与隐私模式

使用上面的[临时真实后端](#需要验证真实后端时)和两部合成影片；普通模拟演示不提供保护接口。全程只操作临时库，使用一次性测试密码，证据中不记录密码或会话凭据。验收状态与后续回归依据统一见[开发计划](../../docs/roadmap/android-tv.md#儿童与隐私模式真机验收已通过)。

### Step 1：准备可区分的内容

1. 在“电视设置 → 观看模式”设置保护密码。此时隐私模式应为空，进入后返回普通模式；儿童模式应隐藏资料不足的合成影片，退出儿童模式需输入密码。
2. 在普通模式打开“直接播放”的“更多操作 → 内容保护”，选择“允许儿童观看”并保存。
3. 对“HLS 双音轨字幕”同时选择“隐私模式：已加入”和“允许儿童观看”，保存后检查：普通模式只剩“直接播放”，儿童模式也只展示“直接播放”，隐私模式只展示“HLS 双音轨字幕”。返回普通模式后仍可从详情添加内容，移出隐私后该影片应重新出现在普通模式。

分别检查列表、搜索、详情和播放入口；不能只确认模式按钮文字变化。保留一部隐私影片用于后续步骤。

### Step 2：检查遥控器与恢复

用方向、确定、返回键完成密码设置、错误密码重试、取消、模式切换和内容保护修改。检查输入法打开／收起、密码遮挡、初始焦点和返回焦点，避免必须使用触摸或鼠标；错误密码不能进入隐私或退出儿童模式。

在隐私详情和播放页分别按 Home、待机、退出应用，再重新打开；也检查应用进入后台后被系统回收的恢复路径。应停止本机声音、遮挡内容，重新进入隐私需验证密码；儿童模式在相同恢复路径中保持。提交密码时立即按 Home，晚到的响应不能重新展示隐私内容。断网后按 Home 再返回，应保持遮挡，恢复连接并重试后才能继续；不要通过清除应用数据代替进程恢复测试。

### Step 3：检查超时、缓存与多设备

1. 在隐私模式停留 15 分钟不操作，确认自动锁定。另一次从头播放合成影片，设为 0.5 倍速后至少 16 分钟不操作，确认播放仍继续；返回详情修改内容保护时应重新验证密码。默认合成影片长 11 分钟，半速可覆盖此检查。重新进入隐私并播放、暂停，停留 15 分钟，应锁定并停止播放。
2. 在不同模式搜索不同词并打开详情，隐私模式加载海报后锁定。检查搜索历史、返回栈、首页海报和系统任务预览均不显示刚才的隐私内容；普通与儿童历史各自保留。把普通模式搜索过的影片加入隐私后，旧历史应被清除；在另一设备修改标记后，本机刷新或重连也不得恢复旧内容。最近演员历史需另用带虚构演员资料的合成影片检查，默认两部夹具不含演员。
3. 第二台电视或模拟器通过各自的 ADB 转发连接同一临时后端，分别进入隐私模式并播放同一部合成 HLS 影片。在其中一台退出隐私、按 Home 或结束播放，另一台应继续播放，进度与字幕操作保持可用。重新授权后修改共用保护密码，确认两台的旧授权均失效、旧密码不能再次进入，新密码可用；仅一台切换儿童模式时另一台的模式不变。

### Step 4：检查旧服务端能力兼容

退出儿童和隐私模式后，改连前述[隔离演示](#step-2运行隔离演示)。其握手未声明 `viewing_modes`，应隐藏顶部及设置中的模式入口，仍可完成浏览、搜索、详情和播放；不能不断请求不存在的保护接口或停留在锁定提示。此检查只验证缺少能力声明的路径，具体旧服务端发行版的兼容性仍需用相应版本的隔离实例复验。

遇到失败时记录操作前后的模式、是否正在播放、网络状态、设备/API、版本和已脱敏日志，按[停止与留证](#step-3停止与留证)回收临时服务；修复后重做对应步骤。

## 排查播放卡顿

使用 Debug 包时，先记录 APK 版本、设备/API、画质及字幕设置，在卡顿发生时通过 SDK 的 `adb` 读取日志：

```sh
adb -s SERIAL logcat -v threadtime 'JzPlayback:D' '*:S'
```

`SERIAL` 换成目标设备序列号。日志记录播放状态、`bufferedMs`（本地剩余媒体缓存毫秒数）、解码器名称、`audioUnderrun`（音频输出欠载）与累计批次掉帧；每 5 秒的 `sample` 还记录是否正在播放、片内位置以及视频输出／掉帧计数。正常 1 倍速播放时，片内位置的增量应接近两次日志的时间差，不能只看转圈是否消失。不记录服务器地址、令牌或字幕正文，Release 包不启用这些诊断事件。

缓存接近零时检查分片请求和服务器供片；缓存已有数十秒却仍反复 `buffering`，应检查音频输出欠载、解码与渲染调度，不能只增加网络缓存。用同片同画质关闭字幕作对照，并分别验证退出重播、续播和跳转。模拟器结果不能代替实体电视验收。

### 验证 Dolby Vision P5 原生播放

在支持 P5 的电视使用自动或原画画质、关闭字幕或选择文本／ASS 字幕。核对界面显示“原视频”，Debug 日志的 `videoFormat` 为 `mime=video/dolby-vision`、`codecs=dvhe.05.xx` 或 `dvh1.05.xx`，并结合 `videoDecoder` 确认实际使用硬件杜比解码器。服务器应直接读取源文件，或只重封装／转换音频，不应启动视频转色、缩放或重编码。仅凭电视弹出杜比标识、能力检测通过或配置解析单测，不能代替这几项核对。

实际画面确认无系统性偏色，连续播放及多次 seek 后检查声音、字幕与进度。另在隔离夹具中验证不支持杜比的设备、缺少杜比封装信息、实际轨道超出解码能力、强制降画质和图片字幕烧录均有明确失败提示；新版 APK 连接返回普通视频转码计划的旧服务端时，不能创建该会话。普通 SDR、HDR10、HLG 和已有 P7 判定按原场景回归。P5 专项真机状态见[开发计划](../../docs/roadmap/android-tv.md)。

## 验收边界与真机检查

### 各类证据的边界

| 证据 | 能说明什么 | 仍不能说明什么 |
| --- | --- | --- |
| 单测／Lint／构建 | 测试覆盖的逻辑、静态问题、可生成 APK | 实际遥控器和播放体验 |
| 模拟 API + 合成媒体 | 客户端界面与协议接线 | 真实后端的转码决策和资源管理 |
| 临时真实后端 + 合成媒体 | 服务端到客户端的实际播放链路 | 真实片源全集和家庭网络表现 |
| TV 模拟器 | 指定系统镜像上的行为 | 实体电视硬件解码、HDR、扬声器和输入法 |

### 真机检查清单

每台真机记录型号、Android/API、APK 与服务器版本，再检查：

1. 安装和桌面入口；连接页地址／令牌输入；全程方向／确定／返回操作和焦点恢复。搜索检查首字母、全拼、英文、数字、清空／退格及右侧翻页，中文片名用拼音查找。
2. 原文件与 HLS、MP4/MKV、H.264/HEVC、多音轨、文本／ASS/SSA／图片字幕；4K/HDR 单独记录。
3. 网页与电视互相续播、跳转、字幕同步、真正结束后连播。
4. 两台设备同片播放，分别切档／跳转／退出互不打断；满额提示可返回。
5. Home、待机、断网重试和退出无残留声音；同签名升级后配置保留。

ASS/SSA 渲染变更需另用包含字体附件、中文和复杂排版的片源核对：字体与字号、描边和颜色、顶部或标牌位置、多行和动画；默认字号应保留原字幕设置。分别在原文件、从非零位置开始的 HLS、续播和跳转后检查同步，再检查延迟调整、切轨、关闭字幕以及控件显示不移动原字幕。不同视频宽高比要检查实际画面区内的定位。

用隔离服务器模拟 ASS／字体读取或渲染失败，确认仅当前轨道回退为 WebVTT 且有提示，随后切到其他 ASS 轨道仍可尝试渲染。新版 APK 连接旧服务端返回 WebVTT、旧 APK 连接新版服务端仅声明 WebVTT 的兼容路径也应覆盖。普通 `demo --hls` 的文本字幕不能代替这项验证；构建、单测和模拟器结果也不能代替红米电视上《未麻的部屋》等实际片源的渲染验收。

结果写在提交／PR 或发布说明，记录场景、环境、通过／失败与证据位置；截图、日志放 `output/android-tv/`，不往本页追加每轮结果。当前尚未完成的事项只维护在[开发计划](../../docs/roadmap/android-tv.md)。
