# 搜索与选集参考

本页供维护搜索、演员资料和选集导航时查阅，记录交互与数据边界。使用和测试步骤见 [README](../README.md) 与[测试指南](testing.md)；颜色、尺寸和控件共用规则见[电视设计系统](design-system.md)。核对日期：2026-10-07。

## 遥控器操作

搜索左侧为固定 6×6 字母数字键盘，按 A–Z、1–9、0 排列，数字始终显示。用方向键选键、确定键输入，可按片名或姓名的首字母、全拼、英文及数字查找。键盘上方的“清空”移除整个查询，“退格”删除末尾一个字符。搜索页不提供系统中文输入入口，中文片名和演员姓名通过首字母或全拼检索。

| 操作 | 必须保持的行为 |
| --- | --- |
| 从电影/电视剧/合集页进入搜索 | 预选对应类型，范围仍为当前媒体库 |
| 修改查询或筛选 | 输入停顿 250ms 后查询，取消旧请求，结果刷新不抢键盘焦点 |
| 从键盘向右 / 从候选左列向左 | 进入候选 / 回最近键位 |
| 从详情返回 | 恢复搜索词、页码和原候选焦点 |
| 切换“片名 / 演员” | 共用键盘；类型筛选仅出现在片名结果或演员作品区 |
| 选中演员 | 进入独立作品页；详情返回原作品，再返回原演员候选 |

无输入、读取中、无结果和错误分别显示。片名空输入显示本机历史；演员空输入显示本库演员。查询、输入提示和清空/退格固定在键盘上方，键盘区域可滚动，大字号时末行按键也必须可达。

候选位于右侧，类型筛选、查询历史和最近演员以分隔线区分。候选超出可视范围时右缘显示滚动条，滚动条仅提示位置，不参与焦点导航。查询成功后，“上一页”“下一页”与页码位于候选区底部；不可用的翻页按钮置灰。空的后续页仍保留上一页入口。离开搜索和详情使用遥控器返回键。

## 服务端与兼容

接口均只读，不联网补资料、不扫描媒体。通过握手的 `features` 判断能力；缺少 `tv_search` 或 `tv_actor_search` 时只限制相应功能，不影响浏览和播放。

### 片名搜索

`GET /api/tv-client/search`

- 能力：`tv_search`。
- 专用参数：`q`、`kind=all/movie/show/collection`。
- 返回：标准分页 + `query`，条目含 `kind`、`id`、`title`、`poster_path`。

### 演员搜索

`GET /api/tv-client/actors`

- 能力：`tv_actor_search`。
- 专用参数：`q`。
- 返回：标准分页，条目含 `key`、`name`、`avatar_path`、`movie_count`、`show_count`、`work_count`。

### 演员作品

`GET /api/tv-client/actor-works`

- 能力：`tv_actor_search`。
- 专用参数：`actor=<key>`、`kind=all/movie/show`。
- 返回：标准分页 + `actor`，媒体条目与片名结果一致。

### 通用参数与分页

| 参数 | 范围 |
| --- | --- |
| `media_library` | 可选媒体库 |
| `limit` | 默认 24，最大 60 |
| `offset` | 从 0 起 |
| `q` | 最长 80 字符 |
| 演员 `key` | 最长 512 字符 |

标准分页字段为 `items`、`total`、`has_more`、`limit`、`offset`。客户端透传不透明的演员 `key`，不要用姓名推算 ID；演员不存在或在当前库无作品时返回 404。

### 查询范围与匹配

搜索覆盖完整选定片库，排除禁用媒体库/视频库。电影同视频库的同片多版本合并，不跨视频库合并。片名空白或纯符号返回空；演员空白查询按作品数排序，纯符号返回空。

片名接口匹配原文、原名、首字母、全拼和数字混排，精确片名优先。拼音使用 `pypinyin` 的词组读音和 `FIRST_LETTER`，不能改用会丢失 y/w 的声母模式。遥控器检索遇到多音字或未保存的译名时，可改用更短的首字母或已保存的英文原名。

只缓存有界的文字派生值，不缓存查询结果，资料改名、删除和禁用在下次查询生效；不改网页 FTS 语义。

## 演员资料边界

“演员”只采用明确的参演记录：

- 电影 `movie_person.role=actor`。
- 与电影/剧绑定的 TMDB 缓存 `credits.cast`。
- 剧季 `cast` 与分集 `episode_credits.guests`，统一归到剧，不把每集算成一部作品。

身份优先使用 TMDB 人物 ID；无 ID 的明确参演记录使用规范姓名的 `name:` 身份。同名不同 ID、无 ID 与有 ID 的记录不猜测合并。混有导演/创作者的旧 `person_names`，以及无法稳定关联业务行的外源/NFO 缓存，不按同名补入作品。

演员搜索匹配已保存的中文名、英文名和读音，姓名首字额外使用有界的多读音候选，不能修改片名拼音词典。候选、作品数和作品列表使用同一媒体库范围。头像只取本地缓存，缺图保留姓名；查询不下载头像或写数据库。

## 选季、选集与返回

### 季卡与海报

季卡使用 `MediaCard`，展示季号/特别篇、独特季名和观看统计。按可用宽度分列，少量季不拉伸占满整行；卡片标题按内容自然增高，几何统一见[控件尺寸](design-system.md#控件尺寸)。

季海报依次尝试 `seasons[].poster_path`、整剧海报、季号文字占位。空路径、HTTP 失败、解码失败都可回退；请求取消不能触发回退，切换来源不能残留上一张图。`SharedImageLoads` 合并在途请求，最后一个使用者离开时取消，最多并发解码四张图片。

### 分集与返回

选集每页最多 50 条，保留版本筛选、合并集范围和已看 / 续播 / 离线标记。焦点所在集的完整名称与状态固定显示在网格上方。

确定进入分集详情，返回恢复原集和列表位置；目标已消失时回退到可用入口。没有前后页时不生成空分页栏。

### 加载与刷新

首页分区独立加载和重试；浏览翻页、筛选或排序后聚焦首项。搜索或演员作品后续页变空时，仍保留上一页入口。剧/季详情的“重新读取资料”只刷新已有信息，不执行扫描、刮削或整理。

## 本机历史

明确选中结果时才记录查询，不逐字保存输入前缀。片名和演员查询各最多 12 条；最近演员按 `key` 去重，也最多 12 条。数据仅保存在电视本机，按规范服务器地址与媒体库隔离，可分别清除，不存访问令牌。
