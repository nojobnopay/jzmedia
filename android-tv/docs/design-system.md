# 跨端图标与电视控件

核对日期：2026-10-04；当前界面版本 `0.5.2`。电视端保留原生 Compose for TV 的遥控器焦点与几何；图标、品牌和主题颜色由仓库根目录 `design/` 管理。普通 APK 构建直接消费已提交生成物，不运行 Python、Node 或联网取图。

## 使用与维护

- 新图标先登记 `design/assets.json` 和使用需求，再修改 SVG 母版、运行 `scripts/build_design.py`。不得在 Kotlin 中手写路径或用字体字符替代图标。
- `TvIcon(name)` 读取生成的 `DesignIcons`，标准视框 24×24、线宽 1.7、圆端点与连接；默认显示 24dp。相邻文字拥有可访问名称，装饰图标不重复播报。`loading` 采用系统 Compose 动画机制，跟随系统动画时长设置。
- `TvNavIcon` 仅委托同源图标；保留 movies/shows/libraries 等旧别名。`forward` 表示导航向前，`forward10` 表示快进 10 秒，不能混用。
- `TvAction` 保留原参数，末尾新增可选 `icon: String?`。普通保存、取消、选择项可只显示文字；播放、导航、搜索、筛选、刷新、设置等操作使用图标加文字。
- 所有原生 `Button` 使用 `tvButtonColors`、`tvButtonShape` 和 `tvButtonScale`。`tvSelected` 同时提供选中语义和红色短线，白底深字的遥控器焦点仍能辨认已选项；移动焦点不会执行操作。
- 颜色和尺寸来自生成的 `DesignTokens`。不要复制十六进制色值到控件；视频黑底、字幕白字和字幕阴影属于内容渲染，可继续独立定义。
- [TvTypography.kt](../app/src/main/java/org/jzmedia/tv/ui/TvTypography.kt) 统一系统无衬线字体及字号层级，跟随系统字体缩放。页面标题为 26/34sp（字号/行高）、章节为 20/28sp、卡片标题为 15/20sp、卡片元信息为 12/16sp，正文为 16/24sp；不要靠空白文本或固定文字区高度对齐卡片。
- 导航字标、启动图标和 320×180 横幅由根目录 `scripts/build_design.py --render-brand` 从 `design/brand/` 母版生成；导出路径、尺寸和密度见 `design/exports.json`，普通 APK 构建直接消费 `app/src/main/res/` 中已提交产物。生成环境与维护步骤见[设计资产说明](../../design/README.md)。

## 使用需求与专用几何

| 控件类别 | 用途与图标 | 电视尺寸 | 状态与名称归属 |
| --- | --- | --- | --- |
| 顶部导航 | 搜索、首页、电影、剧、合集、媒体库、设置 | 24dp 图标、40dp 控件高；长库名单行省略 | 标签拥有名称；当前频道红线、白底焦点独立 |
| 普通操作与播放器 | `TvAction` 可选 24dp 图标 | 最小 40dp；文字可两行，图文间隔 8dp | 原业务禁用条件保留；播放/暂停明确切换图标 |
| 媒体、季卡 | 海报、进度、标题；缺图用 image | 卡片目标宽 150dp（网格按列宽分配），内边距 8dp；海报按页面设置高度 | 10dp 卡片圆角；图文间隔 8dp、标题与元信息间隔 4dp；文字区按实际内容自然增长，聚焦放大 1.05 |
| 演员卡 | person 缺图标与姓名/作品数 | 最小高 76dp、头像 44×56dp；文字需求可增高 | 姓名在头像旁显示；作品数使用随焦点变化的次级文字色；装饰占位不另加姓名 |
| 集号 | 集数、合并集、继续观看等文字 | 最小 56dp 高，自适应列宽 | 继续观看与焦点独立；完整描述由按钮提供 |
| 屏幕键盘 | 字母和数字；删除、清空、中文输入 | 最小高取 28dp 与实际字体行高加 8dp 的较大值，上限取 44dp 与该最小值的较大值 | 纯文字原生控件；保留方向键跨行和右移候选 |
| 搜索历史 | 查询词、最近演员、清除 | 最小高 32/36dp，大字号随文字增高 | 纯文字；保留省略、横向滚动、原焦点恢复 |
| 状态与缺图 | loading/error/info/image/person | 24dp 图标 | 请求未完成不显示为空；错误保留重试入口 |

以上单位均为 Android dp，系统字体使用 sp。1080p/4K 是验收显示环境，不能简单按显示分辨率复制矢量资产；实际像素尺寸取决于设备密度。屏幕键盘和紧凑历史属于遥控器专用控件，不用于手机触摸界面。

媒体卡片的年份、剩余时间紧跟标题，标题最多两行，整卡在实际文字后结束；不保留 60dp 固定文字区，缺少年份或进度时不生成空元信息行。海报底部显示所属媒体库（不是视频库），长库名最多两行；右上角显示有效评分和来源，依次优先 TMDB、豆瓣、自评，缺少有效评分时隐藏。覆盖首页、浏览、搜索和作品卡片，进度条仍在海报最底部。旧服务器缺少媒体库名称但返回 ID 时显示“媒体库 #ID”，不会把视频库名称冒充媒体库；需要服务端更新后显示完整名称。

页面左右留白 40dp、上下 20dp，导航与页面间隔 16dp。首页与通用媒体横栏的卡片间隔为 16dp，滚动内容边距 8dp，标题与横栏间隔 4dp；季卡行使用 8dp 内边距，卡片同样按文字自然增高。焦点缩放需要的滚动边距保留，不能用裁剪焦点来缩短页面。

详情页的返回入口位于标题行右侧，加载和失败状态也保留返回；标题和元信息最多两行，海报为 72×108dp，操作横栏内边距 8dp。简介最多三行、宽度最多 720dp，仍可打开完整内容；演员摘要最多两行。返回焦点沿用 `back`，选季选集、分页和固定上下文的焦点恢复不变。少量分集没有前后页时不生成空分页栏，简介紧接选集区；两行分集说明和结束固定上下文的边界仍保留。设置页按“服务器连接”和“设备与版本”分组，操作保持原有语义。

搜索页使用简短的输入提示；当前查询和说明固定在键盘上方，字母键与底部操作独立滚动，避免大字号时正在输入的内容离开视口。候选海报高为 100–180dp，根据可用高度扣除实际字体缩放下的两行标题、一行元信息、卡片间距及网格焦点空间。播放器设置的标题和返回入口同行，选项占满侧栏宽度，字幕字号和延迟单独分组；播放标题与输出信息单行省略，进度时间保留独立空间。

筛选、完整简介和选择对话框分别按窗口实际高度的 88%/88%/86% 限高，容器内边距 24dp；筛选与选择列表保留 8dp 焦点空间，底部操作始终可达；不以固定大高度挤出低分辨率或大字号电视的操作区。播放器设置滚动区上下保留 4dp，避免首行返回按钮聚焦放大时被裁切。

## 验证

执行 README 的 JVM 单测、Lint、Debug 与未签名 Release 构建。`DesignIconsTest` 覆盖跨端别名和导航/快进语义隔离。使用 `tools/smoke_server.py` 的合成资料验证方向/确定/返回、详情返回焦点、选中状态、长库名、1.3 倍字号及缺图。

截图、模拟请求轨迹和构建日志保存到 `output/android-tv/` 的对应验证目录，不提交 Git。复验至少覆盖首页、浏览、搜索、详情、选季选集、设置和播放器，检查 1.0/1.3 倍字体、长标题和长库名、缺失元信息、同片多库卡片以及方向/确定/返回焦点。模拟器通过仅证明已检查布局与遥控器接线，红米真机远距离辨识、实际遥控器、扬声器、HDR 和系统中文输入法仍须单独验收。
