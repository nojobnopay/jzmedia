# 电视设计系统

本页供维护原生电视界面时查阅，记录设计来源、遥控器焦点与布局约束。测试步骤见[测试指南](testing.md)，待验收项见[开发计划](../../docs/roadmap/android-tv.md)。核对日期：2026-10-07。

## 设计来源

| 内容 | 唯一来源与用法 |
| --- | --- |
| 图标、品牌、颜色与通用尺寸 | 仓库根目录 [design/](../../design/README.md)；修改母版后生成，不直接改 Kotlin 生成物 |
| 图标组件 | `TvIcon(name)` 使用生成的 `DesignIcons`；`TvNavIcon` 保留旧语义别名 |
| 字体层级 | [TvTypography.kt](../app/src/main/java/org/jzmedia/tv/ui/TvTypography.kt)，系统无衬线字体，跟随字体缩放 |
| 普通操作 | `TvAction`；原生 `Button` 共用 `tvButtonColors/tvButtonShape/tvButtonScale` |

### 图标与品牌

新增图标先登记 `design/assets.json` 和用途，再修改 SVG 母版、运行 `scripts/build_design.py`。不得在 Kotlin 中手写第二份图标路径或用字体字符代替图标。`forward` 为导航向前，`forward10` 为快进 10 秒，不能混用。

普通保存、取消、选择项可只显示文字；播放、导航、搜索、筛选、刷新和设置用图标加文字。名称由相邻文字提供，装饰图标不重复播报。加载图标跟随系统动画时长设置。

导航字标、启动图标与横幅由 `scripts/build_design.py --render-brand` 生成，导出规格见 [exports.json](../../design/exports.json)。普通 APK 构建使用已提交产物，不运行设计生成工具。

颜色和通用尺寸使用 `DesignTokens`；视频黑底、字幕白字和阴影属于内容渲染，可独立定义。

## 焦点与信息层级

- 当前频道/选中项显示红色标记，遥控器焦点显示白底深字，两者独立。移动焦点不执行操作。
- 页面与详情返回恢复原条目及滚动位置；目标消失时退到可用入口，不留下不可达焦点。
- 卡片聚焦放大 1.05 倍，滚动容器保留放大空间，不能靠裁切焦点压缩布局。
- 文字随系统字号增长；标题最多两行，元信息缺失时不留空行，不用空白文本或固定文字区高度对齐卡片。
- 缺图仍保留标题/姓名；读取中、空内容和错误分开，错误保留重试，遥控器返回键仍可用。
- 浏览、搜索和详情使用遥控器返回键退出，不显示单独的页面返回按钮；对话框由返回键关闭。播放错误和播放器设置仍保留各自的返回操作。

### 字体层级

字体使用统一规格，不要为某页另建同义字号。

| 用途 | 字号 / 行高（sp） |
| --- | --- |
| 页面标题 | 26 / 34 |
| 章节 | 20 / 28 |
| 正文 | 16 / 24 |
| 卡片标题 | 15 / 20 |
| 卡片元信息 | 12 / 16 |

## 控件尺寸

布局尺寸用 Android dp，字体用 sp；实际像素由设备密度决定，不能按 1080p/4K 分辨率直接换算控件规格。

| 控件 | 尺寸（dp） |
| --- | --- |
| 顶部导航 | 图标 24，控件高 40 |
| 普通操作 / 播放器按钮 | 最小高 40，图文间隔 8 |
| 媒体 / 季卡 | 目标宽 150，内边距 8，圆角 10，海报默认高 180 |
| 演员卡 | 最小高 76，头像 44×56 |
| 集号按钮 | 宽 88–100，最小高 56，列间隔 12 |
| 屏幕键盘 | 最小高为 `max(28dp, 字体行高 + 8dp)`，空间足够时增至 44 |
| 搜索历史 | 清除最小高 32，历史项最小高 36 |

### 内容与状态

- **顶部导航**：长媒体库名单行省略，当前频道与焦点独立。
- **操作按钮**：文字可两行，播放 / 暂停图标随状态切换。
- **媒体 / 季卡**：图文间隔 8dp，标题与元信息间隔 4dp；整卡按文字自然增高，搜索海报按空间调整。
- **演员卡**：姓名、作品数在头像旁，随字号增高。
- **集号按钮**：集号与状态整体居中，合并集、续播与焦点各自可辨。
- **屏幕键盘**：大字号时仍满足最小高，允许滚动，保留跨行 / 候选导航。
- **搜索历史**：大字号自然增高，保留省略与横向滚动。

屏幕键盘与紧凑历史是遥控器专用控件，不能把尺寸直接用于手机触摸界面。

## 页面布局约束

### 通用间距

| 页面 / 区域 | 间距 |
| --- | --- |
| 页面外框 | 左右 40dp、上下 20dp，导航与内容间隔 16dp |
| 媒体横栏 | 卡片间隔 16dp，滚动内容边距 8dp，标题与横栏间隔 4dp |

### 详情与选集

- **详情顶部**：海报默认 168×252dp；内容区宽度小于 700dp 时为 120×180dp，保持 2:3。电影/剧/季/集顶部有横图背景（缺图时不占位，合集无背景），取图偏上，左侧压暗放海报、底部下沉接底色（与网页同口径）；内容四周留边，背景高于海报、低于简介按钮；操作栏内边距 8dp；加载 / 失败时遥控器返回键仍可用。
- **详情简介**：最多三行、最大宽 720dp，可打开全文（整段一块展示，不切片）；演职员为单行横滚卡片（卡片贴内容 88dp、圆形头像+名字，英文原语言才显示角色名，占满整列、与“库中相关推荐”同宽），点卡进演员独立作品页（头像+简介+作品；无简介时简介区隐藏）。
- **选季 / 选集**：季行留 8dp 内边距；分集完整说明滚动时保持可见；无分页则不留空栏。

媒体卡海报底部显示所属**媒体库**，最多两行；不能用视频库名称替代。旧服务器仅返回 ID 时显示“媒体库 #ID”。右上角评分依次优先 TMDB、豆瓣、自评，没有有效值则隐藏；进度位于海报最底部。

已看状态使用与网页一致的绿色 `#7ED321` 和“已看”文字，显示在媒体/季卡海报、详情和继续观看条目中；分集按钮以绿色状态文字标记。剧/季仅在有本地分集且已看数达到本地分集总数时显示已看，不以官方目录完整度判定。

季海报的失败回退、选集分页与导航行为统一见[搜索与选集参考](search-design.md#选季选集与返回)。

### 搜索、设置与播放器

- **搜索**：查询、提示和清空/退格固定于键盘上方，6×6 字母数字键盘可滚动；候选区右缘显示滚动位置，翻页固定在候选区底部。候选海报高 100–180dp，计算时预留实际字号的标题、元信息与焦点空间。
- **设置**：按“服务器连接”“设备与版本”分组。
- **播放器**：设置标题与返回同行，选项占满侧栏，字幕字号 / 延迟分组；播放标题 / 输出信息省略时保留独立时间区域。

### 对话框

筛选 / 完整简介最多窗口高的 88%，选择最多 86%，内边距 24dp。列表保留 8dp 焦点空间，底部操作可达。

## 修改后的核对范围

执行[测试指南](testing.md)中的自动检查，再以合成资料检查首页、浏览、搜索、详情、选季选集、设置与播放器。至少覆盖：

- 1.0/1.3 倍字体、长标题/长媒体库名、缺图/缺元信息、同片多库。
- 方向/确定/返回、原条目焦点恢复、选中与聚焦并存。
- 第一/最后一行焦点不裁切，低高度下对话框底部与键盘操作可达。

长期设计证据保存在[设计验收清单](../../design/acceptance/2026-10-03.json)，只证明记录中的版本和场景。临时截图、请求轨迹、构建日志放 `output/android-tv/`，测试数量和单次修复经过写入提交/PR，不追加到本页。模拟器布局证据不能代替物理电视的远距离辨识、遥控器、连接页输入、扬声器或 HDR 验收。
