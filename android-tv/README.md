# jzmedia Android TV

在电视上连接 jzmedia，浏览电影、剧集和合集，用遥控器搜索、播放和续看；服务端提供在线能力时，还可从“在线”浏览已配置的视频源。扫描、匹配、整理与来源配置仍在网页端操作。

准备一台可安装 APK 的电视和能够互访的 jzmedia 服务器。工程声明的最低系统为 Android 6.0（API 23，`minSdk = 23`）；这只是构建配置中的最低要求，设备安装、遥控器和播放兼容性仍需实际验证。

**本地媒体的主要播放流程与 ASS/SSA 原生渲染已通过红米电视真机验证。** 在线点播单独验收；具体设备、专项验收记录及升级限制见[当前状态](../docs/roadmap/android-tv.md)。

## 已有 APK：安装并连接

### Step 1：确认拿到可安装的包

从 [GitHub Releases](https://github.com/nojobnopay/jzmedia/releases) 下载可安装的 `jzmedia-tv-X.Y.Z-debug.apk`，`X.Y.Z` 是版本号。随包提供 `.apk.sha256`、`.apk.json` 和统一 `manifest.json`，记录校验值、源码及签名信息；当前默认交付 Debug 包。

维护者另行提供正式签名包时，文件名为 `jzmedia-tv-X.Y.Z.apk`；文件名含 `-unsigned` 的包不能安装。源码仓库不提交 APK；标签触发的 Actions 将交付包上传至 GitHub Releases，本机构建目录为 `output/releases/vX.Y.Z/`。

### Step 2：在电视安装

将 APK 复制到 U 盘，用电视支持的文件管理器打开，按系统提示允许该来源安装，然后选择“安装”。各品牌入口不同。

也可用电脑安装：按[环境准备](#step-1准备环境首次一次)安装 Python、SDK Platform-Tools 并[连接设备](#step-3连接电视或模拟器)后，在 `android-tv/` 执行：

```sh
python3 tools/tv.py install --apk /实际路径/文件.apk
```

将路径换成拿到的 APK，含空格时加引号。此命令安装指定包，无需 JDK 或构建；完成后在电视应用列表手动打开。

安装后应能在电视应用列表找到 jzmedia。覆盖升级须使用同一签名；遇到“签名不一致”先向包提供者索取同签名包，卸载会丢失本机连接配置。具体规则见[打包与升级](docs/releasing.md)。

### Step 3：填写服务器地址

1. 打开应用，选择“扫描局域网”，从弹出的服务器列表中选择一台并确认连接（名称 · 版本 · 地址）；附近没有或扫描无结果时手动输入完整地址，例如 `http://192.168.1.10:8080`，将示例 IP 换成你的 jzmedia 服务器局域网 IP。
2. 服务器设置了访问令牌时填写同一令牌，否则留空。
3. 选择检查连接，成功后保存。服务器换了 IP 后再次扫描，会提示更新已保存的地址。

**预期结果：** 进入媒体首页。

电视和服务器需能互访；普通连接不要填写 `localhost` 或 `127.0.0.1`，它们指电视自身。提示协议不兼容时先更新服务器；没有服务器、只想体验界面，可按[隔离演示](docs/testing.md#step-2运行隔离演示)操作。

## 遥控播放与搜索

方向键移动焦点，确定键激活，返回键逐层退出。控件含音轨、字幕、倍速和下一集；按 Home 或退出播放会保存进度并释放本机播放资源。

调出播放控件后，从按钮行按上键选中进度条；左右短按默认每次预选 10 秒，按住会逐步加速，确定键跳转，返回键取消。需要更快地跨越长视频时，可在“播放设置 → 进度调整步长”切换为 1 分钟或 5 分钟，短按即可移动，不依赖长按。控件隐藏时，也可直接按左右键预选、确定键跳转；无跳转预选时确定可暂停／继续。

服务器会在夜间为空闲的新入库影片生成进度预览；预选时已有缩略图会显示，尚未生成时可在“播放设置”中选择“生成进度预览”，生成中已完成的部分也可使用。

文本字幕由电视显示；ASS/SSA 使用原生 libass 渲染字体、样式、位置和动画，加载或渲染失败时提示并回退为兼容文本。若仍显示兼容文本，先核对 APK 与服务端均包含此能力；旧服务端可能继续返回 WebVTT。电视手动点播的图片字幕沿用服务器烧录；下述手机接收入口不会自动烧录。

手机网页投屏可选择已打开的 jzmedia-tv：电视先连接同一服务器并保持前台，手机在投屏面板选择“jzmedia-tv App”和目标电视，点击“在电视 App 播放”。App 自动打开指定电影或剧集，接续手机位置并使用所选音轨及服务器字幕。此功能从 0.31.0 起提供，服务端和 APK 均需升级并包含 `tv_app_handoff`；没有后台唤醒或另装手机 App。按 Home、退出前台、切换连接或观看模式会终止接收；关闭手机网页不影响前台 App 播放。

App 注册名优先使用系统设备名，读取不到时使用型号；每次重新注册时读取，无需新增权限。服务端还可关联已发现的同台电视 DLNA 名称，旧 APK 也可使用该服务端改进；名称识别与回退见[投屏教程](../docs/user-guide/playback-controls.md#投屏到电视)。

手机请求的图片字幕只在原文件直放且能准确映射原生字幕轨道时显示，否则关闭并提示；手机临时本地字幕不上传。电视当前观看模式也必须允许播放该内容。协议与断连、旧命令处理见[手机请求电视 App 播放](docs/protocol.md#手机请求电视-app-播放)。

找片时进入“搜索”，选择“片名”或“演员”，用左侧字母数字键盘输入首字母、全拼或英文；例如中文片名可输入其拼音首字母。清空和退格位于键盘上方，结果在右侧，翻页位于结果底部。浏览和详情通过遥控器返回键退出，返回列表时恢复原条目。具体检索范围见[搜索与选集](docs/search-design.md)。

服务器应用数据达到 20 GB 时，电视浏览页会提醒到网页“设置 → 系统维护”清理缓存。

## 在线点播

服务端在连接握手中提供 `features.online_vod` 时，包含该能力的电视客户端才显示“在线”；协议版本仍为 1，缺少能力的旧服务器不影响本地媒体播放。儿童模式不提供在线入口。先在网页[启用在线点播并配置来源](../docs/user-guide/watch-online.md#启用并播放)，优先使用免费且可直连的来源；电视不管理上游接口或代理凭据。

1. 在顶栏选择“在线”，支持目录浏览的默认来源会自动加载海报。直接选择“分类”和“细类”进行筛选；更多分类通过对应的“更多”按钮选择。父类的“综合条目”只查询来源的父分类自身，不保证包含所有细类。来源支持年份筛选时，可选最近年份，或选“其他”输入四位年份并选择“应用”。选择分类行的“全部”可回到未限定分类的目录；读取失败时选择重试。
2. 选择“键盘”，在“拼音”模式用遥控器输入全拼，再选择候选字词逐段组成片名；候选可翻页。输入英文或数字时切换“英文/数字”，也可使用电视系统输入法。未选定的拼音需先选字、保留字母或清空，才能搜索、切换模式或关闭键盘。词库离线工作，候选不一定包含完整片名。搜索由当前来源处理，不承诺本地媒体库的拼音首字母检索能力。搜索时清除目录筛选，选择分类或年份则返回目录浏览；翻页继续使用已提交的条件。需要换源时选择“来源”按钮，在弹窗中选择其他来源。旧服务器未声明目录能力时仍可搜索，开放样例可通过空关键词的“目录”按钮浏览。
3. 确认海报打开详情，选择播放线路与集号按钮。长剧集可按每组最多 50 项切换，选择“倒序”／“正序”改变显示顺序；有观看记录时可选“定位上次观看”找到该线路与集号。灰色不可播放项可聚焦查看原因；焦点说明被截断时可选择“完整名称”。详情可播放／继续、收藏及查看“完整简介”与许可信息。返回键恢复原目录、搜索结果或记录列表的条目焦点和位置。
4. 用暂停、进度预选、倍速及设备支持的音轨／字幕观看。在线原片由电视解码；不支持时返回选择其它上游线路或设备，不请求 NAS 转码、烧录字幕或生成预览。
5. 在详情“收藏”，或从“继续”“收藏”“历史”重新打开。记录归属本电视的观看身份，普通与隐私模式分别保存；不同线路与分集使用各自断点，不与本地媒体共享进度混用，也不承诺网页和电视的账户同步。

详情选择“更多”可设置“自动播放下一集”，默认关闭，偏好只影响本电视、当前观看模式。开启后仅在真实播完时刷新同源同线目录，进入紧邻下一集；下一集不支持时停止，不跳过片尾或集数。倒序仅影响选集显示，关闭、Home、待机或观看权限变化会停止本机播放并释放在线会话。

打开来源选择弹窗可查看连接状态；其中“刷新状态”只读取 API／媒体的最近实际请求结果，不向上游额外探测，状态不是电视解码或长期稳定性的保证。来源停用后，已有收藏和记录仍可取消或清除。具体能力与真机验收状态见[在线 P4 状态](../docs/roadmap/android-tv.md#在线点播-p4)。

## 观看模式

服务器支持观看模式时，顶部工具区显示当前模式。普通模式隐藏手工加入隐私的内容；儿童模式只展示服务端判定或家长确认适合儿童的非隐私内容；隐私模式只展示手工加入的内容，收藏和限制级影片不会自动加入。模式只影响当前电视，儿童模式在重新打开应用后继续保留。

第一次使用保护功能需设置 6–128 个字符的保护密码；同一密码用于进入隐私模式、退出儿童模式和修改内容可见性。进入影片或剧集详情的“更多操作 → 内容可见性”，输入密码后先选“普通模式可见”或“仅隐私模式可见”。选择普通范围后，再通过“儿童模式是否显示”选择“自动筛选”“普通和儿童模式都显示”或“只在普通模式显示”；底部“保存后”列出三种模式的结果。隐私内容在普通和儿童模式都隐藏，原有儿童决定保留，移回普通后可继续调整。电影设置适用于同一视频库内该电影的全部版本，剧集设置适用于整部剧；详细选项见[设置与维护](../docs/user-guide/settings.md#核对儿童内容)。要向隐私模式添加其他影片，先回普通模式选择影片。“电视设置 → 观看模式”可设置或修改密码。

隐私模式无操作 15 分钟后自动锁定，实际播放期间不计时，暂停后重新计时；按 Home、待机或退出应用也会锁定。重新打开应用不会恢复隐私授权。普通和儿童模式分别保存搜索历史，隐私搜索和最近演员只保留在本次会话内。密码变更会使其他设备的授权失效；服务端锁定失败时，电视先遮挡内容，联网后可重试。旧服务端仍可浏览播放，但不显示模式入口。

## 从源码构建、测试与安装

### Step 1：准备环境（首次一次）

1. **安装并打开工程。** 安装 [Android Studio](https://developer.android.com/studio) 和 [Python](https://www.python.org/downloads/)（本工具要求 Python 3.10+）。取得完整仓库后，用 Studio 的 **Open** 打开 `android-tv/`。首次同步若提示缺少 SDK，完成下一项后重新同步。

2. **安装 SDK 组件。** 打开 **Tools → SDK Manager**，按下面的清单选择组件，再点 **Apply** 完成下载和许可确认。[SDK Manager 官方说明](https://developer.android.com/studio/intro/update#sdk-manager)

   | 位置 | 安装内容 |
   | --- | --- |
   | SDK Platforms | Android API 36 |
   | SDK Tools | Android SDK Platform-Tools |
   | SDK Tools → Show Package Details | Android SDK Build-Tools 36.0.0 |
   | SDK Tools（需要模拟器时） | Android Emulator |

3. **检查环境。** 在仓库根目录打开终端，执行：

   ```sh
   cd android-tv
   python3 tools/tv.py doctor
   ```

> **命令约定：** 后续命令均在 `android-tv/` 执行。Windows PowerShell 将 `python3` 换成 `py -3`，例如 `py -3 tools/tv.py doctor`。Windows 新手建议让 Studio、Python 和 SDK 都运行在 Windows，避免与 WSL 路径混用。

`doctor` 会检查 JDK、SDK 和构建组件，缺少什么就给出修复提示。使用 JDK 17 或 21；脚本会查找常见位置的 Studio 自带 JDK。自定义安装路径时设置 `JAVA_HOME` 为 JDK 目录、`ANDROID_HOME` 为 SDK 目录，或让 Studio 生成 `local.properties`。Studio 内的 JDK 设置与终端环境可能不同，详见 [JDK 官方说明](https://developer.android.com/build/jdks)。

**预期结果：** 终端显示“环境检查通过”。FFmpeg 只在生成演示媒体时需要。

首次构建需联网下载 Gradle 和依赖，不必另装 Gradle，也不需要启动 jzmedia 后端。

### Step 2：一条命令完成测试和构建

```sh
python3 tools/tv.py check
```

脚本依次运行工具测试、文档链接检查、Android 单元测试、Lint 和 Debug／Release 构建，失败即停止。

**预期结果：** 终端显示“检查通过”，并生成以下产物：

| 产物 | 位置（相对 `android-tv/`） |
| --- | --- |
| 可安装的本地 Debug 包 | `app/build/outputs/apk/debug/app-debug.apk` |
| 单元测试报告 | `app/build/reports/tests/testDebugUnitTest/index.html` |
| Lint 报告 | `app/build/reports/lint-results-debug.html` |

没有配置正式签名时，Release 构建产出 `app-release-unsigned.apk`，仅供后续签名。向他人交付 APK 时使用[统一发布](../docs/developer/releasing.md)，签名与覆盖升级要求见[打包与升级](docs/releasing.md)。

### Step 3：连接电视或模拟器

选择下面一种方式即可。

#### 使用模拟器

1. 在 Android Studio 打开 **View → Tool Windows → Device Manager**。
2. 点击 **+ → Create Virtual Device**，选择 TV 设备及兼容电脑的 TV 系统镜像（API 23 以上）。
3. 创建完成后点击启动按钮，等待电视桌面出现。

具体入口见[模拟器官方说明](https://developer.android.com/studio/run/managing-avds)。

#### 使用实体电视

按电视厂商说明开启开发者选项和 ADB 调试，让电脑与电视处于同一局域网。若提供无线配对，先运行：

```sh
python3 tools/tv.py pair 电视IP:配对端口
```

输入电视屏幕上的配对码，然后连接；只有网络调试入口的设备可直接从这里开始：

```sh
python3 tools/tv.py connect 电视IP:调试端口
```

将中文占位换成电视实际显示的地址；配对端口与调试端口可能不同。电视弹出授权时选择允许。[ADB 官方说明](https://developer.android.com/tools/adb)

#### 确认设备已连接

两种方式最后都执行：

```sh
python3 tools/tv.py devices
```

**预期结果：** 设备右侧显示 `device`。`unauthorized` 表示尚未授权，`offline` 表示需要重新连接。

### Step 4：安装并启动

```sh
python3 tools/tv.py install
```

脚本自动构建 Debug 包、安装到唯一在线设备并启动。源码没变化时 Gradle 会复用构建结果。有多个设备时，复制上一步列出的序列号，执行 `python3 tools/tv.py install --serial 实际序列号`。

**预期结果：** 电视打开客户端；首次使用显示连接页。按上面的[填写服务器地址](#step-3填写服务器地址)完成连接。安装失败时脚本不会卸载旧应用，见下文排查。

## 日常命令与常见问题

### 日常命令

无需每次重做环境准备，按当前任务选择一个命令：

| 任务 | 命令 |
| --- | --- |
| 只构建本地 Debug APK | `python3 tools/tv.py build` |
| 只跑工具测试、文档检查、Android 单测与 Lint | `python3 tools/tv.py test` |
| 完整检查并构建两种包 | `python3 tools/tv.py check` |
| 构建、安装、启动 | `python3 tools/tv.py install` |
| 启动隔离演示并自动设置设备转发 | `python3 tools/tv.py demo` |
| 导出带版本号的本地 Debug 包 | `python3 tools/tv.py package debug` |
| 查看各命令参数 | `python3 tools/tv.py --help` 或子命令后的 `--help` |

构建类命令可加 `--offline` 使用已有缓存；第一次构建不能依赖此选项。单独 `package` 的产物位于仓库根 `output/android-tv/`，供开发检查；对外交付使用统一发布目录。

### 常见问题

- **找不到 Python／Java／SDK：** 先完成环境准备；修改环境变量后重开终端，再运行 `doctor`。SDK 路径可在 SDK Manager 的 Android SDK Location 查看。
- **Gradle 下载失败或超时：** 检查终端网络、代理和 SDK 许可后重试；只有完整缓存时才使用 `--offline`。
- **没有设备／多台设备：** 等模拟器进入桌面，或重新连接并授权电视；多设备加 `--serial`。
- **`INSTALL_FAILED_UPDATE_INCOMPATIBLE`：** 签名不同，索取同签名包；不要用卸载作为默认修复。
- **`INSTALL_FAILED_VERSION_DOWNGRADE`：** 安装包内部版本更旧，使用更高版本；脚本不强制降级。
- **连接失败／搜索提示升级：** 先在同网电脑浏览器检查服务器地址并核对令牌。浏览播放可用但搜索缺能力时，更新服务器依赖并重启。

## 开发参考

客户端使用 Kotlin、Compose for TV 和 Media3，只通过 HTTP API 连接服务器。本地媒体的电视和网页共享观看进度；在线收藏与进度按设备观看身份及模式隔离，各设备播放会话独立。Android 日常构建可单独执行，统一发布脚本负责编排镜像和 APK。设备是否能播放 HEVC、HDR 或多声道音频，由实际能力检测和真机验证决定。
