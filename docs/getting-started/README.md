# 项目简介与部署教程

面向第一次接触 jzmedia 的用户。本目录说明软件能做什么、如何安装和维护，不要求了解后端或前端技术。

jzmedia 管理你已经拥有的媒体文件：扫描目录，识别电影与剧集，补充介绍、海报和演职员，再提供浏览器播放。它不提供影片下载源。电影和剧集分开建视频库，同一台 NAS 可以同时承载两类内容。

## 运行前准备

- 一台能运行 Docker Compose 的设备；或具备 Python、Node.js 和 FFmpeg 的 Linux/WSL 开发环境。
- 可读取的媒体目录，以及可写的数据目录。扫描可能按库设置写入 NFO/图片；若暂时只想体验浏览，可把媒体库设为只读。
- 浏览器及到服务器的网络连接。转码性能取决于片源、CPU/GPU 和网络，原文件直发通常负担较低。
- 元数据可来自既有 NFO、本地缓存或网络来源。没有 TMDB 凭据仍可使用离线资料和已启用的外源，但不能保证每部影片都能自动匹配。

当前没有在仓库声明的公开发布地址或许可证。关于分发状态见 [项目首页](../../README.md)。
