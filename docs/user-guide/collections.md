# 用合集、标签和已看状态管理电影

目标：把库中已有影片组织起来，按人物继续找片。

## 准备

选择正确媒体库；合集可包含其下多个电影视频库的影片。

## 操作步骤

从电影海报墙进入多选，勾选已加载电影，可批量标已看/未看、加/去标签、加入合集，或预览删除。**全选只选择当前已加载条目**。批量删除预览列影片、版本及文件数量，确认后会操作物理文件，不能当作“仅从列表隐藏”；执行前核对全部目标和备份。

### 创建和维护合集

入口：顶栏“合集”，或电影详情中的合集标签。合集作用域是媒体库，可跨其下多个电影视频库。

1. 点击“新建合集”展开表单；也可用电影详情“更多操作 → 管理所属合集”新建或加入，海报墙多选支持批量加入。
2. 在合集详情的“管理合集”中编辑名称、简介与成员；编辑时才显示“移出合集”。
3. 需要删除合集时，核对确认弹窗中的名称后再确认。删除合集不删除影片。

合集页默认展示“我的合集”，卡片显示名称和影片数量，手机使用两列；推荐区域可展开，资料补全和全部重查收在“合集维护”。

详情中出现 TMDB 系列提示时可一键建系列合集。合集页也会推荐库中同系列，忽略推荐只保存在当前浏览器；“补齐”将**已在库中的**同系列新片加到已有合集，不下载缺失影片。

点击详情里的演员或导演进入人物页，作品列表只显示当前媒体库：

## 完成后检查

合集成员和标记符合预期；点人物头像可浏览当前库的相关作品。

## 常见问题

删除合集只移除合集；电影墙批量删除会删除实际文件。全选仅含当前已加载条目；合集补齐只加入库中已有影片，不下载缺片。
