# 用合集、标签和已看状态管理电影

目标：把库中已有影片组织起来，按人物继续找片。

## 准备

选择正确媒体库；合集可包含其下多个电影视频库的影片。

## 操作步骤

点击电影海报上的选择圈进入多选，勾选已加载电影，可批量标已看/未看、加/去标签、加入合集，或预览删除。桌面悬停时显示选择圈，手机可直接点海报左上角的选择圈。多选时页面收起“继续观看”。**全选只选择当前已加载条目**。批量删除可展开查看各版本和附属文件的路径。确认前请核对清单和备份。

手机底部保留已选数量、标已看、“更多”和取消；标签、合集、可见性与删除预览从“更多”进入。

### 创建和维护合集

入口：顶栏“合集”，或电影详情中的合集标签。合集作用域是媒体库，可跨其下多个电影视频库。

1. 点击“新建合集”展开表单；也可用电影详情“更多操作 → 管理所属合集”新建或加入，海报墙多选支持批量加入。
2. 在合集详情的“管理合集”中编辑名称、简介与成员；编辑时才显示“移出合集”。
3. 需要删除合集时，核对确认弹窗中的名称后再确认。删除合集不删除影片。

已匹配影片只要在本媒体库内还保留一个版本，就会继续显示在合集里。最后一个版本删除或扫描确认消失后，该影片才会移出本媒体库的合集。空合集可在“管理合集”中手动删除。

合集页在标题旁显示当前合集数量。输入合集名称并搜索，数量会随结果更新。卡片显示合集名称和影片数量，手机上每行两个。打开合集后，点成员的海报或片名即可查看电影详情。展开推荐区域可查看能补齐的合集，资料补全和全部重查收在“合集维护”。

详情中出现 TMDB 系列提示时可一键建系列合集。合集页也会推荐库中同系列，忽略推荐只保存在当前浏览器；“补齐”将**已在库中的**同系列新片加到已有合集，不下载缺失影片。

创建、接受推荐和补齐始终使用发起操作时的媒体库。切换库或离开页面后，“全部接受”停止提交后续项目；已经提交的操作继续处理原库，切回原库查看结果。

## 完成后检查

合集成员和标记符合预期；点人物头像可浏览当前库的相关作品。

## 常见问题

删除合集只移除合集；电影墙批量删除会删除实际文件。全选仅含当前已加载条目；合集补齐只加入库中已有影片，不下载缺片。
