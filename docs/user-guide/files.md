# 文件浏览、上传与删除

<span id="文件浏览上传与删除"></span>

[用户手册](README.md)

## 文件浏览器

入口：“设置 → 文件管理”。也可在“扫描与整理”中点击独立的“管理文件”按钮，选中对应视频库；文件管理不再作为页内标签。通过该按钮进入时，“← 返回扫描与整理”会恢复原视频库、工具标签、展开步骤和滚动位置，同一浏览器标签页刷新后也可返回。从侧栏直接进入时不显示来源返回按钮。

左侧目录树列出视频库及其目录；切换库后，文件列表和操作目标一起切换。文件管理只在配置的视频库内工作，不提供跨视频库移动或复制。

首次进入会显示视频库和目录的加载动画；目录分批读取时显示已读取数量。读取成功后才会提示空目录，连接失败时可直接重试。

单击文件行只定位当前项，不会自动勾选；双击目录进入，双击文件打开预览。需要批量操作时，点击左侧复选框或其周围区域逐项勾选，再使用工具栏。查看另一行或打开预览时，已有勾选保持不变。

按住 Shift 点击复选框可以连续勾选一段项目。表头复选框用于全选当前列表；只勾选其中一部分时显示半选状态，可用“清除勾选”或 Esc 取消。底部状态栏显示已勾选数量，工具栏中的复制、剪切、重命名和删除以这些勾选项为目标。

右键菜单会显示本次操作的对象：右键未勾选的文件时，只操作该文件并保留原有勾选；右键已勾选的文件时，操作整个勾选组。手机可勾选后使用“更多”按钮。操作前可根据菜单顶部的文件名或“已勾选 N 项”确认范围。

文件表格可按名称、大小、修改时间、类型和匹配状态排序；搜索框筛选当前目录，包含后续分页中的文件，不递归搜索子目录。

快捷键仅在文件管理器内生效：方向键移动当前行，Space 切换当前项的勾选，Shift + 上下方向键连续勾选，Enter 打开当前项，Esc 清除勾选。Backspace 返回上级，F5 刷新；Ctrl / ⌘ + A 全选，C / X / V 复制、剪切和粘贴。F2 改名和 Delete 删除也使用明确勾选的项目。改名先预览，再确认；修改新名称会使旧预览失效。移动也先核对目标目录与关联文件。批量删除统一显示影响，确认后物理删除。

电影和剧集文件改名、移动会更新现有记录及同茎字幕/NFO的路径，保留分集 ID、已有匹配和观看进度；预览会列出跟随文件。目录仅支持复制、删除空目录；目录改名或移动请使用归档整理。只读库不能写。

复制为后台任务，有进度与取消，重新打开文件管理会恢复尚在运行的任务。目标同名时自动加“(副本)”并**绝不覆盖**。电影正片复制会尝试以原片匹配线索登记为新版本；目录与剧集文件复制后通过扫描统一登记。大量/大体积操作前再次确认；确认始终使用预览时的目标。取消可能已有部分文件复制完成，等后台写入结束后再扫描。

## 原地预览文件

双击文件，或单击定位后按 Enter、点击“预览”，无需进入媒体详情页，也无需先勾选。关闭弹窗后仍在原目录，保留筛选、排序、当前行、已有勾选和滚动位置；预览与关闭预览不会触发离开前的扫描提示。只读库也可预览。

| 文件 | 预览方式 |
|---|---|
| 图片、PDF | 原地查看，可全屏或下载原文件 |
| TXT、字幕（含 VTT）、NFO、Markdown | 显示纯文本，最多读取前 64 KiB，超出时提示截断；NFO 和 Markdown 不作为网页执行 |
| 已入库电影版本、分集、花絮 | 使用完整播放器预览选中的具体文件，从头开始，不读取或修改观看进度、不标记已看、不自动连播 |
| 未入库视频 | 尝试浏览器直接播放原文件；格式不兼容时可下载，或扫描入库后使用完整播放器 |
| 其他格式 | 显示文件信息和下载入口 |

<DocFigure src="../assets/screenshots/file-preview-text.webp" alt="文件管理中原地查看字幕文本" caption="与详情页共用预览组件；示例字幕与 API 均为合成数据。关闭后回到原来的当前行，不自动勾选。" />

文件管理中的视频预览会显示“不记录观看进度”。如需正常观看并保存进度，使用“查看媒体详情”后播放。预览不会自动扫描或匹配文件；真正离开文件管理时，已有文件变更仍按下方流程核对。

## 文件变更后的扫描与核对

成功的改名、移动、删除、复制和新建目录会留下按视频库保存的待扫描记录；部分成功、取消后已落盘的文件也会保留提醒。页面顶部显示待扫描变更，切换视频库、设置分区或离开设置页前可选择：

- **扫描并核对**：扫描实际发生变更的视频库，转到原有入库流程查看结果和匹配待办。
- **稍后处理**：继续离开，服务器保留待扫描提醒，刷新页面或重启后仍可继续。
- **继续管理**：留在当前文件管理页面。

点击“返回扫描与整理”同样会先检查变更。选择“稍后处理”才恢复原位置；选择“扫描并核对”则进入发生变更的视频库的扫描步骤。

<DocFigure src="../assets/screenshots/file-review.webp" alt="离开文件管理前的扫描核对提示" caption="离开前选择扫描、稍后处理或继续管理。文件操作仍进行时需等待完成后扫描。" />

扫描成功完成后只清除本次已覆盖的变更；扫描期间又改了文件，或扫描失败、取消、库离线时，提醒继续保留。普通扫描不会推翻已确认匹配，结果中的未匹配、集号待办仍需人工核对。文件归档整理继续使用原来的预览确认流程。

关闭或刷新浏览器页面时只能显示浏览器自己的离开提示。在 NAS 或其他软件中改动的文件需要刷新目录或主动扫描才能发现，应用内变更提醒不代表监控了全部外部文件操作。

## 上传

扫描和上传前都需确认目标视频库；上传只列当前媒体库中启用且可写的电影库。传输会分别显示字节、已处理文件及成功／跳过／失败数，可以取消并重试失败文件。取消后已送达服务器的文件可能继续登记，可扫描目标库确认。

电影海报墙“添加影片 → 上传影片”可多选文件或整个文件夹；多电影视频库时先选目标。上传到视频库根，文件夹结构保留；同名文件跳过、不覆盖。进度可取消，正片新版本在上传后会尝试扫描登记；未匹配项可到详情手动处理。上传完成可进入整理预览，将本次影片规范命名或搬到顶层。

<DocFigure src="../assets/screenshots/upload-movie.webp" alt="上传影片：目标视频库、文件选择与开始上传" caption="选好目标库与文件后点“开始上传”；传输中可取消，同名文件跳过不覆盖。" />

电影详情“文件与版本”中的“上传文件”适合与该影片同目录的海报、字幕、音乐、文档、花絮视频或正片新版本。仔细检查目标目录和分类；上传后发现花絮归属错了，先在待处理清单确认。大于 2 GB 的文件更适合稳定局域网传输。上传取消可能留下已经完成的文件。

## 上传剧集

剧集墙“添加剧集”提供“扫描新文件”和“上传文件”。两者都明确显示对应的剧集视频库；上传仅列出当前媒体库中启用且可写的目标。

默认上传整个文件夹，保留原目录结构。多选文件时需选择所属已有剧，或填写新剧名，并指定季号（0 为特典）；文件名的明确季号不能与选择冲突。文件传完后登记可识别的分集，再补全本次剧集资料，显示匹配结果。无法识别集号的文件保留在目标目录，并提示检查编号后重新扫描。上传不会自动移动或改名，目录整理仍经过预览与确认。

## 文件下载、预览和直链

电影详情的“文件与版本”页列正片版本及相关文件，可按文件下载；支持的视频/图片可预览。直链给外部播放器的是原盘文件，不做浏览器端字幕/倍速设置的同步。[播放器说明](player.md)。

## 删除与清理的区别

| 操作 | 实际影响 |
|---|---|
| 删除媒体库/视频库 | 删除库记录，不删磁盘文件 |
| “失效清理” | 对确实不存在的文件清除库记录；库离线时先修复连接，避免误判 |
| 文件浏览器 Delete | 删除实际文件，正片有额外确认；不可恢复 |
| 电影详情文件删除 | 删除选定文件，确认框会区分正片与其他文件 |
| 电影墙批量删除 | 对选中电影执行**物理文件**删除，预览列涉及版本和文件数量 |
| 剧集整理撤销 | 反向重命名/移动已审计操作，不恢复删除的内容 |

物理删除前核对影片、版本、附属文件及备份。只读媒体库禁用写操作，但不是回收站。清理转码缓存只删除服务缓存，不删除媒体文件。
