# 文件浏览、上传与删除

[用户手册](README.md)

## 文件浏览器

入口：“设置 → 扫描与整理 → 对应视频库 → 文件管理”。媒体库根视图显示一级目录和视频库标记，但根本身只读；进入某个视频库后才切换到该视频库的操作上下文。库外目录不可写，也不提供跨视频库移动/复制。

操作类似文件管理器：单击选中、Ctrl 多选、双击进入；Enter 打开、Backspace 返回、F5 刷新，Delete 删除，Ctrl+C/X/V 复制或剪切/粘贴。改名、移动会更新已登记正片及同茎 NFO/字幕的路径；普通媒体目录“目录改名”不支持，可通过归档整理实现。只读库不能写。

复制为后台任务，有进度与取消。目标同名时自动加“(副本)”并**绝不覆盖**。正片复制会尝试以原片匹配线索登记为新版本；目录复制不会自动登记其中全部媒体，完成后需要“扫描新文件”。大量/大体积操作前界面会再次确认；取消可能已有部分文件复制完成。

## 上传

电影海报墙“添加影片 → 上传影片”可多选文件或整个文件夹；多电影视频库时先选目标。上传到视频库根，文件夹结构保留；同名文件跳过、不覆盖。进度可取消，正片新版本在上传后会尝试扫描登记；未匹配项可到详情手动处理。上传完成可进入第二步整理预览，将本次影片规范命名或搬到顶层。

电影详情“文件与版本”中的“上传文件”适合与该影片同目录的海报、字幕、音乐、文档、花絮视频或正片新版本。仔细检查目标目录和分类；上传后发现花絮归属错了，先在待处理清单确认。大于 2 GB 的文件更适合稳定局域网传输。上传取消可能留下已经完成的文件。

## 文件下载、预览和直链

电影详情的“文件与版本”页列正片版本及相关文件，可按文件下载；支持的视频/图片可预览。直链给外部播放器的是原盘文件，不做浏览器端字幕/倍速设置的同步。[播放器说明](player.md)。

## 删除与清理的区别

| 操作 | 实际影响 |
|---|---|
| 删除媒体库/视频库 | 删除库记录，不删磁盘文件 |
| “失效清理” | 对确实不存在的文件清除库记录；库离线时先修复连接，避免误判 |
| 文件浏览器 Delete | 删除实际文件，正片有额外确认；不可恢复 |
| 电影详情文件删除 | 删除选定文件，确认框会区分正片与其他文件 |
| 电影墙批量删除 | 对选中电影执行**物理文件**删除，预览列涉及版本和文件数量 |
| 剧集整理撤销 | 反向重命名/移动已审计操作，不恢复删除的内容 |

物理删除前核对影片、版本、附属文件及备份。只读媒体库禁用写操作，但不是回收站。清理转码缓存只删除服务缓存，不删除媒体文件。
