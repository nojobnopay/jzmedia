# 功能排障

[用户手册](README.md) · [部署排障](../getting-started/troubleshooting.md)

| 现象 | 应先检查什么 | 常用操作 |
|---|---|---|
| 影片/剧集消失 | 顶栏媒体库、搜索筛选、视频库是否停用，NAS 是否在线 | 清空筛选、检查连接、重新扫描 |
| 扫描后标题/海报错 | 实际文件、候选来源、年份和待确认状态 | 详情重新匹配；再检查 NFO/图片落盘 |
| 多次扫描仍未匹配 | 文件名/年份、是否被识别为样片/花絮、来源链冷却 | 检查待匹配清单和提供者状态；使用 NFO/手动绑定 |
| 剧集集号错 | 本地播出顺序、绝对编号、特典归属 | 在集详情指定对应集，确认内容后再整理 |
| 视频没声音 | 音轨选择、音频编码、播放信息、原文件在外部播放器可否播放 | 换音轨；默认 EAC3/AC3 可能转 AAC，仍无声时复制诊断信息 |
| 播放卡顿/CPU 高 | 播放方式、实际输出、后端硬件探测、NAS 链路 | 查看播放信息，试选 1080p/720p；若服务器转码吃力，请维护者检查转码后端，远程适用时预缓存 |
| HDR/DV 色彩不正常 | DV 兼容基底、浏览器的 HDR 支持、是否有硬件色彩转换 | 看播放原因；必要时复制直链交兼容的电视/播放器 |
| 进度条无缩略图 | 是否生成、任务进度、当前节点是否已有页、源文件是否变化 | 在设置生成/继续；远程库空闲时批量生成 |
| 短片已看标记或续播位置不符合预期 | 实际文件版本、当前断点与完成比例，是否使用文件预览 | 对照[完成判定](playback-controls.md#完成后检查)；预览不保存进度，正常观看请从详情播放 |
| ASS 字幕缺字/无样式 | 字体附件、数据目录 fonts、兼容模式 | 投放合法字体或选 VTT 简化模式 |
| 外挂字幕不出现 | 文件是否与正片匹配、所在目录、编码和所选字幕轨 | 检查同茎或标题、`subs/字幕` 一层目录；临时加载测试 |
| 整理提示冲突 | 目标盘/库中占用、疑似错配、做种保护、只读状态 | 核对源和目标；先纠错再重新预览，不覆盖冲突 |
| 撤销失败 | 原路径被占或新路径已被外部移动 | 看撤销预览的冲突明细；从备份和实际目录核对 |
| 更换海报但页面仍旧 | 缓存刷新、绑定、图片源或落盘策略 | 刷新页面，查看数据目录与媒体目录两处图片 |

播放失败时可在齿轮“更多选项 → 复制诊断信息”，同时记录是否为单个片源、特定浏览器或全库问题。日志可能含目录名，分享前去除私人路径及凭据。
