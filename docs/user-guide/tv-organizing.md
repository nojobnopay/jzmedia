# 整理剧集目录与撤销

新增或替换分集后，先补资料，再预览目录与文件名的变化。**确认整理后才会移动或改名**，同茎字幕与 NFO 跟随对应正片，成功操作留在整理历史中。

<DocStoryboard story="tv-organizing" />

## 准备

归属或季号错误时先[修正归属](tv-bindings.md)。整理前核对实际内容与集号，备份重要文件和数据库。整理会改真实目录和文件名，不会自动判断片源内容是否与资料来源一一对应。

只读库可以补应用资料，不能移动或改名。检查时 NFO/海报可能已按视频库策略写入，关闭整理预览不会撤销这些资料更新。

## 剧集：目录规范化

入口：剧详情 **更多操作 → 检查资料与整理**，或 **设置 → 扫描与整理 → 剧集视频库 → 入库整理 → ③ 检查与整理**。

### 检查与补全资料

点击“检查资料与整理”。上传、扫描或进入剧详情发现新分集后，也会使用同一流程。检查期间会显示发现新增分集、补全资料、检查目录与文件名等阶段：有可整理项时自动显示预览；只有资料更新时显示结果，无需确认整理。

检查先复用已确认的剧集归属和缓存，再补齐缺失的季、分集资料，保留手工绑定、本地集和观看进度。可靠资料会先保存到应用；NFO 与海报按视频库落盘策略更新，不会因检查而强制覆盖外部修改。无法识别集号、资料来源请求失败和官方资料暂缺会分别说明，可先处理其余项目。

预览中仍有资料缺失或请求失败时，可点击“重试资料补全”；文件检查不完整时，先等复制结束或恢复连接，再重新检查。

在 FileStation 等外部工具替换分集后，等待写入完成，再重新进入详情、手动检查或扫描视频库；同名覆盖和可唯一对应的改名替换会保留原观看记录，歧义候选需核对。检查后关闭旧播放器再重开，详见[外部替换步骤与检测边界](files.md#在-filestation-中替换分集)。

### 选择整理动作

默认可选七类动作，在预览中的“调整整理范围”选择：

| 动作 | 示例/作用 |
|---|---|
| 剧根改名 | 匹配剧根整理成 `中文标题 (年份)`，最后执行 |
| 季目录 | `season 1` / `S04` → `Season 01` / `Season 04` |
| 包装层拍平 | 去掉只包一层剧资料的多余目录 |
| 正季归位 | 根部散集或季号漂移的集 → 正确 `Season NN/` |
| 特典归位 | S00 → `Season 00/` |
| 花絮目录 | 将符合条件的花絮**目录**上移；不改花絮文件名 |
| 正片改名 | `剧名-S01E01-集名.ext`；同集 V2 用前缀 `剧名-V2-S01E01-…` |

目标冲突不覆盖；深层花絮和散落花絮只提示，可能需自行处理。已确认的本地集保持原名。

检测到做种标记的剧默认跳过。放行做种保护可能影响现有做种状态，需明确选择并重新预览。

绝对集号占比较高的剧默认保留正片名，不猜文件编号。只有核对实际内容后，才勾选允许按 TMDB 编号改名，重新预览后再决定是否执行。

Plex `-partN` 文件保留分段标记；一个多集区间文件按一个实际文件改名或归位。网络资料不足以自动判断各集是否内容对应。

### 单剧与批量预览

剧详情只检查当前剧的目录；扫描与上传涉及多部剧时，在一份预览中按剧汇总。

1. 核对“已补全资料”、原路径、新路径、风险和最终季目录分布。展开每部剧，查看正片及随行字幕、NFO 的数量。
2. 选择执行剧目。需要修改动作时，展开默认收起的“调整整理范围”；修改选项会自动更新这批剧的预览，并保留剧目勾选。
3. 确认变化符合预期，点击“确认并整理”。若执行前文件、归属或规则已变化，必须更新预览后再次核对，不会执行未展示的新变化。

某部剧没有符合当前选项的变更时会从列表隐藏，恢复选项后可再次显示；范围不会扩大到其他剧。列表为空、提示“当前范围无需整理”时，点击“完成”关闭即可。

执行中不能关闭弹窗，进度和完成结果会保留。需要恢复已完成的移动或改名时，使用[整理历史与撤销](#剧集整理历史与撤销)。

### 稍后处理与忽略

- **稍后处理**：保留在待办中，同一批变更不再自动弹窗。可从详情或设置的“查看待办”继续处理。
- **忽略本次**：隐藏当前版本的整理建议；在设置勾选“显示已忽略”仍可查看，手动“检查资料与整理”也能重新预览。
- **有新变化**：新增或替换文件、资料补齐后出现新的整理变化时，会重新提示。

待办与忽略状态保存在服务端，各浏览器共用。播放器、认证或其他弹窗打开时，自动预览会等待，不抢当前操作的焦点。启用访问保护后，自动检查仅在已有管理权限时进行；需要时可手动进入检查并验证权限。

设置中的“查看待办”只重新检查当前视频库已有的待办，勾选“显示已忽略”时一并检查已忽略项目。没有待办时会提示“没有待处理的剧集”。需要检查整库的新文件时，使用“检查资料与整理”。

## 完成后检查

核对成功、跳过与冲突数量，以及最终季目录分布；打开详情试播。取消任务只停止后续工作，已经完成的移动仍然保留。

## 剧集整理历史与撤销

1. 在同一“剧集目录整理”面板展开“整理历史/撤销”，从当前视频库最近 30 批中选择批次与动作类型。
2. 点击“预览撤销”，核对可还原数量、冲突路径和原因。如果整理时也改过剧根，只勾选“剧集”会在改名后的剧根内还原分集，保留当前剧根名称。
3. 核对后点击“执行撤销”，再点击“确认执行撤销”。即使期间有了更新的整理批次，也只会处理刚刚预览的那一批。切换批次或动作类型、磁盘文件发生变化时，请重新预览。

如提示原路径被占用，先核对占用文件的内容并妥善移开，再选同一批次重新预览。如提示源已变化或缺失，请先找到当时整理的原文件。同名的新文件会保留在原处。旧版本的整理记录需能核对剧集归属、文件大小和修改时间；证据不足的项目会列为冲突，保留在历史中供人工核对。

部分存储不提供目录创建时间，应用无法核实同名目录是否仍是整理时的目录。遇到这种提示时，可以只勾选“剧集”重新预览，先还原能核实的分集，再手动核对目录名。

本地和挂载视频库跨磁盘整理时，应用先把完整副本放到目标磁盘，再清理源文件。如果此时原目录收到新文件，任务会报告失败并保留新增文件。请核对两处内容后，再决定保留哪一份。

## 常见问题

集号未确认时，可以在“调整整理范围”取消正片改名，只整理目录。遇到目标冲突或目录占用，先核对实际文件；跨批次的外部改名与移动不能直接通过旧批次恢复。
