# 整理剧集目录与撤销

目标：新增或替换分集后，自动补齐资料并预览目录、季集号和文件命名的变化，再确认整理。操作会保留可核对的整理历史；只读库可以补应用资料，不能移动或改名。

## 准备

归属或季号错误时先[修正归属](tv-bindings.md)。整理前核对实际内容与集号，备份重要文件和数据库。整理会改真实目录和文件名，不会自动判断片源内容是否与资料来源一一对应。

## 剧集：目录规范化

入口：剧详情“更多操作 → 检查资料与整理”，或“设置 → 扫描与整理 → 剧集视频库 → 入库整理 → ③ 检查与整理”。上传、扫描或进入剧详情发现新分集后，也会使用同一流程补资料、检查整理项。有可整理项时自动显示预览；只有资料更新时显示结果，没有文件变更就无需确认整理。

检查先复用已确认的剧集归属和缓存，再补齐缺失的季、分集资料，保留手工绑定、本地集和观看进度。可靠资料会先保存到应用；NFO 与海报按视频库落盘策略更新，不会因检查而强制覆盖外部修改。无法识别集号、资料来源请求失败和官方资料暂缺会分别说明，可先处理其余项目。

在 FileStation 等外部工具替换分集后，等待写入完成，再重新进入详情、手动检查或扫描视频库；同名覆盖和可唯一对应的改名替换会保留原观看记录，歧义候选需核对。检查后关闭旧播放器再重开，详见[外部替换步骤与检测边界](files.md#在-filestation-中替换分集)。

默认可选七类整理动作：

| 动作 | 示例/作用 |
|---|---|
| 剧根改名 | 匹配剧根整理成 `中文标题 (年份)`，最后执行 |
| 季目录 | `season 1` / `S04` → `Season 01` / `Season 04` |
| 包装层拍平 | 去掉只包一层剧资料的多余目录 |
| 正季归位 | 根部散集或季号漂移的集 → 正确 `Season NN/` |
| 特典归位 | S00 → `Season 00/` |
| 花絮目录 | 将符合条件的花絮**目录**上移；不改花絮文件名 |
| 正片改名 | `剧名-S01E01-集名.ext`；同集 V2 用前缀 `剧名-V2-S01E01-…` |

预览中先核对“已补全资料”、将执行的目录和文件变化、风险及最终季目录分布，再展开每部剧查看正片与字幕/NFO 附属数量。选择执行剧目，点击“确认并整理”。目标冲突不覆盖；深层花絮和散落花絮只提示，可能需自行处理。已确认的本地集保持原名。检测到做种标记的剧默认跳过；放行做种保护可能影响现有做种状态，需明确选择并重新预览。

<DocFigure src="../assets/screenshots/tv-organize-panel.webp" alt="剧集入库检查与待办入口" caption="设置中按当前视频库检查资料与整理，或查看之前保留的待办；整理历史与撤销仍在本工具中。" />

绝对集号占比较高的剧默认保留正片名，不猜文件编号。只有核对实际内容后，才勾选允许按 TMDB 编号改名，触发重新预览，再决定是否执行。Plex `-partN` 文件保留分段标记；一个多集区间文件按一个实际文件改名/归位。网络源不足以自动判断各集是否内容对应。

整理示例：`某剧/season 1/第01集.mp4` → `某剧 (2020)/Season 01/某剧-S01E01-集名.mp4`，同茎字幕和 NFO 跟随。

### 单剧与批量预览

剧详情只检查当前剧的目录；扫描与上传涉及多部剧时，在一份预览中按剧汇总。先核对原路径、新路径和目标季目录。“调整整理范围”默认收起，修改选项会自动更新预览。存在连续集号风险时，默认保留正片文件名，只执行允许的目录整理；核对实际内容后，明确勾选按 TMDB 编号改名，才会重新预览文件名变化。

<DocFigure src="../assets/screenshots/tv-organize-dialog.webp" alt="统一剧集入库预览" caption="同一预览汇总已补全资料、目录与文件变化和风险；核对后一次确认整理，也可稍后处理或忽略本次。" />

点击“确认并整理”才会移动目录或重命名文件。执行前若文件、归属或整理规则已经变化，需要更新预览后再次核对，不会直接执行未展示的新变化。执行中不能关闭弹窗，进度和完成结果会保留；需要恢复时参见下方[整理历史与撤销](#剧集整理历史与撤销)。

### 稍后处理与忽略

- **稍后处理**：保留在待办中，同一批变更不再自动弹窗。可从详情或设置的“查看待办”继续处理。
- **忽略本次**：隐藏当前版本的整理建议；在设置勾选“显示已忽略”仍可查看，手动“检查资料与整理”也能重新预览。
- **有新变化**：新增或替换文件、资料补齐后出现新的整理变化时，会重新提示。

待办与忽略状态保存在服务端，各浏览器共用。播放器、认证或其他弹窗打开时，自动预览会等待，不抢当前操作的焦点。启用访问保护后，自动检查仅在已有管理权限时进行；需要时可手动进入检查并验证权限。

## 完成后检查

核对成功、跳过与冲突数量，以及最终季目录分布；打开详情试播。取消任务只停止后续工作，已经完成的移动仍然保留。

## 剧集整理历史与撤销

在同一“剧集目录整理”面板展开“整理历史/撤销”，选择批次与动作类型，先预览，再按两段确认执行。回退按原操作的反向顺序进行，检查当前文件存在、原路径空闲；冲突只报告，不覆盖。它会同步相关数据库路径与整理标记。

<DocFigure src="../assets/screenshots/organize-history.webp" alt="整理历史与撤销" caption="历史区：选择批次（最近 30 批）与动作类型 → 预览撤销 → 两段确认；源缺失或原路径被占时跳过。" />

撤销不自动重写 NFO/海报；需要时另运行“重写剧集 NFO 与海报”。批次审计仅记录成功操作，跨批次手工移动、外部改名或目录占用仍需人工处理。不要把“撤销”当成通用备份恢复。[备份教程](../getting-started/operations.md)。

## 常见问题

集号未确认时可以只整理目录，保留正片名。绝对集号改名许可必须由用户明确勾选并重新预览；本地集保持原名。目标冲突、跨批次外部改名或目录占用需根据实际文件处理。
