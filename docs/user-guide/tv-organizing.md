# 整理剧集目录与撤销

目标：统一剧根、季目录与正片命名，并保留可核对的整理历史。先核对实际内容与集号，备份重要文件和数据库；只读库不能执行。

## 准备

归属或季号错误时先[修正归属](tv-bindings.md)。整理会改真实目录和文件名，不会自动判断片源内容是否与资料来源一一对应。

## 剧集：目录规范化

入口：剧详情“更多操作 → 整理剧集目录”，或“设置 → 扫描与整理 → 剧集视频库 → 入库整理 → ③ 目录整理”。匹配成功后可出现单剧引导。默认可选七类动作：

| 动作 | 示例/作用 |
|---|---|
| 剧根改名 | 匹配剧根整理成 `中文标题 (年份)`，最后执行 |
| 季目录 | `season 1` / `S04` → `Season 01` / `Season 04` |
| 包装层拍平 | 去掉只包一层剧资料的多余目录 |
| 正季归位 | 根部散集或季号漂移的集 → 正确 `Season NN/` |
| 特典归位 | S00 → `Season 00/` |
| 花絮目录 | 将符合条件的花絮**目录**上移；不改花絮文件名 |
| 正片改名 | `剧名-S01E01-集名.ext`；同集 V2 用前缀 `剧名-V2-S01E01-…` |

打开整理项目调整范围，预览后先看“将执行”“仅提示”“需手动”“冲突”“保持原名”及最终季目录分布，再展开每部剧核对正片与字幕/NFO 附属数量。选择执行剧目，按界面两段确认。目标冲突不覆盖；深层花絮和散落花絮只提示，可能需自行处理。已确认的本地集保持原名。检测到做种标记的剧默认跳过；放行做种保护可能影响现有做种状态，应自行确认。

<DocFigure src="../assets/screenshots/tv-organize-panel.webp" alt="剧集目录整理面板预览" caption="面板预览：顶部统计将执行的剧数、正片与附属文件，展开每部剧核对动作与文件示例。" />

绝对集号占比较高的剧默认不选且不猜文件编号。只有核对实际内容后，才勾“我已核对无误，同意按 TMDB 编号改名”触发重新预览，再决定是否执行。Plex `-partN` 文件保留分段标记；一个多集区间文件按一个实际文件改名/归位。网络源不足以自动判断各集是否内容对应。

整理示例：`某剧/season 1/第01集.mp4` → `某剧 (2020)/Season 01/某剧-S01E01-集名.mp4`，同茎字幕和 NFO 跟随。

### 单剧预览与确认

从剧详情打开“更多操作 → 整理剧集目录”时，会先检查该剧目录中的新分集，再展示预览；无法识别集号的文件会提示并保持原样。先核对原路径、新路径和目标季目录。“调整整理范围”默认收起，修改选项会自动更新预览。存在连续集号风险时，默认保留正片文件名，只执行允许的目录整理；核对实际内容后，勾选“我已核对集号，允许按 TMDB 编号改名”才会重新预览文件名变化。

<DocFigure src="../assets/screenshots/tv-organize-dialog.webp" alt="单剧整理弹窗" caption="剧详情的整理弹窗：先列“将执行的更改”与整理后的季分布，再进入两段确认；调整整理范围默认收起。" />

点击“下一步：确认整理”，再次核对后点“确认并开始”。执行中不能关闭弹窗，进度和完成结果会保留；需要恢复时参见下方[整理历史与撤销](#剧集整理历史与撤销)。

## 完成后检查

核对成功、跳过与冲突数量，以及最终季目录分布；打开详情试播。取消任务只停止后续工作，已经完成的移动仍然保留。

## 剧集整理历史与撤销

在同一“剧集目录整理”面板展开“整理历史/撤销”，选择批次与动作类型，先预览，再按两段确认执行。回退按原操作的反向顺序进行，检查当前文件存在、原路径空闲；冲突只报告，不覆盖。它会同步相关数据库路径与整理标记。

<DocFigure src="../assets/screenshots/organize-history.webp" alt="整理历史与撤销" caption="历史区：选择批次（最近 30 批）与动作类型 → 预览撤销 → 两段确认；源缺失或原路径被占时跳过。" />

撤销不自动重写 NFO/海报；需要时另运行“重写剧集 NFO 与海报”。批次审计仅记录成功操作，跨批次手工移动、外部改名或目录占用仍需人工处理。不要把“撤销”当成通用备份恢复。[备份教程](../getting-started/operations.md)。

## 常见问题

集号未确认时可以只整理目录，保留正片名。绝对集号改名许可必须由用户明确勾选并重新预览；本地集保持原名。目标冲突、跨批次外部改名或目录占用需根据实际文件处理。
