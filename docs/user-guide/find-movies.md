# 找到想看的电影

目标：在当前媒体库中找到影片并进入详情。

## 准备

确认已完成[首次入库](onboarding.md)，在顶栏选择需要浏览的媒体库。

## 操作步骤

入口：顶栏“电影”。先选媒体库，输入片名、原名、简介、演职员或标签等已入库文字，再按 Enter 或点击输入框内的放大镜。点击“筛选”展开条件，收起后仍显示已选摘要；结果数量、排序与方向在海报墙上方显示；电影含搜索关键词时按相关度排序。类型、产地大区、国家/地区、年代/年份、标签、已看状态、合集及 TMDB/豆瓣/自评分数可组合筛选。不同维度同时生效；多数维度内多选为任选其一，标签多选要求同时具备。计数来自当前库已有内容。筛选随 URL 保存，可分享链接；无结果时先清空筛选并确认媒体库。长列表会继续加载，也可点击“加载更多”。进入详情再返回时恢复已加载列表和原海报位置；滚动超过一屏后，右下角可一键回到顶部。浏览位置按当前媒体库、筛选与排序分别保存于本次会话。

桌面与手机的“继续观看”都使用可横向滑动的紧凑卡片，海报旁显示片名和进度。手机海报列数随屏幕宽度与[海报大小设置](settings.md#界面显示与系统维护)调整。搜索、筛选和排序集中在列表上方，筛选默认收起。

### 智能搜索

先在“设置 → [智能辅助](settings.md#智能辅助)”中展开“配置与测试服务”，完成配置后启用并保存。在当前媒体库点击“智能搜索”，输入要求，例如“找没看过的 90 年代香港喜剧，TMDB 7 分以上”，再点“解析条件”。查看解析出的类型、年份、评分来源和已看状态，需要时直接修改，最后点“确认应用条件”；结果仍只来自当前浏览范围内已入库的影片。

应用会替换当前筛选，保留所选媒体库；之后可像普通筛选一样调整或清空。关键词输入时的即时联想仍使用本地资料，不会每输入一个字就调用模型。剧集墙也可使用智能搜索，筛选项以剧集当前可用条件为准；电影含搜索关键词时仍按相关度排序。

<DocFigure src="../assets/screenshots/ai-search-preview.webp" alt="智能搜索解析后显示可修改的类型、年代、评分和观看状态，以及确认应用按钮" caption="v0.19.0，2026-10-02：真实界面、模拟解析结果。先核对或修改条件，再确认应用；此图不代表真实模型的理解效果。" />

“两小时以内”“不要恐怖片”“适合儿童”等要求不能靠现有筛选完整表达。遇到不支持或无法核对的条件，先查看提示并改写要求，不要把返回的候选当作满足了全部要求。未启用、无 Key、额度用尽或服务失败时，仍可使用普通搜索和筛选。

## 完成后检查

找到海报，点击后进入对应电影详情；返回列表时恢复原位置。

## 常见问题

没有结果时先清除筛选并确认媒体库和视频库是否启用。评分未提供时不显示，不代表影片评分为零。
