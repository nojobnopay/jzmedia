# 找到想看的电影

知道片名或演员时，可以直接搜索。想按情节、风格或相似作品挑一部看，可以用[智能搜索](#智能搜索)。

## 准备

搜索自己的电影前，先完成[首次入库](onboarding.md)。

## 操作步骤

1. 从顶栏进入“电影”，选择要浏览的媒体库。
2. 输入片名、原名、简介、演职员或标签等已入库文字，按 Enter 或点击输入框内的放大镜。
3. 查看结果数量、排序和方向；有搜索关键词时按相关度排序。找到影片后点击海报进入详情。

### 缩小筛选范围

点“筛选”可以选择类型、地区、观看状态、具体年份、标签及评分。桌面在右侧展开全部条件，手机使用全屏面板。桌面搜索结果上方还提供“类型”“地区”“年代”和“观看”快捷入口。分组收起时显示当前选择；国家/地区、年份或标签较多时，可在对应组内搜索。

选择后点击快捷面板的“应用”或全部面板的“应用筛选”才刷新结果。“清除此项”或“重置”只修改本次草稿；关闭面板或按 Esc 放弃尚未应用的修改，切换媒体库或离开当前页面也会丢弃草稿。已应用条件显示为搜索框下方的标签，点击标签上的关闭图标可立即删除该项；“清空筛选”保留搜索关键词和排序。

同组类型、地区可多选，满足任意一项即可；标签多选要求全部符合。不同条件组同时生效。产地大区与具体国家/地区是两种选择方式，切换方式会替换原有地区条件；同时指定年代与年份时，结果必须同时满足，例如“2020 年代＋2023 年”只保留 2023 年。选项旁的“本库数量”来自当前媒体库已有内容，不是其他筛选组合后的预测结果数。

复制当前页面链接即可分享这组筛选条件。

### 返回列表与手机浏览

长列表会继续加载，也可点击“加载更多”。进入详情再返回时恢复已加载列表和原海报位置；滚动超过一屏后，右下角可一键回到顶部。浏览位置按当前媒体库、筛选与排序分别保存于本次会话。

在桌面宽屏上，打开电影频道就能看到最近未看完的电影。点“继续播放”回到上次观看的版本，点“查看详情”可以核对资料和选择版本。没有断点时，首屏展示当前排序的第一部影片。

手机页头第一行可查看媒体库和观看模式，第二行切换频道。“继续观看”有多部影片时可左右滑动。点续看卡的片名进入详情，点播放键回到断点。点“全部最近播放”可查看最近 20 条记录，包括已看完的影片。手机海报列数随屏幕宽度与[海报大小设置](settings.md#界面显示与系统维护)调整。

### 智能搜索

先在“设置 → [智能辅助](settings.md#智能辅助)”配置并启用模型。电影页和剧集页都可以找片。儿童模式下隐藏此入口。

1. 选好媒体库，点“智能搜索”。输入一句想看的内容，例如“找几部我没看过的、两小时以内的科幻电影”，按 Enter 或点“找片”。普通搜索框里的文字会自动带入，勾选“沿用当前筛选”还可以保留类型、年份等条件。
2. 片单会列出符合条件的作品和入选理由。默认查当前频道，也可以指定电影、剧集或两者，按评分或年份排序，或按现有资料查找具体音轨和分集。符合条件的作品不足时，只列实际找到的数量。
3. 点片名看详情，点“返回片单”继续挑。想比较时直接追问“第一部和第三部有什么区别？”，也可以要求缩小范围或替换其中一部。

<DocFigure src="../assets/screenshots/ai-search-preview.webp" alt="智能搜索列出推荐作品、年份、评分和入选理由，下方可继续追问" caption="这份片单使用虚构作品和模拟模型回答。点片名看详情，或接着提要求调整片单。" />

想找库外作品，可选择“公开片目”查询 TMDB。公开排行默认要求至少 100 票。未入库的作品可查看来源资料，或点“去在线搜索”从已启用的视频源找片。

“没看过”按当前可见片库的共享观看记录判断，已经开始观看的作品也会排除。库外作品的观看情况未知。资料不足以判断某项要求时，页面会说明原因，你可以放宽条件再试。追问失败可重试，或切回“普通搜索”使用原有关键词和筛选。切换媒体库、观看模式或锁定隐私模式后需重新找片。

## 完成后检查

点击海报进入对应影片详情，返回列表可继续从原位置浏览。

## 常见问题

没有结果时，先清除筛选，确认当前媒体库和视频库已启用。评分留空表示尚无评分资料。
