# 找到想看的电影

目标：在当前媒体库中找到影片并进入详情。

## 准备

确认已完成[首次入库](onboarding.md)，在顶栏选择需要浏览的媒体库。

## 操作步骤

1. 从顶栏进入“电影”，选择要浏览的媒体库。
2. 输入片名、原名、简介、演职员或标签等已入库文字，按 Enter 或点击输入框内的放大镜。
3. 查看结果数量、排序和方向；有搜索关键词时按相关度排序。找到影片后点击海报进入详情。

### 缩小筛选范围

需要缩小范围时，点击“类型”“地区”“年代”或“观看”调整常用条件；“全部筛选”还可设置具体年份、标签及 TMDB／豆瓣／自评分数。桌面在右侧展开全部筛选；手机保留“类型”“观看”快捷入口，其余条件从全屏的“全部筛选”面板进入。分组收起时显示当前选择；国家/地区、年份或标签较多时，可在对应组内搜索。

选择后点击快捷面板的“应用”或全部面板的“应用筛选”才刷新结果。“清除此项”或“重置”只修改本次草稿；关闭面板或按 Esc 放弃尚未应用的修改，切换媒体库或离开当前页面也会丢弃草稿。已应用条件显示为搜索框下方的标签，点击标签上的关闭图标可立即删除该项；“清空筛选”保留搜索关键词和排序。

同组类型、地区可多选，满足任意一项即可；标签多选要求全部符合。不同条件组同时生效。产地大区与具体国家/地区是两种选择方式，切换方式会替换原有地区条件；同时指定年代与年份时，结果必须同时满足，例如“2020 年代＋2023 年”只保留 2023 年。选项旁的“本库数量”来自当前媒体库已有内容，不是其他筛选组合后的预测结果数。

筛选随 URL 保存，可分享链接；无结果时先清空筛选并确认媒体库。

### 返回列表与手机浏览

长列表会继续加载，也可点击“加载更多”。进入详情再返回时恢复已加载列表和原海报位置；滚动超过一屏后，右下角可一键回到顶部。浏览位置按当前媒体库、筛选与排序分别保存于本次会话。

桌面与手机的“继续观看”都使用可横向滑动的紧凑卡片，海报旁显示片名和进度。手机海报列数随屏幕宽度与[海报大小设置](settings.md#界面显示与系统维护)调整。搜索、常用筛选入口和已选条件集中在列表上方，其余条件按需展开。

### 智能搜索

先在“设置 → [智能辅助](settings.md#智能辅助)”中展开“配置与测试服务”，完成配置后启用并保存。

1. 在当前媒体库点击“智能搜索”，输入要求，例如“找没看过的 90 年代香港喜剧，TMDB 7 分以上”。
2. 点击“解析条件”，核对类型、年份、评分来源和已看状态，需要时直接修改。
3. 点击“确认应用条件”。结果仍只来自当前浏览范围内已入库的影片。

应用会替换当前筛选，保留所选媒体库；之后可像普通筛选一样调整或清空。关键词输入时的即时联想仍使用本地资料，不会每输入一个字就调用模型。剧集墙也可使用智能搜索，筛选项以剧集当前可用条件为准；电影含搜索关键词时仍按相关度排序。

“两小时以内”“不要恐怖片”“适合儿童”等要求不能靠现有筛选完整表达。遇到不支持或无法核对的条件，先查看提示并改写要求，不要把返回的候选当作满足了全部要求。未启用、无 Key、额度用尽或服务失败时，仍可使用普通搜索和筛选。

## 完成后检查

找到海报，点击后进入对应电影详情；返回列表时恢复原位置。

## 常见问题

没有结果时先清除筛选并确认媒体库和视频库是否启用。评分未提供时不显示，不代表影片评分为零。
