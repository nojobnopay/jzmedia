# 观看在线视频

顶栏的“在线”从已启用的视频源搜索内容，影片不必先加入 NAS 媒体库。播放设备负责解码，jzmedia 只做鉴权、地址解析与有界媒体透传。在线点播默认关闭，需要管理员先配置来源；儿童模式暂不开放在线内容。

## 启用并播放

### Step 1：打开在线点播

进入“设置 → 在线视频源”，点击“启用在线点播”。保护功能开启时，先完成管理验证；配置过写操作令牌的服务还需在当前浏览器填写令牌。

**预期结果：**开关显示已启用。没有启用的视频源时，“在线”仍会提示添加来源。

### Step 2：添加并启用来源

在“视频源”中点击“添加来源”，填写来源名称并选择提供方：

| 提供方 | 需要填写的内容 |
|---|---|
| 开放样例目录 | 接口与主机固定；勾选“启用此来源”即可保存 |
| MacCMS JSON | 站点提供的 JSON 接口地址，以及 API、媒体 CDN、跳转和 HLS 子资源实际使用的精确主机 |

开放样例目录只提供 **Big Buck Bunny**，用于验证联网播放流程，不包含中文影视片库。详情中显示 Blender Foundation、原项目与许可链接；[原项目说明](https://peach.blender.org/about/)使用 CC BY 3.0，完整播放应保留片尾署名。

MacCMS 接口地址例如 `https://example.com/api.php/provide/vod/`，请替换成自己的真实接口，不填写播放网页、单个视频链接、账号密码或查询参数。“允许访问的主机”每行一个精确域名或公网 IP，不带协议、路径、端口或通配符；API 主机会自动包含，媒体可能需要额外添加 CDN 主机。

首次保持“搜索 action”为 `list`、“详情 action”为 `detail`。只有站点明确采用其它兼容方式时，才在“接口兼容设置”中选择 `detail` 或 `videolist`。勾选“启用此来源”，点击“保存来源”。

**预期结果：**来源出现在列表中并显示已启用。保存只验证配置格式，不会自动访问上游，也不代表接口或媒体已经可播放。

### Step 3：选择网络方式

在来源旁点击“网络”，分别设置“来源默认”“API 查询”“媒体取流”等用途，再点击“保存网络规则”。

- **继承**：用途继承来源默认，来源默认再继承应用默认；初始应用默认是直连。
- **直连**：不使用出站代理，也不读取环境代理变量。
- **指定网络档案**：使用已有直连或代理档案。创建代理档案目前通过管理 API，见[网络档案配置](../getting-started/configuration.md#网络档案)。

优先选择免费且可直连的来源；确需代理时，可只为 API 或媒体配置相应出口。代理故障不会自动改走直连。保存网络规则不做连通性验证，API 与媒体是否允许不同出口仍需实际测试。

### Step 4：搜索、选线路并播放

1. 从顶栏打开“在线”，选择一个视频源。MacCMS 输入片名后点击“搜索”；开放样例目录可直接点击“浏览目录”。每次只查询当前来源。
2. 点击结果的“查看详情”，选择播放线路；剧集再选择具体分集。灰色不可播放项会说明不支持的格式或尚未允许的媒体主机，可改选线路或修正来源配置。
3. 点击播放项，在播放器中暂停、跳转、调整速度或使用设备支持的音轨与字幕。关闭播放器会释放当前在线会话；“返回搜索结果”保留当前页的查询结果。

**预期结果：**播放器显示真实画面并推进时间。在线不会自动调用 NAS 转码、字幕烧录或预览生成；设备不支持编码时，选择其它上游线路或播放设备。

## 收藏、续播与观看历史

在线页顶部的“我的在线记录”提供“继续观看”“我的收藏”“观看历史”，每页 20 项。这些记录属于当前设备的观看身份，普通模式与隐私模式分别保存；不与本地媒体记录合并，也不承诺跨设备账户同步。刷新页面后可以读取最近成功保存的位置；清除浏览器观看 Cookie、换浏览器或设备后，不能自动找回原设备的记录。

1. 在内容详情点击“收藏”，之后可从“我的收藏”打开详情或继续播放；点击“取消收藏”移除收藏，不删除观看进度。
2. 已实际开始播放的内容会保存进度。再次点击“继续播放”前会重新读取当前线路与分集，恢复相应位置；起播失败或尚未显示首帧不会建立观看历史。不同线路分别保存位置，不把另一个版本的断点直接搬过来。
3. 在“观看历史”选择“清除观看记录”，移除该内容在当前设备、当前模式下的全部线路和分集进度，收藏仍会保留。

来源或在线总开关停用后，已有记录仍会显示为不可播放，可继续取消收藏或清除记录。每个设备与模式最多保存 500 个收藏、1000 条完整播放身份的进度；达到上限时可清理旧记录。

进度约每 10 秒合并保存，暂停、跳转、关闭和播完时会尝试及时保存；网络失败不会阻止退出。另一播放页已更新同一断点时，旧页会停止覆盖它，视频仍可继续播放。需要从当前页重新保存时，关闭后明确重新开始播放。

清除观看记录会同时使本设备、同一观看模式中其它已打开页面的旧写入失效，防止刚清除的记录被后台回调重新写回。这些页面需重新开始播放后才会保存新记录。退出隐私模式或锁定后不会在普通模式显示隐私收藏与断点。

## 连续播放与手动换线路

剧集详情中的“自动播放下一集（当前浏览器）”默认关闭；偏好在当前浏览器内按普通、隐私模式分别保存，不影响其它设备。开启后，仅在视频真正播到结束时重新读取当前来源的目录，并播放同一内容、同一线路中紧邻的下一集。下一集不支持播放时停止并提示手动选集，不跳过到后面的集数。达到片尾附近的百分比不会提前推进；末集结束、查询失败或关闭播放器时停止。

取消“自动播放下一集”或点击“取消连续播放”可停止等待中的下一集。切换来源、返回搜索、换集、权限变化也会取消旧推进，不会自动改到其它来源或另一个版本。

手动换线路时先关闭当前播放，选择线路后再明确选择分集，各线路沿用自己的断点。换来源需要重新查找并确认片名、版本和集号，不承诺跨源无缝续播。

## 查看最近来源状态

来源选择下方分别显示 API 与媒体的最近实际请求结果及“直连／代理”出口。“刷新状态”只读取已有记录，不主动探测上游：

| 状态 | 含义 |
|---|---|
| 查询通过／本地目录 | API 已返回可解析的目录；开放样例目录本身在服务内提供 |
| 清单已读 | 已完整读取并接受一份有界 HLS 清单，尚不能证明分片或终端解码成功 |
| 取流通过 | 已完整读取一次受限媒体响应，可能仅是文件区间；尚不能证明整片播放稳定 |
| 未观察／观察已过期 | 当前配置没有可用的新观察结果 |
| 近期失败／已停用 | 最近实际请求失败，或来源、总开关已停用 |

观察仅保留在当前服务进程中，最长参考时间为 30 分钟；重启后重新开始，来源或网络配置变化后旧结果不再适用。它不代表终端已经能解码、无需代理或长期稳定，实际播放仍按当前设备与部署网络验证。

## 遇到问题

| 现象 | 下一步 |
|---|---|
| 没有来源或提示已停用 | 检查总开关和对应来源的启用状态 |
| 搜索超时、限流或认证失败 | 稍后重试，或检查该来源的接口、兼容 action 与 API 网络规则 |
| 线路不支持直接播放 | 选择直接提供 MP4/HLS 的其它线路；播放网页、解析 ID 或远程脚本不受支持 |
| 提示媒体主机尚未允许 | 核对该来源真实使用的 CDN 主机后更新允许列表，再重新打开详情 |
| 线路或分集已变化 | 关闭播放器，返回搜索结果并重新打开详情选择 |
| 设备无法解码 | 更换上游版本或播放设备，不会自动转入 NAS 转码 |
| 提示另一播放页已更新进度 | 视频可继续；关闭后重新开始播放，才重新申请当前页的保存资格 |
| 清除历史后另一页面不再保存 | 这是清理旧写入的结果；在需要保存的页面重新开始播放 |

已播放的会话失效时，播放器可有限重建并保留位置；首次起播的格式或协议错误会显示提示与“重新加载”，不会无限重试。持续失败时换来源或检查[网络配置](../getting-started/configuration.md#在线来源的网络策略)。实际可达性取决于部署网络，开发机样例验证不代替 NAS、真实手机/电视或长播验收。
