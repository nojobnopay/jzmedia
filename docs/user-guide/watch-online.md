# 观看在线视频

顶栏的“在线”从已启用的视频源搜索内容，影片不必先加入 NAS 媒体库。播放设备负责解码，jzmedia 只做鉴权、地址解析与有界媒体透传。在线点播默认关闭，需要管理员先配置来源；儿童模式暂不开放在线内容。

## 启用并播放

### Step 1：打开在线点播

进入“设置 → 在线视频源”，点击“启用在线点播”。保护功能开启时，先完成管理验证；配置过写操作令牌的服务还需在当前浏览器填写令牌。

**预期结果：**开关显示已启用。没有启用的视频源时，“在线”仍会提示添加来源。

### Step 2：添加并启用来源

在“视频源”中点击“添加来源”，从“选择视频源”选择一项。名称、接口、允许的主机和兼容选项会自动填入；新增来源的“启用此来源”默认勾选，核对后点击“保存来源”。已有来源的启用状态不会被这项默认值改变。

来源目录目前提供以下配置建议，不会自动添加全部来源或访问上游：

| 来源 | 内容与用途 | 当前验证范围 |
|---|---|---|
| 开放样例目录 | Blender 的 Big Buck Bunny，用于验证播放流程 | 目录在服务内提供；媒体速度需在自己的服务器验证 |
| 暴风资源 | 第三方维护的电影、剧集等目录 | 2026-10-29 开发机 API、部分 HLS 清单与少量分片直连读取通过；整片播放未验 |
| 量子资源 | 第三方维护的影视目录 | 待验证；该次开发机直连未通过，媒体主机尚需核对 |
| 非凡资源 | 第三方维护的影视目录 | 待验证；该次开发机直连未通过，媒体主机尚需核对 |

第三方来源的节目范围、可用地区和媒体线路由运营者决定。接口可读取不代表片库中的每一项都能播放，目录中的网络说明也不能代替当前服务器的验证。不同影片可能还需要补充其实际使用的精确媒体主机。

开放样例目录只提供 **Big Buck Bunny**，用于验证联网播放流程，不包含中文影视片库。详情中显示 Blender Foundation、原项目与许可链接；[原项目说明](https://peach.blender.org/about/)使用 CC BY 3.0，完整播放应保留片尾署名。

需要使用自己的接口时，选择“自定义接口”，填写名称并选择提供方。MacCMS 接口地址例如 `https://example.com/api.php/provide/vod/`，请替换成自己的真实接口，不填写播放网页、单个视频链接、账号密码或查询参数。“允许访问的主机”每行一个精确域名或公网 IP，不带协议、路径、端口或通配符；API 主机会自动包含，媒体和海报可能需要额外添加 CDN 主机。

自定义接口首次保持“搜索 action”为 `list`、“详情 action”为 `detail`。只有站点明确采用其它兼容方式时，才在“接口兼容设置”中选择 `detail` 或 `videolist`。

**预期结果：**来源出现在列表中并显示已启用。保存只验证配置格式，不会自动访问上游。点击该来源旁的“测试来源”可读取一页目录；“目录读取成功”只说明目录响应有效，仍需选择影片实际试播。

### Step 3：选择网络方式

在来源旁点击“网络”，通常只需修改“连接方式”：

- **直连**：服务器直接访问来源，不使用出站代理，也不读取环境代理变量。
- **HTTP(S) 代理**：选择已有代理，或选择“填写新的代理”，填写代理协议、服务器地址和端口；需要认证时展开“代理认证（可选）”。地址必须从运行 jzmedia 的服务器可达。账号密码只写入保存，不会回显。

先核对下方“搜索与详情”和“视频播放”的最终出口，再点击“保存网络规则”。优先尝试直连；若目标服务器访问慢或无法连接，可明确改为代理后重新测试。保存规则本身不做连通性验证，代理故障也不会自动改走直连。

只有搜索接口、媒体或海报需要不同出口时，才展开“高级：按用途分别配置”。六项分别为来源默认，以及搜索与详情、视频播放、海报图片、字幕、订阅更新。“继承来源默认”会跟随上方连接，“直连”则固定绕过代理，即使默认连接以后改成代理也保持直连；来源默认还可继承服务默认，初始服务默认是直连。

修改基本连接会保留已有的单独用途规则。确实希望所有用途使用同一连接时，点击“全部用途使用此连接”，再保存。更多参数见[网络档案配置](../getting-started/configuration.md#网络档案)。

### Step 4：搜索、选线路并播放

1. 从顶栏打开“在线”，选择一个视频源。首次进入会浏览该来源最近更新的内容，再次进入恢复此前的分类、年份、页码和浏览位置。
2. 选择电影、剧集或短剧等频道，再选择具体分类；找不到时打开“全部分类”（手机为“选择分类”），在面板中查找。频道会记住上次选择的分类，综合条目与细分类分别浏览，不能把综合条目当作整个频道的汇总。
3. 来源已验证支持年份查询时，可以选择“年份”；选择“其他年份…”后填写“指定年份”并点击“应用年份”。输入片名后点击“搜索”会清除分类与年份，每次只搜索当前来源。
4. 从海报墙选择内容并“查看详情”，选择播放线路；剧集再选择具体分集。灰色不可播放项会说明不支持的格式或尚未允许的媒体主机，可改选线路或修正来源配置。
5. 点击播放项，在播放器中暂停、跳转、调整速度或使用设备支持的音轨与字幕。关闭播放器会释放当前在线会话；“返回搜索结果”恢复此前的海报墙位置和条件。

**预期结果：**播放器显示真实画面并推进时间。在线不会自动调用 NAS 转码、字幕烧录或预览生成；设备不支持编码时，选择其它上游线路或播放设备。

“发现推荐”按所选来源的最近更新展示，不是个性化推荐或全站热度榜。分类来自来源返回的真实目录，没有分类时不显示分类按钮。海报通过该来源的图片网络规则读取；来源未提供海报或图片读取失败时显示占位，仍可打开详情和选择播放线路。

海报上的更新备注，以及详情中的题材、地区、语言、演员和导演，均来自当前来源；缺少的资料不显示，也不据此推测分集数量。年份筛选由来源执行，当前仅为已核对的暴风接口开放；未验证的来源不显示该控件。可手动查询 1000–9999 的四位年份，某年没有结果时可清除年份或换分类。

目录会短时复用，点击海报墙上方的“刷新”可立即读取来源最新结果并重试海报。加载新结果时保留原有海报墙，更新完成后再替换；图片优先加载当前屏幕可见的部分。分类、页码与位置只在当前网页会话中保留，锁定或切换观看模式会清除；来源配置变化或停用后也会重新校验，不能继续复用旧目录。

## 媒体主机未加入允许列表

目录、海报可以加载，但分集显示“媒体主机尚未加入此来源允许列表”时，说明播放地址使用了当前来源尚未允许的 CDN 域名。

1. 在影片详情点击“检查媒体主机”，进入对应来源设置；按提示完成管理验证。
2. 来源内容编号会自动填写，点击“检查媒体主机”。检查只读取该内容的目录资料，列出精确域名，不会访问新主机或自动修改配置。
3. 核对并勾选需要允许的域名，点击“加入允许列表”。这会保留原有主机与其它配置，并关闭该来源的旧播放会话。
4. 点击“返回影片详情”，重新读取线路后选集播放。

如果检查后其它页面修改了来源，保存会要求重新检查，避免覆盖新配置。新主机实际读取时仍会校验全部 DNS 地址和连接的公网地址；检查出域名不代表已经验证媒体可播。HLS 子清单、分片或重定向使用的额外主机未必出现在目录资料中，需要继续核实后添加。

## 收藏、续播与观看历史

在线页目录下方的“我的在线记录”提供“继续观看”“我的收藏”“观看历史”，每页 20 项。这些记录属于当前设备的观看身份，普通模式与隐私模式分别保存；不与本地媒体记录合并，也不承诺跨设备账户同步。刷新页面后可以读取最近成功保存的位置；清除浏览器观看 Cookie、换浏览器或设备后，不能自动找回原设备的记录。

1. 在内容详情点击“收藏”，之后可从“我的收藏”打开详情或继续播放；点击“取消收藏”移除收藏，不删除观看进度。
2. 已实际开始播放的内容会保存进度。再次点击“继续播放”前会重新读取当前线路与分集，恢复相应位置；起播失败或尚未显示首帧不会建立观看历史。不同线路分别保存位置，不把另一个版本的断点直接搬过来。
3. 在“观看历史”选择“清除观看记录”，移除该内容在当前设备、当前模式下的全部线路和分集进度，收藏仍会保留。

来源或在线总开关停用后，已有记录仍会显示为不可播放，可继续取消收藏或清除记录。每个设备与模式最多保存 500 个收藏、1000 条完整播放身份的进度；达到上限时可清理旧记录。

进度约每 10 秒合并保存，暂停、跳转、关闭和播完时会尝试及时保存；网络失败不会阻止退出。另一播放页已更新同一断点时，旧页会停止覆盖它，视频仍可继续播放。需要从当前页重新保存时，关闭后明确重新开始播放。

清除观看记录会同时使本设备、同一观看模式中其它已打开页面的旧写入失效，防止刚清除的记录被后台回调重新写回。这些页面需重新开始播放后才会保存新记录。退出隐私模式或锁定后不会在普通模式显示隐私收藏与断点。

## 连续播放与手动换线路

剧集详情中的“自动播放下一集（当前浏览器）”默认关闭；偏好在当前浏览器内按普通、隐私模式分别保存，不影响其它设备。开启后，仅在视频真正播到结束时重新读取当前来源的目录，并播放同一内容、同一线路中紧邻的下一集。下一集不支持播放时停止并提示手动选集，不跳过到后面的集数。达到片尾附近的百分比不会提前推进；末集结束、查询失败或关闭播放器时停止。

取消“自动播放下一集”或点击“取消连续播放”可停止等待中的下一集。切换来源、返回搜索、换集、权限变化也会取消旧推进，不会自动改到其它来源或另一个版本。

手动换线路时先关闭当前播放，选择线路后再明确选择分集，各线路沿用自己的断点。换来源需要重新查找并确认片名、版本和集号，不承诺跨源无缝续播。

## 查看最近来源状态

展开在线页的“连接状态”，可分别查看目录 API 与媒体的最近实际请求结果及“直连／代理”出口。“刷新状态”只读取已有记录，不主动探测上游：

| 状态 | 含义 |
|---|---|
| 查询通过／本地目录 | API 已返回可解析的目录；开放样例目录本身在服务内提供 |
| 清单已读 | 已完整读取并接受一份有界 HLS 清单，尚不能证明分片或终端解码成功 |
| 取流通过 | 已完整读取一次受限媒体响应，可能仅是文件区间；尚不能证明整片播放稳定 |
| 未观察／观察已过期 | 当前配置没有可用的新观察结果 |
| 近期失败／已停用 | 最近实际请求失败，或来源、总开关已停用 |

观察仅保留在当前服务进程中，最长参考时间为 30 分钟；重启后重新开始，来源或网络配置变化后旧结果不再适用。它不代表终端已经能解码、无需代理或长期稳定，实际播放仍按当前设备与部署网络验证。

## 在 Android TV 观看

使用包含在线能力的服务端及电视客户端时，电视顶栏会显示“在线”；儿童模式不显示。来源和网络规则仍按上面的步骤在网页配置，电视只选择已有来源，不填写上游接口或代理凭据。安装与连接见 [Android TV 说明](https://github.com/nojobnopay/jzmedia/tree/main/android-tv)。

1. 在电视“在线”选择来源，输入完整片名并“搜索”；可使用电视输入法或“遥控字母键盘”。此搜索交给所选来源，不承诺本地片库的拼音首字母能力；开放样例可直接“浏览目录”。
2. 进入“查看详情”，选择线路和分集，用遥控器确认播放。返回键先回原结果／记录，再退出在线页面；“简介与来源”可查看完整介绍和许可。
3. 在详情收藏，或从“继续观看”“我的收藏”“观看历史”打开。电视的在线记录属于本电视和当前模式，与浏览器记录、本地媒体的共享进度分开；不会自动把网页断点同步到电视。

电视“自动播放下一集”同样默认关闭，只影响本电视、当前模式，真实播完后才播放同来源同线路的紧邻下一集。下一集不支持时停止，不跳集；关闭或离开播放也会取消等待中的下一集。

在线原片由电视解码，服务器不为此自动转码、烧录或生成预览。无法播放时返回选择其它线路或设备；实际音轨、字幕与编解码支持取决于这台电视。没有在线入口时，核对服务端和电视客户端是否都包含在线能力；原有本地媒体播放仍可使用。

## 遇到问题

| 现象 | 下一步 |
|---|---|
| 没有来源或提示已停用 | 检查总开关和对应来源的启用状态 |
| 搜索超时、限流或认证失败 | 稍后重试，或检查该来源的接口、兼容 action 与 API 网络规则 |
| 目录测试成功但影片卡顿 | 展开“连接状态”查看媒体出口；在来源“网络”中明确比较直连和可用代理，或换上游线路。目录查询成功不能证明视频 CDN 足够快 |
| 海报为空但能搜索 | 检查允许的图片主机和“海报图片”网络规则；图片缺失不影响继续选择播放线路 |
| 线路不支持直接播放 | 选择直接提供 MP4/HLS 的其它线路；播放网页、解析 ID 或远程脚本不受支持 |
| 提示媒体主机尚未允许 | 核对该来源真实使用的 CDN 主机后更新允许列表，再重新打开详情 |
| 线路或分集已变化 | 关闭播放器，返回搜索结果并重新打开详情选择 |
| 设备无法解码 | 更换上游版本或播放设备，不会自动转入 NAS 转码 |
| 提示另一播放页已更新进度 | 视频可继续；关闭后重新开始播放，才重新申请当前页的保存资格 |
| 清除历史后另一页面不再保存 | 这是清理旧写入的结果；在需要保存的页面重新开始播放 |

已播放的会话失效时，播放器可有限重建并保留位置；首次起播的格式或协议错误会显示提示与“重新加载”，不会无限重试。持续失败时换来源或检查[网络配置](../getting-started/configuration.md#在线来源的网络策略)。实际可达性取决于部署网络，开发机样例验证不代替 NAS、真实手机/电视或长播验收。
