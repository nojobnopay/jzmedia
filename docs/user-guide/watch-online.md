# 观看在线视频

顶栏的“在线”从已启用的视频源搜索内容，影片不必先加入 NAS 媒体库。播放设备负责解码，jzmedia 负责鉴权、地址解析、媒体转发与有限预取缓存。在线点播默认关闭，需要管理员先配置来源；儿童模式暂不开放在线内容。

## 启用并播放

### Step 1：打开在线点播

进入“设置 → 在线视频源”，点击“启用在线点播”。手机上可从顶栏“更多 → 设置”进入，已在“在线”频道时可直接点“管理视频源”。保护功能开启时，先完成管理验证。配置过写操作令牌的服务还需在当前浏览器填写令牌。

**预期结果：**开关显示已启用。没有启用的视频源时，“在线”仍会提示添加来源。

<span id="online-source-add"></span>

### Step 2：添加并启用来源

1. 在“视频源”中点击“发现并探测来源”。网页逐个探测候选，让正在测速的来源独占本页的取样时间。若公共名单读取失败，可在“本次候选目录出口”选择直连或已有代理。这个选择只影响公共名单，读取失败时会使用最近的缓存或内置候选。
2. 优先看 **播放速度**。例如，2 倍表示预计 3 秒能下载完一个时长 6 秒的分片，低于 1 倍的样片持续播放时容易缓冲。目录耗时是取得一页节目的时间，媒体取样耗时还包括打开清单和读取少量视频。遇到失败或低于 1 倍，服务会在时限内再试其他地址，每个来源最多试三个，并列出各次结果。倍率只代表本次抽到的样片。
3. 某个来源超时或低于 1 倍时，点“延长取样并复测”。若想比较直连与代理，在该来源的“复测出口”中选直连或已配置的代理，再点复测。这个出口同时用于试读该来源的影片目录和视频。核对新结果后，再决定是否保存到这个来源。
4. 新来源会临时试读样片引用的公网播放主机。已配置来源若提示需要新主机，先确认本次试读并复测。核对成功样片需要的主机，需要海报时勾选海报域。沿用当前来源设置时，点“启用来源”。用临时出口成功取样后，新来源可点“启用并保存实测出口”，已启用来源可点“保存实测出口”或“保存出口和主机”。保存后，该来源的影片目录和视频都使用实测出口，海报及其他用途保留原设置。已启用的来源可点“使用此源”找片。
5. “仅目录可读”表示本次尚未读到可用样片，可查看失败步骤，再换出口或延长取样。使用原网络设置探测时，也可主动启用目录可读的来源，手动尝试其他影片。若目录为空、结果过期，或来源和代理配置已经变更，请重新探测。

如需指定接口，点“添加来源”，从“选择视频源”选择一项。名称、接口、允许的主机和兼容选项会自动填入，核对后点击“保存来源”。

添加、编辑来源和配置网络各自打开独立表单，顶部显示当前任务与来源名称。点击“返回视频源列表”恢复列表位置；有未保存修改时先选择继续编辑或放弃。

**预期结果：**所选来源出现在列表中并显示已启用。单个来源旁的“测试来源”只读取一页目录。要比较视频样本速度，使用“发现并探测来源”；要验证某集的实际表现，从该集开始播放。

#### 填写自定义接口

选择“自定义接口”，填写名称并选择提供方。MacCMS 接口地址例如 `https://example.com/api.php/provide/vod/`，请替换成自己的真实接口，不填写播放网页、单个视频链接、账号密码或查询参数。“允许访问的主机”每行一个精确域名或公网 IP，不带协议、路径、端口或通配符；API 主机会自动包含，媒体和海报可能需要额外添加 CDN 主机。

自定义接口首次保持“搜索 action”为 `list`、“详情 action”为 `detail`。只有站点明确采用其它兼容方式时，才在“接口兼容设置”中选择 `detail` 或 `videolist`。

#### 去哪里找视频源？ {#online-source-directory}

找片源时，从“设置 → 在线视频源 → 去哪里找视频源？”打开下表中的来源官网。暴风和量子在帮助中心的“JSON 采集接口”列出主接口和备用接口，非凡将地址列在“app json接口”。请复制 MacCMS 视频目录的基础地址。影视播放网页、M3U8 解析框、XML 接口及 TVBox 订阅都不能填入此栏。

在量子帮助中心的“主页 → 接口总览 → JSON 采集接口”可以复制主接口和备用接口。“替换助手”公告列出播放和封面域名的变更。只想测试播放时，可选择开放样例目录，试播 Blender 官方的 Big Buck Bunny。

#### 问小映为什么在线资源无法播放 {#online-source-diagnosis}

1. 在当前在线节目的详情或播放器点“问小映”，输入“为什么这集播不了？”。也可以在普通模式浏览页或设置页问“为什么量子在线资源无法播放了？”。按提示完成管理验证。没有唯一匹配的视频源时，在“要诊断的视频源”中选择。
2. 等待小映检查，展开“查看检测依据”查看每项的读取时间、出口和结果。从节目或分集打开，能检查该节目详情、所选线路及少量媒体数据。仅提供来源名称时，先检查目录；目录可读时，从出问题的分集再问一次。
3. 当前目录连续两次检测失败时，小映会从已识别运营方的帮助中心查找 JSON 目录栏目，使用本机相同的 API 出口检查候选。有节目上下文时还会核对原节目并取媒体样本。点“查看来源网页”可核对出处；帮助页暂不可达或栏目改版时，依据会注明改用本版收录的候选。
4. 出现换址方案时，核对来源、新旧目录接口和要替换的 API 主机。回复“同意”或点“同意修改”，小映会保存并用当前配置复测。正在使用这个来源的播放会话需要重新打开；有“重新播放”时可直接重试原分集，确认设备能否正常起播。

诊断换址只替换本次验证的目录主机。若希望换址时按公告一并清理播放或封面域名，请在确认前点“取消”，转到设置的换址预览逐项勾选。[预览旧域名与新域名](#online-source-migration)

若目录能读，只有某集通过代理取流失败，小映可能显示“允许临时直连测试本集”。点击后，服务器才会从直连出口访问同一线路进行比较。这次测试只对当前诊断生效。两个出口的结果支持改动时，小映会另行请你确认将这个来源的“视频播放”改为直连。

遇到媒体主机未获允许、设备解码失败或没有已验证的替代地址时，按检测依据处理对应环节。方案有效期为五分钟。超时或期间有人修改了来源或网络设置，点击“重新诊断”可取得当前结果。

#### 请小映更新视频源接口 {#online-source-migration}

1. 在设置页打开小映，说“帮我更新量子资源接口”。小映在本地使用本版内置的来源模板准备新地址。运营方已公布其他地址时，也可以在请求中给出一个完整的公开 HTTP 或 HTTPS 目录地址。
2. 在建议卡的“要更新的已有来源”中核对目标。“新接口取自”可以选运营方模板，也可选“填写接口地址”。核对当前接口、新接口和预览中列出的域名，取消勾选仍要保留的旧域名。
3. 核对后点“确认应用”，新地址和勾选的域名替换会一起保存。回到“设置 → 在线视频源”，点该来源的“测试来源”读取目录，再打开一项节目试播。

有未保存的视频源或网络设置时，先保存或放弃草稿。如果其他管理员已修改来源，点“重新核对”读取当前配置。这个换址预览依据本地配置生成。希望小映先现场查明故障、验证候选并在保存后复测时，请直接描述播放问题。[问小映为什么在线资源无法播放](#online-source-diagnosis)

#### 更新已有来源的接口和允许主机

1. 在已有来源旁点击“编辑”，按运营方帮助页更新接口地址。同一片库在原来源中编辑，可以保留收藏、续播记录、已缓存的剧集及网络规则。
2. 更换接口域名后，在“确认允许列表的主机替换”中核对旧域名、新域名和用途。已核对的媒体与封面域名旁有“来源公告”。只勾选要替换的旧域名，如果旧域名仍有其他用途，可以保留。新接口的主机随地址自动加入允许列表。
3. 点击“保存来源”，再点“测试来源”。打开一项有权观看的节目试播。如果目录能读、分集提示主机未获允许，可在详情检查这部节目的实际媒体主机。[媒体主机检查步骤](#媒体主机未加入允许列表)

接口域名保持原样、只有媒体或封面域名变动时，按公告直接编辑“允许访问的主机”。也可从详情检查实际缺少的主机。该检查只追加已确认的主机，要清理失效的旧域名请在编辑框中移除对应行。

暂时不可用时，可在“编辑”中取消“启用此来源”并保存。停用保留来源配置、网络规则、收藏、进度和剧集缓存。当前设置提供停用操作，尚无整源删除入口。需要释放空间时，可在“在线 → 本地缓存”删除选中的缓存；共享代理在“在线视频源 → 共享代理与服务默认”中管理。[删除剧集缓存](#提前缓存剧集到服务器)

### Step 3：选择网络方式

在来源旁点击“网络”，通常只需修改“连接方式”：

- **直连**：服务器直接访问来源，不使用出站代理，也不读取环境代理变量。
- **HTTP(S) 代理**：选择已有代理，或选择“填写新的代理”，填写代理协议、服务器地址和端口；需要认证时展开“代理认证（可选）”。地址必须从运行 jzmedia 的服务器可达。账号密码只写入保存，不会回显。重复使用同一代理时选择已有配置；“填写新的代理”每次保存都会创建独立档案。

先核对下方“搜索与详情”和“视频播放”的最终出口，再点击“保存网络规则”。优先尝试直连；若目标服务器访问慢或无法连接，可明确改为代理后重新测试。保存规则本身不做连通性验证，代理故障也不会自动改走直连。

只有搜索接口、媒体或海报需要不同出口时，才展开“高级：按用途分别配置”。六项分别为来源默认，以及搜索与详情、视频播放、海报图片、字幕、订阅更新。“继承来源默认”会跟随上方连接，“直连”则固定绕过代理，即使默认连接以后改成代理也保持直连；来源默认还可继承服务默认，初始服务默认是直连。

修改基本连接会保留已有的单独用途规则。确实希望所有用途使用同一连接时，点击“全部用途使用此连接”，再保存。更多参数见[网络档案配置](../getting-started/configuration.md#网络档案)。

展开“共享代理与服务默认”，在其中的“代理配置”查看已保存的代理地址、认证状态、超时与证书配置。点击“编辑”，修改名称、地址或认证后点击“保存代理配置”；编辑会影响所有引用该档案的来源。认证字段留空保留原值，需要移除时明确选择清除认证。点击“删除”，再点击“确认删除”；仍被引用的档案会提示先修改来源规则或服务默认，也要检查高级设置中的单独用途规则。“服务默认连接”修改后需点击“保存服务默认”。切换某一个来源为直连，并不一定解除其它来源或服务默认对该档案的引用。

代理档案的名称只是保存时填写的标签，不表示应用自动发现或持续读取 NAS 的系统代理。旁边的“沿用来源默认”只表示该用途继承上方连接，应以显示的实际代理地址和最终出口为准。选择代理后无法读取目录时，先切回直连并保存，再点击“测试来源”；目录恢复后，核对代理地址、端口、认证及代理是否支持 CONNECT，排查方法见[网络档案配置](../getting-started/configuration.md#网络档案)。保存后关闭并重新打开播放器，使播放使用新的网络配置。

### Step 4：搜索、选线路并播放

1. 从顶栏打开“在线”，选择一个视频源。首次进入会浏览该来源最近更新的内容，再次进入恢复此前的分类、年份、页码和浏览位置。
2. 选择电影、剧集或短剧等频道，再选择具体分类；桌面可打开“全部分类”查找。手机点“筛选”可查找分类并选择年份；仅支持分类的来源显示“分类”。
3. 在搜索框输入片名，点击框内的搜索按钮或按 Enter，每次只搜索当前来源。需要缩小结果时，按下方[分类、年份与搜索规则](#分类年份与搜索)继续筛选。
4. 点击海报打开详情，核对片名与来源。点击片名下方的红色按钮开始播放。有未完成的观看记录时，按钮显示“继续播放”和对应条目。要看另一集，可先选线路，再点集数。
5. 在播放器中暂停、跳转、调整速度或使用设备支持的音轨与字幕。关闭播放器会释放当前在线会话；详情中的返回按钮恢复进入前的海报墙或“我的记录”，以及原来的浏览位置和条件。

**预期结果：**播放器显示真实画面并推进时间。在线不会自动调用 NAS 转码、字幕烧录或预览生成；设备不支持编码时，选择其它上游线路或播放设备。

灰色不可播放项会说明不支持的格式或尚未允许的媒体主机，可改选线路或修正来源配置。

#### 分类、年份与搜索

未搜索时，频道会记住上次选择的分类，综合条目与细分类分别浏览，不能把综合条目当作整个频道的汇总。

来源支持搜索内筛选时，可继续选择分类、年份，搜索词会保留。例如选择“剧集”会包含其全部细类，再选“国产剧”可缩小范围。选择“全部年份”或“不限分类”只取消对应条件。桌面可直接选择年份，手机从“筛选”进入。选定后手机入口会显示年份。也可在“其他年份…”中填写四位年份并点击“应用年份”，关闭面板会放弃尚未应用的年份。

“发现”按所选来源的最近更新展示，不是个性化推荐或全站热度榜。分类来自来源返回的真实目录。后续筛选、年份或分页查询暂时缺少分类资料时，会保留当前来源已读取的分类，不影响继续选择；切换来源、配置或观看范围后重新校验。从未取得分类资料时，不显示分类按钮。海报通过该来源的图片网络规则读取；来源未提供海报或图片读取失败时显示占位，仍可打开详情和选择播放线路。

海报上的更新备注，以及详情中的题材、地区、语言、演员和导演，均来自当前来源；缺少的资料不显示，也不据此推测分集数量。

未搜索时，年份筛选由来源执行，可与分类组合，翻页保留所选年份。现有实现支持暴风 `bfzyapi.com` 与量子 `cj.lziapi.com` 的 HTTPS JSON 点播接口。新模板中的 `apibfzy.com` 和 `lzzyapi.com` 尚未开放年份筛选，网页隐藏该控件，电视保留“年份”一行并提示“当前视频源暂未开放年份筛选”。支持年份的接口可以手动查询 1000–9999 的四位年份。

量子上述主接口支持在搜索结果中继续按分类和年份筛选。首次搜索只读取一页来源数据，先展示 20 项；筛选会复用已读数据，不足时再补充一次有上限的检索。尚未读完时显示已找到的数量和“尚未检索完”，选择“加载更多”或“继续检索”才继续读取，不会一次收集全部搜索条目。暂时没有匹配项时也可继续检索，只有全部读完才会提示没有结果和最终数量。匹配很少的分类可能需要多次继续检索；请求失败会保留已找到的内容与条件，可重试。来源未声明此能力时，搜索中的筛选会提示暂不支持，不会清除搜索词并跳转目录。

搜索框中尚未提交的文字不会影响分类或年份筛选；提交新片名时保留已选条件。清空片名并提交可返回带原分类、年份的目录，“发现”则清除搜索与筛选并返回最近更新。返回详情前的结果时保留已加载内容、条件和位置。

详情页优先显示播放与选集，浏览筛选暂时隐藏，返回后恢复。长简介可展开或收起，演员、导演等资料可按需展开。

详情读取遇到短暂网络超时或上游服务不可用时，会在加载过程中自动再尝试一次，无需连续点击。仍然失败时可点击“重新加载”，或返回选择其他内容；返回、换片及观看权限变化会取消尚未完成的读取，不会自动播放。

目录在当前网页会话中优先复用：15 分钟内返回直接恢复已有海报墙；15～30 分钟先显示已有内容，再检查来源是否更新；超过 30 分钟重新读取。普通目录海报墙可见且标签页在前台时，每 15 分钟最多自动检查一次当前来源、筛选和页码，不扫描其他页面。在结果标题旁的“刷新”可看到上次检查时间。发现变化会提示“内容有更新”，点击“查看更新”才应用结果，保留浏览位置；检查失败继续显示原有内容，不循环重试。搜索内筛选通过“刷新”重新读取，不自动遍历全部搜索结果；其服务端已读数据只短时保存在内存，过期后保留条件重新检索。

点击海报墙上方的“刷新”可立即读取最新结果，并重试失败或缺失的海报。已显示且路径未变的海报会保留。网页先加载屏幕上还没尝试过的海报，遇到临时网络错误时再自动重试一次。已有本地缓存快照时优先使用保存的详情；未命中完整缓存的播放地址仍实时解析，不受首页目录缓存周期限制。分类、页码、位置及待应用结果只在当前网页会话中保留，浏览器完整重载后需重新读取目录；锁定、切换观看身份、来源配置变化或服务重启后会重新校验并清除对应旧内容。

首次读取目录、详情或记录时，会先显示与内容布局相同的占位。翻页、搜索或刷新需要等待时，保留当前海报墙，在屏幕底部显示紧凑的加载提示；操作按钮也显示等待状态。成功、失败或取消后提示消失，不会移动键盘焦点；打开弹窗或播放器时隐藏底部提示。后台检查更新及相关推荐使用各自区域内的轻量提示。浏览器开启“减少动态效果”时停止动画，仍保留可读状态。

播放器在起播、跳转或实际缓冲时，在画面中央显示圆环和对应文字；恢复后自动收起。等待期间仍可操作控件或关闭播放器。短暂等待会延迟显示动画，减少闪烁。

#### 卡顿时使用推荐线路

联网播放器等待首帧、播放中缓冲，或松开进度条后持续等待跳转约 5 秒，网页和支持此功能的 Android TV 会开始查找同一节目、同一集的备用线路。服务器优先检测近期测速表现好的已启用来源。第一条合格线路会先出现，其他设备占用探测名额时显示等待状态。可以直接选择已出现的线路。

点“切换到”后，服务器重新核对片名、年份、季、分集和版本，并准备目标播放会话。准备期间可点“取消切换”继续原线路。目标内容已被替换或准备失败时，原播放器仍可使用。切换成功后沿用新线路自己的观看进度，首次观看该线路从头播放。原线路自行恢复时探测会取消；原线路报错时，仍可等待已启动的探测，或从错误页手动查找。本地缓存播放不会启动卡顿探测。

HLS 点播会自动并行预取后续视频，并在服务器内存中临时缓存，减少短时网络波动造成的等待，无需额外设置。预取窗口按约 10 分钟及每条媒体清单最多 600 个后续分片计算；实际能缓存多久还取决于分片时长、视频码率、缓存空间、设备和下载速度。多个播放会话共用服务器的缓存额度。网页播放器进度条的灰色部分只显示设备已接收的缓冲；服务器已预取但尚未送到设备的数据不会显示在灰色部分，两者可能重叠，不能简单相加。暂停后可以保持播放页面打开，让已有预取继续积累；如果长时间暂停，播放会话可能过期。临近分片遇到短暂网络失败后会有限补试，减少网络恢复后仍需现取的缓存空缺。跳转后调整预取位置，关闭播放后清除当前会话的缓存；不会下载整部影片到媒体库。MP4 沿用按需读取。持续卡顿时仍需检查视频播放的网络出口，有限缓存无法补足长期不足的下载速度。

服务器会自动缓存成功加载的海报原图，最多 128 MiB、有效期 24 小时。刷新整个网页或重启服务后，取得新目录中的图片入口即可复用仍有效的原图，减少重复下载；首次读取、图片地址变化或缓存过期时仍需连接来源。缓存不保证来源网络一直可用，也不绕过观看权限和来源配置检查。

MacCMS 来源的前台目录和搜索主请求遇到连接或读取超时、上游 `502/503/504` 时，会自动补试一次。仍失败时保留已有结果，可点击“重试”；不会循环请求或自动切换代理。服务器还会短时保留成功读取的分类树，减少额外分类查询；主目录仍按正常流程读取，配置或观看权限变化后重新校验。

### 量子网页播放线路

量子当前主接口 `lzzyapi.com` 使用 `lzm3u8` 直链。jzmedia 的 `liangzi` 网页线路仅在此前已适配的 `cj.lziapi.com` 和 `cj.lzcaiji.com` 接口上开放。点击播放时，服务器读取所选分集的网页并取得视频地址；`lzm3u8` 则直接读取视频清单。两条线路各自保留观看进度，不会自动互换。

页面主机和视频主机都需要在来源允许列表中；出现主机提示时，按[媒体主机确认步骤](#媒体主机未加入允许列表)核对后添加。页面解析和视频读取使用“视频播放”的网络规则。服务器只支持已识别的静态页面格式，遇到“网页结构暂不支持”或“网页解析失败”时，可关闭播放器并选择 `lzm3u8` 线路；后者也可先点击“重新加载”重试。

## 长剧集选集与观看定位

播放条目超过 50 项时，可用“条目范围”选择分组，每组最多 50 项。范围按当前列表中的来源顺序划分；条目仍显示原名称，番外、预告或非标准集名不会被改成推测的集号。

长篇剧集和多期节目同样使用分组选择；单条线路最多读取 2000 个播放项，单条内容的所有线路合计最多读取 8000 个播放项。超出时会提示播放项数量超过上限，可换其他内容或来源；不会只显示截断后的部分集数。来源中集名和播放地址完全相同的重复条目只显示一次，保留首次出现的顺序；同名但地址不同的条目仍会提示无法稳定选择。旧版电视客户端仍限制所有线路合计最多 2000 项，需要升级客户端才能打开更长的内容。

“排序”可在正序与倒序间切换，只改变列表显示，不改变“自动播放下一集”的来源顺序。上次观看的位置会在对应组标记；点击“定位上次观看”可切到相应组并聚焦该项，不会自动播放。

初次打开详情时，可恢复上次未完成记录所在的原线路。主动换线后，主要播放按钮遵循当前线路，不把另一版本的断点搬过来；若想回到上次的线路，可使用观看定位入口，再明确选择播放。找不到原条目时，重新选择当前可用的线路与分集。

## 提前缓存剧集到服务器

网络较好时，在网页选择剧集下载，晚上从“在线 → 本地缓存”观看。缓存保存在运行 jzmedia 的服务器磁盘，网页和电视可以共享；观看设备仍须连接服务器。下载管理需要管理验证，服务配置了访问令牌时还须提供该令牌。

1. 打开剧集详情，选择要缓存的线路，点击“缓存剧集”。
2. 勾选单集或多集，或选择整剧后提交。长剧可以跨组选集；整剧只包含提交时当前线路已有的集数，不会自动追更。
3. 打开“本地缓存”检查进度。关闭网页后服务器继续下载；需要时暂停、继续或重试失败的任务。
4. 等目标集数显示“已缓存”，从缓存页打开播放。Android TV 在“在线 → 本地缓存”浏览和观看，添加任务与删除仍在网页完成。

**预期结果：**已缓存剧集可以播放、拖动和连续观看已缓存的下一集，无须访问视频源。再次搜索到同来源、同线路、同一集时，播放也会优先使用缓存。其他来源或线路不会仅凭片名和集号替换成已有缓存。

缓存页使用保存的剧集资料，即使源站暂时不可用或单个来源已停用，完整缓存仍能观看；在线总开关和观看保护继续生效。下一集尚未缓存时会提示，只有明确选择联网播放后才访问来源。缓存损坏时需要重新缓存，不会静默改走网络。

已完成缓存长期保留，不参与“系统维护”的播放缓存或缩略图自动清理。在“本地缓存”中可删除单集、选中的多集或整剧；删除正在播放的集数会停止相关播放。关闭在线点播总开关后仍可暂停和删除缓存，重新启用后才能继续下载或观看。剩余磁盘空间不足时下载暂停，清理出空间后再继续。服务器缓存为共享内容，收藏与观看进度仍按当前设备和观看模式分别保存。

默认缓存当前线路的最高带宽视频画质及其关联音轨、字幕，不重新编码。支持当前可播放的未加密 HLS 点播及 MP4；设备的解码能力与在线播放相同。缓存目录和磁盘配置见[本地剧集缓存配置](../getting-started/configuration.md#本地剧集缓存)。

恢复未完成的下载时，服务器会检查来源内容是否一致。内容变化或来源无法提供可靠的校验信息时，该集会重新下载，避免混合不同版本；已经完成的缓存仍可直接本地播放。

## 查看其他季与相关推荐

来源支持时，网页详情的选集下方会显示相关内容，全部来自当前视频源：

- **同系列其他季**优先显示，按明确的季号排序，并标出当前季。关联由 jzmedia 根据片名与季号整理，仍需核对具体内容；没有标明季号的条目不会自动当作第一季。
- **相关推荐**显示当前来源的同类内容。
- **名称相关**单独显示名称相近、关系尚不确定的条目，可能并非同一系列。

点击推荐海报只打开该条目的详情，需要点击主要播放按钮或具体条目才会播放。详情中的返回按钮仍恢复最初进入详情前的目录或记录页，以及分类、年份、页码和浏览位置。各季沿用来源中的独立条目，收藏与进度分别保存；推荐关系不会合并记录，“自动播放下一集”也不会跨季推进。

相关内容在详情加载后单独读取，不影响先选集播放。部分查询失败时先显示已取得的内容，并提示尚有部分内容无法读取；可手动“重试”，重试期间保留已有海报。没有相关结果时隐藏对应区域；全部读取失败会区分超时、上游限流等原因，查询被暂缓时可点击“查看相关推荐”。推荐读取失败不妨碍使用当前详情与播放器，不会自动循环重试。

## 媒体主机未加入允许列表

同一来源的海报、视频和不同分集可能来自多个域名。网页会提示当前缺少授权的海报或播放主机。

### 在网页确认

**海报加载不出来时**，如果海报墙或节目详情出现“检查海报主机”，点击后会检查对应节目，列出待允许的海报域名。核对域名并点击“确认添加”，当前海报墙或详情会自动刷新。旧服务未提供海报授权状态时，网页不会显示这个提示。

**从设置进入时**，打开“设置 → 在线视频源 → 视频源”，在已启用的 MacCMS 来源旁点击“检查媒体主机”。系统会从来源首页选一部节目，优先检查缺少海报主机的节目。检查结果显示节目名称，并标出海报域名。勾选需要的域名，点击“加入允许列表”。想检查别的节目时，可填写其来源内容编号再检查。从带节目编号的链接进入设置时，编号会自动填好。

如果分集提示“媒体主机尚未加入此来源允许列表”，打开节目详情后会出现播放主机确认对话框。核对域名并点击“确认添加”，详情刷新后继续选择线路和分集。开启保护且尚未取得管理权限时，按提示点击“验证并检查”。

添加主机只对当前来源生效，保留已有主机和网络配置。该来源已有的播放会话会关闭。

<DocFigure src="../assets/screenshots/online-hosts.webp" alt="允许媒体主机对话框：检查并勾选候选域名" caption="隔离模拟：示例域名只用于展示确认步骤，检查不会自动添加域名。" />

点击“暂不添加”或关闭对话框会保留现有配置。关闭播放主机提醒后，可从详情的“检查媒体主机”再次打开。

### 在电视确认

1. 在在线详情选择“检查媒体主机”。开启保护且尚未通过管理验证时，先按提示验证保护密码，再检查。
2. 用方向键浏览候选域名，按确定键切换勾选。候选默认全选，核对后选择“确认添加”；确认前选择“暂不添加”或按返回键不修改配置。
3. 添加成功后，电视重新读取详情，不自动播放。继续选择线路和分集；修改作用于使用该来源的所有设备，该来源已有播放会话会关闭。

如果电视提示服务端不支持检查接口，可先在网页配置媒体主机，或升级服务端后重试。检查后其它页面修改了来源时，需重新检查再确认。添加成功但详情刷新失败时，选择重新加载详情，无需再次添加。来源设置中仍保留手动检查入口。

### 检查范围与允许列表的作用

网页和电视都只从当前内容的目录资料提取所有线路、分集及海报地址中的主机，不查询候选主机的 DNS，也不访问这些新主机。检查出域名不代表已验证媒体可播。HLS 子清单、分片或重定向使用的额外主机未必出现在目录资料中，需要继续核实后添加。

服务端会代播放设备读取来源中的媒体地址。允许列表用于确认该来源可以让服务访问哪些主机，避免目录或重定向变化后自动请求未经确认的网站。实际读取时还会独立校验 DNS 的全部地址，拒绝内网、回环和其它非公网目标；直连只连接已校验的公网地址，代理出口则需信任管理员配置的代理。

如果默认允许所有公网主机，但保留公网地址校验，内网目标仍受拦截；增加的风险是来源可让服务请求任意公网主机，产生额外对外请求和流量。完全取消公网地址校验还会增加访问本机、内网服务等风险。因此保留精确主机确认，同时用“检查媒体主机”减少手动填写。完整网络边界见[在线远程读取](../developer/playback.md#在线远程读取)。

## 收藏、续播与观看历史

浏览在线目录时，搜索栏下方的“继续观看”最多显示最近 12 项未完成内容。左右滑动找到想看的作品，点右侧圆形播放键可从断点继续，点海报或片名可查看详情。提交关键词搜索后，这一行会收起。

点击页面上方“我的记录”，或“继续观看”旁的“查看全部”，可查看完整的续播、收藏和历史，每页 20 项。点击“返回在线浏览”可回到原来的来源、分类和浏览位置。

<DocFigure src="../assets/screenshots/online-records.webp" alt="我的记录中的继续观看、我的收藏和观看历史入口" caption="模拟记录页：从分类入口查看续播、收藏或历史，记录与海报均为虚构数据。" />

这些记录属于当前设备的观看身份，普通模式与隐私模式分别保存；不与本地媒体记录合并，也不承诺跨设备账户同步。刷新页面后可以读取最近成功保存的位置；清除浏览器观看 Cookie、换浏览器或设备后，不能自动找回原设备的记录。

1. 在内容详情点击“收藏”，之后可从“我的收藏”点击海报或标题打开详情。记录卡片的“更多 → 取消收藏”移除收藏，不删除观看进度。
2. 已实际开始播放的内容会保存进度。点击卡片上的播放按钮可继续观看；播放前会重新读取当前线路与分集，恢复相应位置。起播失败或尚未显示首帧不会建立观看历史。不同线路分别保存位置，不把另一个版本的断点直接搬过来。
3. 在“观看历史”打开相应卡片的“更多 → 清除观看记录”，移除该内容在当前设备、当前模式下的全部线路和分集进度，收藏仍会保留。

记录卡片显示海报、片名、来源及已有的集名、播放位置和最近观看时间。时长未知时只显示已观看时间。已完成的内容显示“已看完”，可重新播放。较早的记录可能缺少海报，图片规则变化后也可能出现占位。如果打开该条目的在线详情时取得可用的海报，返回“继续观看”或“我的记录”即可看到更新，无需播放视频或刷新网页。来源缺少可用海报时，卡片会继续显示占位并保留观看进度。目录、记录读取失败时可分别重试，已有内容会尽量保留。

来源停用后，完整缓存仍可播放，其余内容暂不可播放；在线总开关关闭时全部在线内容停止播放。已有记录仍可取消收藏或清除。每个设备与模式最多保存 500 个收藏、1000 条完整播放身份的进度；达到上限时可清理旧记录。

进度约每 10 秒合并保存，暂停、跳转、关闭和播完时会尝试及时保存；网络失败不会阻止退出。另一播放页已更新同一断点时，旧页会停止覆盖它，视频仍可继续播放。需要从当前页重新保存时，关闭后明确重新开始播放。

清除观看记录会同时使本设备、同一观看模式中其它已打开页面的旧写入失效，防止刚清除的记录被后台回调重新写回。这些页面需重新开始播放后才会保存新记录。退出隐私模式或锁定后不会在普通模式显示隐私收藏与断点。

## 连续播放与手动换线路

剧集详情中的“自动播放下一集（当前浏览器）”默认关闭；偏好在当前浏览器内按普通、隐私模式分别保存，不影响其它设备。开启后，仅在视频真正播到结束时重新读取当前来源的目录，并播放同一内容、同一线路中紧邻的下一集。下一集不支持播放时停止并提示手动选集，不跳过到后面的集数。达到片尾附近的百分比不会提前推进；末集结束、查询失败或关闭播放器时停止。

取消“自动播放下一集”或点击“取消连续播放”可停止等待中的下一集。切换来源、返回搜索、换集、权限变化也会取消旧推进，不会自动改到其它来源或另一个版本。

播放器出现备用线路推荐时可以直接切换。需要自行挑选版本时，先关闭当前播放，在详情中选择线路与分集，或回到“在线”选择其他来源。各线路沿用自己的断点。

## 查看最近来源状态

展开在线页来源与搜索工具栏中的“连接状态”，可分别查看目录 API 与媒体的最近实际请求结果及“直连／代理”出口。“刷新状态”只读取已有记录，不主动探测上游：

| 状态 | 含义 |
|---|---|
| 查询通过／本地目录 | API 已返回可解析的目录；开放样例目录本身在服务内提供 |
| 清单已读 | 已完整读取并接受一份有界 HLS 清单，尚不能证明分片或终端解码成功 |
| 取流通过 | 已完整读取一次受限媒体响应，可能仅是文件区间；尚不能证明整片播放稳定 |
| 未观察／观察已过期 | 当前配置没有可用的新观察结果 |
| 近期失败／已停用 | 最近实际请求失败，或来源、总开关已停用 |

观察仅保留在当前服务进程中，最长参考时间为 30 分钟；重启后重新开始，来源或网络配置变化后旧结果不再适用。它不代表终端已经能解码、无需代理或长期稳定，实际播放仍按当前设备与部署网络验证。

## 在 Android TV 观看

使用包含在线能力的服务端及电视客户端时，电视顶栏会显示“在线”；儿童模式不显示。上游接口和网络规则仍按上面的步骤在网页配置；电视可选择已有来源，并确认追加所需的媒体主机，不填写上游接口或代理凭据。安装与连接见 [Android TV 说明](https://github.com/nojobnopay/jzmedia/tree/main/android-tv)。

1. 在电视“在线”选择来源，选择“键盘”后用遥控器输入拼音，并选择候选字词组成片名；英文和数字可切换到“英文/数字”模式，也可使用电视系统输入法。选好文字后选择“搜索”。来源支持搜索内筛选时，可继续选择大类、细类和年份，或用结果下方的“加载更多”“继续检索”补充内容，规则与网页相同。候选由电视离线生成，未必包含完整片名，可逐字选择；搜索交给所选来源，不承诺本地片库的拼音首字母能力。
2. 进入“查看详情”，选择线路和分集，用遥控器确认播放。若提示媒体主机未加入允许列表，按[电视确认步骤](#在电视确认)添加。返回键先回原结果／记录，再退出在线页面；“简介与来源”可查看完整介绍和许可。
3. 在详情收藏，或从“继续观看”“我的收藏”“观看历史”打开。电视的在线记录属于本电视和当前模式，与浏览器记录、本地媒体的共享进度分开；不会自动把网页断点同步到电视。

<DocFigure src="../assets/screenshots/tv-online-browse.webp" alt="电视端在线目录的来源、分类和海报" caption="雷电模拟器中的电视端在线目录：影片和海报均为隔离演示资料，不代表电视真机验收。" />

<DocFigure src="../assets/screenshots/tv-online-keyboard.webp" alt="电视端拼音键盘及候选字词" caption="在拼音键盘输入全拼，再选择候选字词组成搜索内容；画面来自雷电模拟器和隔离演示数据。" />

<DocFigure src="../assets/screenshots/tv-online-detail.webp" alt="电视端在线电影详情、播放线路与正片入口" caption="雷电模拟器中的虚构电影详情：可先选择线路，再播放正片。" />

电视“自动播放下一集”同样默认关闭，只影响本电视、当前模式，真实播完后才播放同来源同线路的紧邻下一集。下一集不支持时停止，不跳集；关闭或离开播放也会取消等待中的下一集。

在线原片由电视解码，服务器不为此自动转码、烧录或生成预览。无法播放时返回选择其它线路或设备；实际音轨、字幕与编解码支持取决于这台电视。没有在线入口时，核对服务端和电视客户端是否都包含在线能力；原有本地媒体播放仍可使用。

## 遇到问题

要检查一次具体的播放失败，可打开出问题的影片或分集，向小映描述现象。[用小映诊断原分集](#online-source-diagnosis)

| 现象 | 下一步 |
|---|---|
| 没有来源或提示已停用 | 检查总开关和对应来源的启用状态 |
| 搜索超时、限流或认证失败 | 稍后重试，或检查该来源的接口、兼容 action 与 API 网络规则 |
| 目录测试成功但影片卡顿 | 展开“连接状态”查看媒体出口；在来源“网络”中明确比较直连和可用代理，或换上游线路。目录查询成功不能证明视频 CDN 足够快 |
| 海报为空但能搜索 | 出现“检查海报主机”时，按[网页确认步骤](#在网页确认)添加提示的域名。域名已允许时，可核对来源网络中的“海报图片”出口。来源没有提供海报、单图超过 1 MiB 或格式不受支持时也会显示占位 |
| 线路不支持直接播放 | 选择直接提供 MP4/HLS 的其它线路；只有量子官方 `liangzi` 线路支持已识别的静态网页格式，其它网页或解析 ID 暂不支持 |
| 网页结构暂不支持／网页解析失败 | 量子网页格式可能变化；关闭播放器后选择 `lzm3u8`，解析失败也可先重新加载 |
| 提示媒体主机尚未允许 | 在详情选择“检查媒体主机”，核对候选后确认添加，再重新读取详情 |
| 线路或分集已变化 | 关闭播放器，返回搜索结果并重新打开详情选择 |
| 设备无法解码 | 更换上游版本或播放设备，不会自动转入 NAS 转码 |
| 提示另一播放页已更新进度 | 视频可继续；关闭后重新开始播放，才重新申请当前页的保存资格 |
| 清除历史后另一页面不再保存 | 这是清理旧写入的结果；在需要保存的页面重新开始播放 |

已播放的会话失效时，播放器可有限重建并保留位置；首次起播的格式或协议错误会显示提示与“重新加载”，不会无限重试。持续失败时换来源或检查[网络配置](../getting-started/configuration.md#在线来源的网络策略)。实际可达性取决于部署网络，开发机样例验证不代替 NAS、真实手机/电视或长播验收。
