# 修正剧名与单集匹配

目标：把整部剧或某一集关联到正确资料。

## 准备

先核对实际内容、年份、播出顺序和特典；改显示名称不能修正错配。

## 操作步骤

1. 未匹配的剧在详情点击“匹配资料”；已有匹配需纠正时，点击“更多操作 → 重新匹配剧集”。也可从“设置 → 扫描与整理 → 剧集视频库 → 入库整理 → 核对匹配”进入。
2. 输入标题，核对候选的剧名、原名、年份与来源后选择。TMDB 候选可直接匹配；支持的无 TMDB ID 候选可“绑定外源”。已有待确认标记时，核对后点“匹配正确”。
3. 匹配完成后核对详情中的海报和季集信息。出现整理引导时，可先查看变更或取消，见[单剧预览与确认](tv-organizing.md#单剧预览与确认)。

“更多操作”中的“修改剧名”改变显示标题，“更新剧集资料”重新取当前绑定信息，两者均不等于移动本地文件。

已启用智能辅助时，可在此请求[候选建议](metadata.md#辅助核对匹配)，核对建议后再选择候选确认。请求建议不修改剧集绑定、季号、集号或目录归属，也不替代已有手工规则。已有目录归属时，此处仅能确认当前 TMDB 作品；其他作品或外源候选会提示通过“归属与季号”预览并调整，不提供直接换绑按钮。

### 单集没有对应资料

进入集详情的“更多操作 → 修正集号匹配”，选季、查询该季候选，按实际内容核对后绑定。操作更新元数据关联，不自动改本地季/集号。总集篇、未收录特典等确实没有对应项，可填写本地标题并点“确认无对应集”；该集继续可播，不再反复作为待匹配提醒，整理时保持原名。以后找到匹配仍可手动绑定。绝对编号、DVD 顺序和特典顺序尤其不能只凭编号顺次套用。

## 完成后检查

剧的海报、简介和季集信息符合实际；无法匹配的本地集可继续播放且不再反复提醒。

## 常见问题

“修正集号匹配”更新资料关联，不自动改文件季/集号。需要多个目录归为同一剧或调整季号时，使用[归属与季号](tv-bindings.md)。
