# 归档整理与撤销

[用户手册](README.md)

整理会改真实目录/文件名。第一次执行前备份重要媒体与数据目录；预览核对片名、年份、季集号及目标路径。只读库不会执行写操作；已有整理审计不是媒体备份。

## 电影：从匹配到归档

单片匹配成功后详情可能弹出“已匹配成功，可以归档了”；也可进入“设置 → 媒体库工具 → 电影视频库 → ③ 归档整理”。先处理第二步待匹配、待确认项，防止按错误影片改名。

1. 在“③ 归档整理”选择“就地归档”或“搬到顶层”。就地规范影片自身目录/文件，保留自建父目录；搬到顶层把影片收敛到当前视频库根。
2. 点击刷新预览。逐行读源/目标、目录内文件列表、命名档提示和冲突。
3. 勾选需要处理的项，可对单行设“强制搬到顶层”或“保持不动”。
4. 对疑似错配返回电影详情修正匹配；对规格变体先调整版别/规格备注再重新预览。系统不会覆盖已占用目标。
5. 确认执行选中项，等待结果并核对文件和详情记录。

`kodi` 与 `plex` 的输出形式不同；`off` 保持命名。预览是当前磁盘状态的快照，执行前若外部软件移动了文件，应重新预览。首次入库位置会保存，电影库“更多工具 → 恢复到原始位置”可预览搬回候选；源缺失或原位置被占时会跳过，不能保证一键恢复所有动作。

## 剧集：目录规范化

入口：剧详情“整理目录”，或“设置 → 媒体库工具 → 剧集视频库 → ③ 剧集目录整理”。匹配成功后可出现单剧引导。默认可选七类动作：

| 动作 | 示例/作用 |
|---|---|
| 剧根改名 | 匹配剧根整理成 `中文标题 (年份)`，最后执行 |
| 季目录 | `season 1` / `S04` → `Season 01` / `Season 04` |
| 包装层拍平 | 去掉只包一层剧资料的多余目录 |
| 正季归位 | 根部散集或季号漂移的集 → 正确 `Season NN/` |
| 特典归位 | S00 → `Season 00/` |
| 花絮目录 | 将符合条件的花絮**目录**上移；不改花絮文件名 |
| 正片改名 | `剧名-S01E01-集名.ext`；同集 V2 用前缀 `剧名-V2-S01E01-…` |

打开整理项目调整范围，预览后先看“将执行”“仅提示”“需手动”“冲突”“保持原名”及最终季目录分布，再展开每部剧核对正片与字幕/NFO 附属数量。选择执行剧目，按界面两段确认。目标冲突不覆盖；深层花絮和散落花絮只提示，可能需自行处理。已确认的本地集保持原名。检测到做种标记的剧默认跳过；放行做种保护可能影响现有做种状态，应自行确认。

绝对集号占比较高的剧默认不选且不猜文件编号。只有核对实际内容后，才勾“我确认按 TMDB 编号改名”触发重新预览，再决定是否执行。Plex `-partN` 文件保留分段标记；一个多集区间文件按一个实际文件改名/归位。网络源不足以自动判断各集是否内容对应。

## 剧集整理历史与撤销

在同一“剧集目录整理”面板展开“整理历史/撤销”，选择批次与动作类型，先预览，再按两段确认执行。回退按原操作的反向顺序进行，检查当前文件存在、原路径空闲；冲突只报告，不覆盖。它会同步相关数据库路径与整理标记。

撤销不自动重写 NFO/海报；需要时另运行“重建剧集 NFO/海报”。批次审计仅记录成功操作，跨批次手工移动、外部改名或目录占用仍需人工处理。不要把“撤销”当成通用备份恢复。[备份教程](../getting-started/operations.md)。
