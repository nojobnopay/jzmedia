# 切换音轨、加载与调整字幕

目标：选对语言，让字幕同步且清晰。先打开一部影片；需要临时字幕时准备 SRT、VTT、ASS 或 SSA 文件。

## 操作步骤

### Step 1：选择想听的语言

<DocStep>

点击播放器底部齿轮，在“音轨”中选择语言；只有一条音轨时不显示切换菜单。部分文件切换音轨时会短暂加载。没有声音时先换一条音轨，并确认原文件在其他播放器中能否正常播放。

</DocStep>

### Step 2：选择或加载字幕

<DocStep>

在“字幕”中选择已有的内嵌或外挂轨道；不需要字幕时选择关闭。

点击“加载字幕文件”可从当前设备选择 SRT、VTT、ASS 或 SSA。临时字幕不写入媒体库；切画质、跳进度仍保留，关闭播放器后失效；也可点“移除本地字幕”提前清除。

### Step 3：调整字幕时间与外观

<DocStep>

展开“字幕调整”，每次可提前或延后 0.5 秒：正值使字幕更晚出现，负值使字幕提前，按影片版本记住。继续播放一段对白，核对同步效果。

文本字幕还能调整背景、描边、字号和位置。“自动”在下黑边足够高时优先放黑边，否则放在画面内。时间偏移按版本保存在当前浏览器，外观设置由该浏览器的文本字幕共用。

## 完成后检查

确认语言、字幕内容和出现时间一致。要长期使用外挂字幕，将文件放在影片旁，或一层 `subs/`、`字幕/` 目录内，用与正片同名或可识别的标题和语言后缀命名；重新打开播放器检查是否识别。

<details>
<summary>各类字幕能调整什么</summary>

| 字幕类型 | 可调整的内容 |
|---|---|
| SRT/VTT 等文本 | 延迟、背景、描边、字号和位置 |
| ASS/SSA 样式字幕 | 延迟；兼容模式会简化原有样式 |
| PGS 图片字幕 | 延迟；兼容处理时可能需要等待 |
| 需要写入画面的字幕 | 切换时可能重新加载视频 |

不同格式不一定拥有相同的外观选项。文本自绘字幕不会显示在浏览器画中画里。ASS 缺中文字形时，可请维护者在数据目录 `fonts/` 投放有权使用的中文字体，或启用 VTT 兼容模式；后者会丢失原有 ASS 样式。实现说明见[播放设计](../developer/playback.md)。

</details>

## 常见问题

- **字幕关不掉：**已经压在视频画面里的硬字幕不能关闭。
- **外挂字幕不出现：**核对同名规则、所在目录、文件编码和当前选中轨；先临时加载同一文件测试。
- **关闭播放器后临时字幕不见了：**重新加载，或按上方规则放成永久外挂字幕。
