# 调整剧集目录归属与季号

把多个目录分配到正确的剧与季，同时保留观看进度。**归属调整的是应用中的分类，实体文件留在原处。**

<DocStoryboard story="tv-bindings" />

## 准备

先确认资料来源中的条目、季名、年份、集数和本地版本。同系列的续作可能列为多个季，也可能有独立剧条目，不能仅凭系列名称或集数相同自动合并。

## 操作步骤

入口：**设置 → 扫描与整理 → 剧集视频库 → 剧集归属与季号**，或剧详情 **更多操作 → 归属与季号**。尚未扫描的新目录也可直接选择。

1. 勾选本次要处理的目录，搜索目标剧或点击“按目录获取建议”。候选会显示季名称、年份及集号覆盖的依据；获取建议不会直接改变归属。
2. 选择系列条目或已有剧，逐目录指定季号。确认使用同一剧条目时，可将不同目录分别指定为第 1、2 季；采用独立剧条目时，分次选择各自目录和对应目标。
3. 点击预览，核对变更前后的季集号、资料缺失、重复集号及手工绑定冲突。明确季号冲突时需主动允许覆盖；同季同集的多个文件需确认保留全部版本，文件不会被丢弃。
4. 确认保存目录规则。新增分集、重新扫描和资料刷新都会沿用确认结果。

“保留原季号”保留已入库分集的当前编号，新文件仍按文件名解析。特典保留第 0 季。确认后的目录按所选季集号补资料，找不到对应项时保留待确认，不再猜测跨季对应关系。

### 保存后需要移动目录或更新资料文件

保存归属只修改应用中的归属记录和图片缓存，**不会移动视频、重命名或写入 NAS 的 NFO/海报**；只读媒体库也可使用。

按后续需要选择入口：

- **重建 NFO 与海报**：使用剧集维护中的“重写剧集 NFO 与海报”。
- **补齐新增分集资料或合并目录**：打开“更多操作 → 检查资料与整理”。补资料沿用已确认编号，NFO/海报按视频库策略写入，目录变化仍需预览确认。

简单的独立季目录可归并到统一剧根的 `Season NN`；混合季号、目标占用或复杂层级需人工核对。首次归并保留正片名，完成后可再次预览统一命名。具体操作见[剧集整理与撤销](tv-organizing.md)。

### 撤销归属变更

在弹窗底部展开“归属变更记录”，先预览，再撤销；撤销前的观看进度会保留。

若确认后又新增分集、移动目录或改变归属，旧记录不能直接撤销，需按当前状态重新设置归属。实体目录整理使用单独的[整理历史与撤销入口](tv-organizing.md#剧集整理历史与撤销)。

## 完成后检查

打开目标剧，核对目录对应的季号。例如 `第一季/`、`第二季/` 应分别出现在第 1、2 季。现有分集 ID、观看状态和断点保留；可打开原先未看完的一集核对进度。

## 常见问题

- **文件名写着 S01，实际属于第 2 季**：先核对内容，在预览前主动允许覆盖明确季号。资料来源没有对应分集时保留待确认，不通过反复保存猜测编号。
- **目录加载较慢**：弹窗先显示已扫描目录，再在后台刷新实体磁盘；远程 NAS 较慢或暂时不可达时，仍可核对已有目录。
- **请求超时**：季资料建议、预览和保存由后台任务处理，浏览器请求超时不会重复启动同一项工作。
