# 选集、续播与连续观看

目标：从剧、季或单集进入播放，沿当前版本继续观看。

## 准备

先把文件登记到剧集类型的视频库，确认剧、季、集号正确。

## 操作步骤

在媒体库建立类型“剧集”的视频库并扫描。顶栏“剧集”汇总当前媒体库的剧集；搜索或筛选后点剧海报进入剧详情，再进入季和集。剧详情优先展示继续观看/下一集与选季，季详情优先展示选集，季/集也可标已看。剧、季、集沿用剧集横版背景，长简介按需展开；单集的上一集/下一集独立成行。各集保存独立断点；花絮和剧场版在剧详情的独立区块播放，拥有自己的断点。

剧集墙的常用筛选和“全部筛选”与[电影墙](find-movies.md#操作步骤)一致，选择后点击“应用”生效，关闭面板放弃草稿；已选标签可逐项移除。“观看”按整剧区分“已看完／未看完”，“全部筛选”另有“连载中／已完结／其他”状态；剧集评分支持 TMDB 与自评。清空筛选保留搜索词和排序，已选条件随 URL 保存。

手机海报墙与电影墙一致，可在[界面显示](settings.md#界面显示与系统维护)调整海报大小。桌面与手机的“继续观看”都以紧凑横卡显示剧名、集号和进度，可横向滑动。

手机上的剧、季、集详情将海报或剧照与标题、基本资料并排，播放操作在简介前。季页分集使用紧凑列表：左侧剧照，右侧集名、日期和简短介绍，点入集详情可查看完整资料；演员列表可横向滑动。

### 花絮和文件状态

剧详情把剧场版和花絮分区，是否归属正确取决于扫描识别和目录结构。远程文件若在应用外部移动，可使用剧或季详情中的“更多操作 → 检查文件是否可用”或重新扫描更新存在性记录；断线时先恢复连接，不要清理记录。

<DocFigure src="../assets/screenshots/tv-extras.webp" alt="剧详情花絮区" caption="花絮按类型标注（幕后/删减片段等）并列出播放入口，各自拥有独立断点。" />

需要向媒体目录写入 NFO 和海报时，参见[剧集资料维护](settings.md#剧集视频库维护)；需要改名或移动目录时，参见[剧集整理与撤销](tv-organizing.md)。

## 完成后检查

下一集沿当前版本推进，已经覆盖的多集区间不会重复播放。自动连播只在当前视频真正结束后触发；达到[已看完阈值](playback-controls.md#完成后检查)只更新已看状态和续播候选，不会提前跳过片尾。

## 常见问题

一个 S01E01-E02 文件仍是一个视频；当前版本结束时自动连播停止。NAS 断线应恢复连接，再检查文件存在性。
