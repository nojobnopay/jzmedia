# 选集、续播与连续观看

目标：查看播出与收藏情况，从剧、季或单集进入播放，沿当前版本继续观看。

## 准备

先把文件登记到剧集类型的视频库，确认剧、季、集号正确。

## 操作步骤

在媒体库建立类型“剧集”的视频库并扫描。顶栏“剧集”汇总当前媒体库的剧集；搜索或筛选后点剧海报进入剧详情，再进入季和集。剧详情优先展示继续观看/下一集与选季，季详情优先展示选集，季/集也可标已看。剧、季、集沿用剧集横版背景，长简介按需展开；单集的上一集/下一集独立成行。各集保存独立断点；花絮和剧场版在剧详情的独立区块播放，拥有自己的断点。

剧集墙的常用筛选和“全部筛选”与[电影墙](find-movies.md#操作步骤)一致，选择后点击“应用”生效，关闭面板放弃草稿；已选标签可逐项移除。“观看”按整剧区分“已看完／未看完”，“全部筛选”另有“连载中／已完结／其他”状态；剧集评分支持 TMDB 与自评。清空筛选保留搜索词和排序，已选条件随 URL 保存。

手机海报墙与电影墙一致，可在[界面显示](settings.md#界面显示与系统维护)调整海报大小。桌面与手机的“继续观看”都以紧凑横卡显示剧名、集号和进度，可横向滑动。

手机上的剧、季、集详情将海报或剧照与标题、基本资料并排，播放操作在简介前。季页分集使用紧凑列表：左侧剧照，右侧集名、日期和简短介绍，点入集详情可查看完整资料；演员列表可横向滑动。

### 查看连载状态与缺季

进入剧详情后，标题下显示“连载中”“已完结”“已取消”等来源状态，播出与收藏区显示最近播出的季集号、日期和收藏情况，并注明资料更新时间。没有下一集日期不代表已完结；资料不足时会显示状态未知或尚未获取，可点击“检查更新”。这项检查只更新播出资料，完整刮削仍使用“更多操作 → 更新剧集资料”。

“选择剧季”同时展示本地季与已有官方资料中的季。没有收藏的季也有卡片，可以进入查看介绍与分集；未来季标注“尚未播出”，日期不明时标注“播出时间未知”。“特别篇（SP）”单独列出，不计入正季的“尚未收藏”汇总。已播出的正季完全没有对应收藏时才进入缺季提示。

收藏范围是**当前媒体库**：同一作品分散在这个媒体库的多个启用剧集视频库中时会合并计算，同集多个文件版本不重复计数。“在某视频库中查看”带你进入实际存有文件的剧季。观看进度、播放版本与已看状态仍属于各自本地文件；另一个媒体库里的收藏不计入当前范围。

季卡片与季详情用“已收藏 3/8 集”表示已收藏 3 集、官方共 8 集；总数包含官方目录中尚未播出的分集，不等于当前已播集数。已确认收藏数超过缓存总数时显示“总数待更新”，保留实际收藏数量。

官方分集目录尚未缓存完整时，已对应官方编号的部分显示“已确认收藏 3/8 集”；本地还有未完成对照的集时，另列本地集数。只能确定本地数量时显示“已收藏 3 集 · 官方 8 集”，避免把本地季与官方季错误相除；总数未知时保留“已收藏 3 集”。无法确定的部分不当成缺集。“资料待补全”说明缺少对照资料，不代表匹配错误或后台任务仍在运行，无需重新匹配。进入“全部分集”可按需读取目录，原有播出资料检查周期保持不变。

实际存在匹配待确认、目录归属冲突或无法确认的季集编号时，页面会说明需要核对的原因；提示只作用于受影响的季或分集，不把其他季一并标为待核对。可按提示检查[剧集匹配](tv-matching.md)。尚未配置 TMDB 或暂时断网时，仍可浏览已保存的资料和本地分集。

### 已收藏与全部分集

季页的“已收藏”用于选集播放，保留剧照、断点、版本筛选与已看操作；“全部分集”按 TMDB 的季集顺序列出分集资料，区分已收藏、未收藏、尚未播出和待核对。没有本地分集的季会先展示全部分集资料。

<DocFigure src="../assets/screenshots/tv-airing-catalog.webp" alt="未收藏新季的全部分集目录：按官方季集号显示日期、尚未播出及未收藏状态" caption="虚构新季目录配合模拟 API：尚未播出与未收藏分别标注，未收藏条目只显示资料；可展开分集简介。" />

官方编号与本地编号不同时，来源链接会显示实际本地季集号。未收藏条目没有播放入口，也不会自动下载文件或建立可播放记录。目录按需读取并缓存；读取失败时保留已有内容，可点击“重试”。

### 海报墙的每周推荐

未搜索或筛选时，剧集海报页的“最近播出”汇总当前媒体库近期已播但尚未收藏的新集，每部剧一张卡片。默认每周自动展开一次，先显示最多 6 部，其余通过“展开其余”查看；手机上可横向滑动。点卡片进入剧详情，不会直接播放。

提醒按当前浏览器和媒体库分别记忆，实际看到的推荐才计入已展示；没有推荐时不会消耗本周提醒机会。新的推荐未到自动展开时间时可点击“查看更新”，从详情返回海报墙时会恢复此前批次与浏览位置。文件扫描入库后，对应分集会从未收藏推荐中移除；已收藏的新集仍可从“继续观看”或季页找到。

在[设置 → 界面显示](settings.md#界面显示与系统维护)可关闭推荐。关闭只影响当前浏览器的海报墙，详情中的播出与收藏资料仍可查看；服务器的低频资料维护独立运行，见[剧集播出资料维护](settings.md#剧集播出资料维护)。

### 多版本与连续观看

多版本（V1/V2）可在季页通过“播放版本”筛选，V2 及以上在集号旁显示版本徽标。自动连播沿当前版本走：V1E01 之后应找 V1E02，不把 V2E01 当下一集。季页可选择版本，去重集数包含多集文件覆盖的集号。上下集与自动连播统一使用服务端顺序，跨分页、跨季均保持当前版本，跳过已覆盖的集号；当前版本结束时自动连播停止。重新进入剧或季详情时，主播放按钮会优先选未完成断点或后续未看集，当前版本没有未看项时也可能推荐其他版本；播放前可核对版本。一个 `S01E01-E02` 文件仍是单个视频；Plex 的 `-partN` 表示分段文件，不等于第二版本。

<DocFigure src="../assets/screenshots/tv-versions.webp" alt="季页的播放版本筛选与分集版本徽标" caption="“播放版本”筛选当前季的分集列表，V2 及以上显示版本徽标；从所选文件开始播放后，自动连播沿当前版本推进。" />

### 花絮和文件状态

剧详情把剧场版和花絮分区，是否归属正确取决于扫描识别和目录结构。远程文件若在应用外部移动，可使用剧或季详情中的“更多操作 → 检查文件是否可用”或重新扫描更新存在性记录；断线时先恢复连接，不要清理记录。

<DocFigure src="../assets/screenshots/tv-extras.webp" alt="剧详情花絮区" caption="花絮按类型标注（幕后/删减片段等）并列出播放入口，各自拥有独立断点。" />

需要向媒体目录写入 NFO 和海报时，参见[剧集资料维护](settings.md#剧集视频库维护)；需要改名或移动目录时，参见[剧集整理与撤销](tv-organizing.md)。

## 完成后检查

下一集沿当前版本推进，已经覆盖的多集区间不会重复播放。自动连播只在当前视频真正结束后触发；达到[已看完阈值](playback-controls.md#完成后检查)只更新已看状态和续播候选，不会提前跳过片尾。

## 常见问题

一个 S01E01-E02 文件仍是一个视频；当前版本结束时自动连播停止。NAS 断线应恢复连接，再检查文件存在性。
