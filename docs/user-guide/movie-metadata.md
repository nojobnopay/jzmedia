# 编辑资料与更换海报

目标：修改显示资料、评分标签，或为正确匹配的电影选择海报。

## 准备

先核对片名、年份、简介；匹配到另一部片时先[重新匹配](metadata.md#案例二发现匹配错了)。

## 操作步骤

在详情点击“更多操作 → 编辑资料”，修改简介覆盖、自评/豆瓣分、标签及版本备注并保存。分数范围 0～10；豆瓣分默认靠手工维护，不能把可选候选来源当成自动评分服务。已看状态在详情主操作中修改，合集通过“更多操作 → 管理所属合集”管理。

编辑显示资料不能修正绑定错片；需要重新匹配、刷新来源或修复资料文件时，按[纠错流程](metadata.md#案例二发现匹配错了)操作。刷新来源数据前可先检查单片，避免覆盖自己的调整。

### 更换海报

点详情海报可放大、下载或进入“换海报”候选界面。选中并保存后检查缓存图片；如果媒体目录里的 `poster.jpg` 仍旧，查看库的落盘策略、写权限和“更多操作 → 修复资料文件（可选 NFO、海报或两者）”。应用海报缓存与媒体目录海报是两份文件。

## 完成后检查

详情显示刚保存的资料或海报；需要媒体目录资料同步时再检查落盘结果。

## 常见问题

应用海报缓存与媒体目录海报是两份文件；只读或关闭落盘时不会向媒体目录写入。
