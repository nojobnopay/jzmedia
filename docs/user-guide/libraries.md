目标：把本地目录或 NAS 连接为媒体库，再添加电影或剧集视频库。第一次使用可直接跟随[新手向导](onboarding.md)。

## 两层结构

一个媒体库保存一个存储连接或根目录，下面可建多个视频库。每个视频库指定相对子目录，并选择电影或剧集类型。例如 `/app/media` 下的 `Movies` 和 `TV Shows` 可以分别登记为电影和剧集视频库。

## 创建本地媒体库

1. 打开“设置 → 媒体库连接 → 添加媒体库”，填写名称，来源选择“本地路径”。
2. 根路径填写**应用进程看得到的路径**：默认 Compose 容器中是 `/app/media`，即使宿主文件实际位于 `/volume1/video`。
3. 添加至少一个视频库，选择相对子目录和电影/剧集类型；可用“检测子目录”辅助选择。
4. 点击“创建媒体库”，检查连接，再先扫描一个视频库核对结果。

添加媒体库会打开独立表单。手机上可直接从名称开始填写，底部保留创建操作；点击“返回媒体库列表”回到原位置。有未保存输入时，先选择继续编辑或放弃修改。

首次启动可能已有默认库。已登记的本地视频库根目录消失时，扫描会报告库离线，保留影片、分集和观看进度。重新接好媒体盘或恢复原目录后，再扫描该库。目录既有电影又有剧集时，先按实际目录拆分视频库，不要用两个重叠路径的视频库代表“分类”。确认路径与类型后再扫描；误扫后不要靠改显示名称修复路径。

## 远程连接

### SMB

在新建媒体库选择 SMB，直接粘贴 `\\服务器\共享\目录` 或 `//服务器/共享/目录`，系统会尝试拆分主机、共享及路径。复杂共享名可展开高级字段手工填写。

输入账户后测试连接，再选择视频库子目录。通常使用自动模式；需调整直读或挂载方式时查看[配置参考](../getting-started/configuration.md)。修改连接后检查库中文件是否仍位于同一逻辑目录。

### NFS

填写 `服务器:/导出路径` 并检查挂载。当前 NFS 依赖操作系统挂载，没有独立用户态直读。应用内挂载权限不足时可在宿主挂载后，以本地路径登记。临时断线应先恢复连接，不要删库重建。

### 扫描提示核对媒体目录

本地目录、挂载点或 SMB 共享不可用时，扫描和“检查失效条目”都会跳过该库。即使路径或共享名相同，换成另一目录也会先保留旧影片、分集和断点。升级后首次检查若找不到任何已登记的文件，也需要核对目录。部分存储无法提供目录创建时间；这种情况下，如果目录有变化且全部已登记文件都已移走，应用会要求确认。

先在宿主机核对媒体盘、挂载内容和视频库路径。挂载意外中断时，恢复原挂载后重扫。确实迁移到新目录时，在该视频库的“扫描入库”中点击“已核对挂载，使用当前目录”。确认只登记当前目录；再次扫描或清理时才处理缺失记录。

### 凭据与备份

远程凭据以加密形式存数据库，数据目录的 `secret.key` 用于解密；换机备份需一并保存。界面不会回显密码。

## 命名档、落盘与只读

| 选项 | 作用 | 注意事项 |
|---|---|---|
| `kodi` | 通用标题/年份/版本/规格命名 | 执行整理时才重命名 |
| `plex` | Plex edition 等命名方式 | 整理预览会提示兼容风险 |
| `off` | 不按命名档改名 | 不等于停止扫描或播放 |
| `none` | 元数据只在应用中 | 不主动向媒体目录写 NFO/图片 |
| `nfo` | 写 NFO | 对应扫描/刷新/重建等落盘流程 |
| `nfo_art` | 写 NFO 和本地图片 | 供其他媒体软件读取 |
| 只读 | 阻止媒体目录写入 | 浏览、播放、扫描入数据库仍可用 |

命名档和落盘策略独立。希望彻底保护媒体目录时同时使用只读设置与操作系统权限。

## 编辑、停用和删除

展开媒体库可逐视频库扫描、编辑或删除；媒体库的“更多”中有连接、挂载、只读、停用等操作。

手机默认收起各媒体库的视频库明细，点击媒体库名称展开。修改连接、根目录或视频库时进入独立编辑页面；保存或取消后回到列表，未保存内容会先提示确认。

视频库类型只能在空库改；已有记录的本地媒体库也不支持直接“改路径”，以防旧文件路径失联。删除媒体库会级联删除所属视频库**记录**，不会删除媒体盘文件，但已有匹配和库设置可能丢失。先备份再做结构调整。
