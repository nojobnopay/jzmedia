# 使用进度缩略图与远程预缓存

目标：预览跳转位置，或提前缓存适用的远程视频。

## 准备

新扫描入库的视频会排队，在服务器本地时间 03:00–06:00 且无人播放时自动生成。升级前已经入库的视频不会自动加入整库队列，可以在设置中将已有的本地视频加入闲时队列。远程读取会占用 NAS 带宽，批量操作建议在空闲时运行。

## 操作步骤

鼠标悬停进度条会显示目标时间，已有预览图时显示附近采样节点。拖动时只更新预览，松手后跳转；触屏同样可拖动。连续按方向键会合并目标。缓冲或已产出片段范围内尽量直接定位，超出时可能要重新建立播放连接。

### 生成进度缩略图

1. 若当前片还没有预览图，在播放器中打开齿轮，选择“更多选项 → 进度缩略图 → 生成预览”。
2. 在“更多选项”查看当前影片已抽取的帧数和百分比；已有页可先用，任务可取消并继续。完成后这里显示“预览已生成完毕”，生成按钮不可再点击。
3. 回到进度条悬停或拖动，核对预览图。查看进度条本身不会启动抽帧。

进入“设置 → 扫描与整理 → 对应视频库 → 资料维护”，可查看本库的“正在处理”和“待处理队列”。待处理项可逐一“移出队列”，也可勾选多项后“批量移出选中项”；“全选本库待处理项”覆盖所有分页，勾选后仍可取消个别影片。正在处理的闲时任务需单独“取消并移出队列”，不会被待处理项的全选包含。移出只影响预览任务，不删除影片或已经生成的预览图。若选择期间队列变化，界面会提示重新选择。

本地视频库可点击“将已有影片加入闲时队列”，把尚未完成预览的已有电影、分集和花絮排入上述时段；已有成品、已排队项和源文件不可用项会分别统计。需要立即生成时，点击“立即批量生成”：任务处理当前库的所有可播放项，自动跳过已有成品，遇在线转码会等待。“正在处理”也会显示立即生成的当前影片；点击“取消任务”会停止整个立即生成任务。远程生成会读取 NAS，建议空闲运行。

默认本地每 10 秒、SMB/NFS 每 20 秒取一帧，不是逐帧预览。自动队列会让位于播放及手动生成，达到应用数据 20 GB 提醒线或接近进度缩略图缓存上限时暂停。图片有独立缓存限额，源文件变化或缓存淘汰后需重新生成；无兼容基底的 Dolby Vision 暂不生成预览。

### 为远程播放预缓存

电影详情的“预缓存与转码”折叠区内，对适用的远程 remux/音频转码版本显示“预缓存到服务器”，把从 0 开始的完整播放结果缓存到服务器；需要视频重编的版本显示“开始预转码”，直发无需此项。远程视频仅需重新封装时，可选择“原画”保留视频；主动降到低于源尺寸的 1080p/720p 会进行视频转码。

完成的完整缓存也可用于续播和跳转，但缓存方案须与实际画质、编码和烧录字幕设置一致。缓存尚未完成、方案不同或缓存已淘汰时，仍可能重新读取片源。缓存受 24 小时保存期限与总量限额约束，不是永久离线下载。续播操作见[续播与从头开始](playback-controls.md#完成后检查)。

### 外部播放与诊断

“更多选项 → 复制播放直链”得到原文件地址，可交给 VLC/Kodi 等播放器；外部设备需能访问 jzmedia 并自行支持该格式，浏览器中的倍速、字幕样式/延迟不会带过去。播放问题可用“复制诊断信息”；分享前检查路径和环境信息。

## 完成后检查

进度条显示已经生成的采样图；预缓存完成后，以相同播放方案从头播放、续播或跳转均可复用完整缓存。

## 常见问题

缩略图不是逐帧预览。新入库视频在夜间自动生成；旧片可加入本地库闲时队列，急需预览的片源可立即生成。进度缩略图可在“设置 → 系统维护”先检查可清理空间，再确认清理；播放缓存另有清理入口。无兼容基底的杜比视界暂不生成缩略图。
