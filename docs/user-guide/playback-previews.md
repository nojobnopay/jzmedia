# 使用进度缩略图与远程预缓存

目标：预览跳转位置，或提前缓存适用的远程视频。

## 准备

新扫描入库的视频会排队，在服务器本地时间 03:00–06:00 且无人播放时自动生成。升级前已经入库的视频不会自动加入整库队列，可以在设置中将已有的本地视频加入闲时队列。远程读取会占用 NAS 带宽，批量操作建议在空闲时运行。

## 操作步骤

鼠标悬停进度条会显示目标时间，已有预览图时显示附近采样节点。拖动时只更新预览，松手后跳转；触屏同样可拖动。连续按方向键会合并目标。缓冲或已产出片段范围内尽量直接定位，超出时可能要重新建立播放连接。

### 生成进度缩略图

1. 若当前片还没有预览图，在播放器中打开齿轮，选择“更多选项 → 进度缩略图 → 生成预览”。
2. 在“更多选项”查看当前影片已抽取的帧数和百分比；已有页可先用，任务可取消并继续。完成后这里显示“预览已生成完毕”，生成按钮不可再点击。
3. 回到进度条悬停或拖动，核对预览图。查看进度条本身不会启动抽帧。

进入“设置 → 扫描与整理 → 对应视频库 → 资料维护”，可查看本库的“处理队列”。当前影片固定在列表顶部，显示抽帧进度或等待播放转码的原因；其余项目是立即批量生成和闲时队列中尚未开始的影片，同一影片只显示一次，生成完成后自动移出。点击待处理项右侧的移出图标可逐一移出，也可勾选多项后“批量移出选中项”；“全选待处理”覆盖本库所有分页，勾选后仍可取消个别影片。当前影片不参与勾选和批量移出。长片名和文件名会省略显示，鼠标悬停可查看完整名称。

清空待处理项会同步移出立即批量任务和闲时队列中的这些影片；正在处理的影片继续完成，之后不会再生成已移出的影片。要立即停止当前任务，可点击顶部当前项右侧的取消图标：闲时任务会取消并移出，立即批量任务则取消整个任务。移出只影响预览任务，不删除影片或已经生成的预览图。若选择期间队列变化，界面会提示重新选择。

展开“已生成缩略图”，可分页查看本库已有完整预览的电影、分集和花絮；需要重新核对时点击刷新。列表按需加载，未展开时不会读取。标为“旧版可用”的影片仍可显示已有预览，可按下文步骤更新画质；部分生成、片源已变化或不再可用的预览不会列为成品。抽帧进度达到 100% 后还需要完成拼图和保存，完成后才会进入清单。

在“已生成缩略图”下方、处理队列上方展开“生成失败”，可查看本库失败影片的文件名、最近失败时间和原因，例如片源离线、抽帧超时或解码失败。每个视频只保留最近一次未解决失败，刷新页面或重启服务后仍可查看；升级前已经丢失的失败信息无法恢复。清单支持独立分页和刷新，展开期间会更新，读取失败时可点击重试。

修复原因后，点击该项的“重新生成”，会将影片加入处理列表末尾。手动重试不受自动生成开关和闲时时段限制，不打断正在处理的影片；执行时会跳过暂不符合运行条件的闲时项，因此后面的手动重试可能先于这些闲时项开始。已经运行或等待立即生成的项目不会重复加入；仅在闲时队列中的同一影片会改为手动重试并移到队尾。手动重试遇到播放转码时仍会等待，排队后上次失败原因继续保留，成功后才从失败清单移出；再次失败则更新时间和原因。

手动重试可在处理队列中逐项移出，正在生成的重试也可单独取消，不影响其他任务。取消或移出不会清除上次失败原因。服务重启后未完成的重试仍会恢复；若保留的旧版缩略图可用，但升级画质失败，同一影片可以同时出现在已生成清单和失败清单。

本地视频库可点击“将已有影片加入闲时队列”，把尚未完成预览的已有电影、分集和花絮排入上述时段；已有成品、已排队项和源文件不可用项会分别统计。需要立即生成时，点击“立即批量生成”：任务处理当前库的所有可播放项，自动跳过已有成品，遇在线转码会等待。“处理队列”顶部也会显示立即生成的当前影片；取消该项会停止整个立即生成任务。远程生成会读取 NAS，建议空闲运行。

帧数暂时不动且显示等待播放转码时，表示任务正在为播放让出资源。已保存的页面会保留，当前尚未提交的页在恢复后可能重做；播放转码结束或因缓冲已足够而暂停时，手动缩略图任务继续。普通播放器关闭后会释放自己的转码任务；异常断开且关闭请求未送达时，需要等待会话失活回收。其他设备仍在播放，或此前明确启动了整片预缓存时，后台任务仍可能继续，无需反复取消缩略图。

默认本地每 10 秒、SMB/NFS 每 20 秒取一帧，不是逐帧预览。自动队列会让位于播放及手动生成，达到应用数据总预算（默认 20 GB）或接近进度缩略图缓存上限时暂停。图片有独立缓存限额，源文件变化或缓存淘汰后需重新生成；无兼容基底的 Dolby Vision 暂不生成预览。总预算及缓存额度可在[应用数据与缓存](settings.md#调整应用数据与缓存)中调整。

本地视频默认批量提取附近的关键画面，只对缺失位置补抽；不适合批量处理的片源会自动逐点提取附近画面，再按需使用精确抽帧。采样间隔保持不变，预览画面与目标时间可能相差一个采样间隔，松手后的跳转位置仍按原片时间计算。需要强制精确预览或调整资源占用时，维护者可参考[播放与缓存配置](../getting-started/configuration.md#播放与缓存)。

每张预览画面为 160×90 像素。生成时用无损中间图片保留抽帧结果，拼图时只进行一次 JPEG 压缩，减少重复压缩造成的模糊；缩略图仍不能呈现原片的全部细节。

升级前已生成的旧画质图片不会自动变清晰，也不会因升级自动重建全库。要更新已有预览，在上述视频库资料维护中点击“立即批量生成”，或将本地库已有影片加入闲时队列；这两种方式会按当前画质规则处理，跳过已经完成新画质预览的影片。重建完成前仍可显示旧版完整预览，中途取消或失败会保留旧图；同一片源和采样配置的新版完整生成后，自动删除对应旧画质图片，完成后重新打开播放器读取新图。无需先清空全部缩略图。

### 为远程播放预缓存

电影详情的“预缓存与转码”折叠区内，对适用的远程 remux/音频转码版本显示“预缓存到服务器”，把从 0 开始的完整播放结果缓存到服务器；需要视频重编的版本显示“开始预转码”，直发无需此项。远程视频仅需重新封装时，可选择“原画”保留视频；主动降到低于源尺寸的 1080p/720p 会进行视频转码。

普通 HLS 播放按需要提前生成一段内容，缓冲足够时暂停生成，继续播放后恢复；明确点击预缓存或预转码则表示要在后台生成整片，关闭播放器不会取消该任务。同一产物可由多个播放器共享，退出其中一个不影响其他设备。

完成的完整缓存也可用于续播和跳转，但缓存方案须与实际画质、编码和烧录字幕设置一致。缓存尚未完成、方案不同或缓存已淘汰时，仍可能重新读取片源。播放缓存受 24 小时保存期限和容量维护约束，正在使用的缓存受保护，可能暂时超过配置的软限额；它不是永久离线下载。播放缓存与进度缩略图分开统计、分开清理，缩略图不随播放缓存的 24 小时期限删除。续播操作见[续播与从头开始](playback-controls.md#完成后检查)。

### 外部播放与诊断

“更多选项 → 复制播放直链”得到原文件地址，可交给 VLC/Kodi 等播放器；外部设备需能访问 jzmedia 并自行支持该格式，浏览器中的倍速、字幕样式/延迟不会带过去。播放问题可用“复制诊断信息”；分享前检查路径和环境信息。

## 完成后检查

进度条显示已经生成的采样图；预缓存完成后，以相同播放方案从头播放、续播或跳转均可复用完整缓存。

## 常见问题

缩略图不是逐帧预览。新入库视频在夜间自动生成；旧片可加入本地库闲时队列，急需预览的片源可立即生成。进度缩略图可在“设置 → 系统维护”先检查可清理空间，再确认清理；播放缓存另有清理入口。无兼容基底的杜比视界暂不生成缩略图。
