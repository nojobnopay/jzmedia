# 新手配置向导

[用户手册](README.md) · [安装与首次使用](../getting-started/deployment.md)

首次打开尚无电影或分集的安装，首页会展示欢迎卡片。点击“开始配置”进入 `/setup`。已有内容的安装不会自动提示；“设置 → 新手配置”始终可以打开向导。

## 跟随四步完成首次入库

| 步骤 | 操作与结果 |
|---|---|
| 资料来源 | 粘贴自己的 TMDB Read Token，点击“保存并测试 TMDB 连接”。也可选择“稍后配置 TMDB”，继续使用已有 NFO、本地缓存及启用的备用来源。 |
| 视频库 | 选择电影或剧集，确认已有库，或添加本地／SMB／NFS 存储和视频库。点击“检查并使用此视频库”验证目录。 |
| 添加内容 | 文件已在服务器／NAS 上时选扫描；文件在当前电脑上时选上传。目标始终是上一步确认的视频库。 |
| 查看结果 | 核对已登记的内容、待匹配项及上传失败数；打开详情核对资料或播放，点击“完成引导”。 |

TMDB 读取令牌位于账户的 API 设置中，界面提供[官方获取说明](https://developer.themoviedb.org/docs/authentication-application)。Read Token 优先于 API Key。测试使用服务器的网络和代理，直接验证 TMDB 凭据与 API；不走备用资料搜索，也不验证图片下载。无法连通时可明确跳过，之后到“设置 → 资料来源”补配。

应用首次启动可能已创建默认电影库。默认库并不表示目录已确认，仍需检查。若其根目录混有电影和剧集，应将空默认库改为独立子目录，再添加另一个视频库；同一存储下的视频库目录不能互相嵌套。已有内容的库不能直接改变类型。本地路径填写应用进程可见的位置，例如 Docker 的 `/media`，而不是浏览器所在电脑的目录。

一次引导确认一个电影库或剧集库，完成后可“继续添加另一视频库”。本地可写库会按需创建视频子目录；远程子目录需要预先存在。只读库可以扫描和播放，上传需要写入权限。命名档、资料落盘等选项在创建表单的折叠区；默认沿用通用命名和 NFO，扫描可能写资料文件。

电影可上传多个文件或整个文件夹；剧集默认上传包含剧名的完整文件夹，也可以指定所属剧与季号上传散集。同名文件跳过不覆盖。仅传入字幕、花絮或无法识别集号的文件，不会被算作完成首次导入。部分内容入库、部分失败时可以结束引导，但请核对失败提示并按需重试。

## 暂缓与恢复

“稍后继续”或“稍后导入”保留已保存的配置和内容，并停止自动欢迎提醒；下次从设置页继续。直接离开未完成的向导，首页会显示“继续配置”。进度保存在服务器数据库，同一安装的浏览器共享，不是按用户独立保存。

扫描是后台任务，离开页面后仍会运行，返回可查看状态。上传依赖当前浏览器，进行中需要先取消才能离开；刷新或关闭浏览器后需重新选择文件，已传完的同名文件再次上传会跳过。若传输结束但没有登记内容，可扫描目标视频库确认。

返回时向导会核对目标库是否仍存在、启用和保持原类型；配置被修改时需重新检查。服务重启后任务详情可能不再保留，但已入库记录和引导进度仍在。

“已入库”不等于“资料已匹配”。未匹配、待确认或资料不完整的内容可以进入详情继续处理，播放也从详情页进入。目录整理不属于首次配置必做项，需另行预览与确认；向导不会自动移动或改名媒体文件。
