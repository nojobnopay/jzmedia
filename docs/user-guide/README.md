# 详细用户手册

面向已安装 jzmedia、需要管理复杂影视库的用户。各章从界面入口写起，说明操作、结果和限制。媒体库是存储连接，视频库是其下按电影或剧集划分的目录；顶栏按媒体库浏览，设置页工具按视频库工作。

| 章节 | 适合查找的问题 |
|---|---|
| [媒体库与视频库](libraries.md) | 建库、连接 NAS、只读和落盘策略 |
| [电影、合集与人物](movies.md) | 搜索筛选、评分标签、多版本、合集、海报 |
| [剧、季、集](tv.md) | 连播、观看状态、集号匹配和本地集 |
| [扫描与元数据](metadata.md) | 扫描、手动纠错、NFO、来源链 |
| [播放器](player.md) | 倍速、预览、画质、音轨、字幕、续播 |
| [整理与撤销](organizing.md) | 电影归档、剧集目录规范化、撤销 |
| [文件与上传](files.md) | 文件浏览、复制移动、上传与删除 |
| [设置与维护](settings.md) | 全局设置、视频库工具、维护任务 |
| [功能排障](troubleshooting.md) | 对照症状排查问题 |

建议的完整流程：连接媒体库 → 添加电影/剧集视频库 → 扫描 → 核对未匹配和待确认 → 试播 → 整理预览 → 确认执行。单纯观看不要求先整理目录。

“预览”只列操作；“确认执行”才改文件。取消后台任务通常只阻止后续步骤，已完成项不会自动回滚。删媒体库记录、清理失效记录和删除物理文件是三种不同操作。部署和备份见 [入门教程](../getting-started/README.md)。[返回文档导航](../README.md)。
