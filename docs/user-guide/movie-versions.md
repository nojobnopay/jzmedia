# 选择电影版本与相关文件

目标：打开正确版本，接着上次的位置观看，找到对应文件。

## 准备

电影已经登记。多个文件只有在**同一视频库内，且都绑定相同、非空的 TMDB ID** 时，才会聚合为同片的多个版本。文件同名或加上 `-V2` 后缀不能单独触发合并；不同视频库的文件仍各自展示。

## 操作步骤

1. 点击海报进入详情，核对片名和简介。同片多个实际文件会作为版本展示，先选择需要观看的版本。
2. 点击播放或继续观看；缺失或不可读文件会提示。各文件维护独立断点，播放前注意所选版本。
3. 需要下载、上传或管理文件时，打开“文件与版本”。对应版本行的“更多 → 复制直链”可用于外部播放器。

可在“更多操作 → 编辑资料”中填写版本（edition）、规格/备注（spec），例如“导演剪辑版”“蓝光”；版本选择器和“文件与版本”会显示实际文件名及这些备注。修改备注不自动改文件名，也不改变聚合关系。

### 查看详情资料

首屏展示独立横版背景、评分、简介和播放入口，长简介可展开。“影片资料”展示演职员与“库中类似”；演员/导演可点进人物页。人物作品与相似推荐都限于当前媒体库，不会替你下载其他影片。

手机详情将小海报与片名、评分及基本资料并排显示，播放和维护入口紧接标题区，简介在其后按需展开；演职员可横向滑动查看。未匹配影片先显示“匹配资料”入口，点击后再搜索与核对候选。

### 多版本的断点与已看状态

例如，同一视频库中的 `阿凡达 (2009).mp4` 与 `阿凡达 (2009)-V2.mp4` 都匹配到同一 TMDB 作品后，会在版本选择器中按各自文件名展示；填过版本、规格备注时，还会显示对应备注。看完前一个文件的一半退出，断点只记在该文件上，另一个文件仍从头开始。播放时先选版本，选错版本续播位置不对时切回正确文件即可。

“已看”标记按同片共享：手动标记或正常播放达到[完成阈值](playback-controls.md#完成后检查)时，同片各版本都会标为已看。各版本的断点仍独立；文件管理中的预览不保存断点，也不改变已看标记。

## 完成后检查

确认播放器所选版本、断点与文件一致。

## 常见问题

- **没有合并成多个版本：** 确认文件已扫描登记、位于同一视频库，并分别核对其 TMDB 匹配；未匹配或匹配到不同作品时，按[重新匹配](metadata.md#案例二发现匹配错了)修正后重新打开详情。
- **版本文件缺失或不可读：** 先检查连接和实际路径，不要直接删除记录。每个文件独立保存断点；版本备注不会自动重命名文件。
