# 播放、续播与调整画质

目标：控制播放进度和速度，选出适合当前网络与设备的画质。

## 准备

从电影详情选择版本，或从剧、季、集详情打开播放。

## 操作步骤

<DocFigure src="../assets/screenshots/player-settings.webp" alt="播放器画面右上角工具与展开的播放设置" caption="使用文件预览中的合成视频演示控件：倍速、音量和字幕有独立快捷入口，画质与高级选项从画面右上角齿轮进入；此预览不记录观看进度。" />

进度条单独一行，显示已播和缓冲范围。底栏提供播放、快退 10 秒、快进 10 秒、音量、倍速和“字幕与音轨”六个控件；手机将时间单独显示，并保留至少 44px 的触摸区域。画面右上角提供设置、投屏和全屏，窗口与全屏的位置一致。

窗口态的画外底栏保持可见，播放时右上工具约 3 秒无操作后淡出；全屏时上下控件一起淡出。轻点画面、桌面移动鼠标或操作键盘可重新显示，暂停、菜单打开、键盘聚焦、错误或投屏控制期间保持可见。手机控件隐藏时，轻点画面只唤出控件；控件可见时单击画面播放/暂停，双击画面切换全屏。

| 按键 | 操作 |
|---|---|
| 空格 | 播放/暂停；当前聚焦按钮、下拉框等控件时保留控件自身行为 |
| ← / → | 快退/快进 10 秒；输入/选择控件中不抢按键 |
| ↑ / ↓ | 音量增减 |
| Esc | 先关打开的快捷菜单或设置；全屏时由浏览器退出全屏，窗口态可关播放器 |
| Tab / Shift+Tab | 切换播放器控件，键盘聚焦时全屏控件保持可见 |

浏览器阻止自动带声播放时，点画面中央的播放按钮。等待期有加载提示，失败时可从错误卡片重试。

### 调整音量

点击底栏音量图标，向上展开音量面板；桌面也可将鼠标悬停在图标上打开。向上拖动竖向滑条增大音量，向下减小，面板显示当前百分比。静音使用面板内的独立按钮；再次点击可恢复声音。

点击面板外或按 Esc 收起，调节期间播放控件保持可见。浏览器不允许网页调节音量时，面板提示使用设备音量键，仍可通过静音按钮开关声音。

### 选择倍速与画质

点击底栏的 `1×` 等倍速按钮，在短菜单中选择 0.5、0.75、1、1.25、1.5、2 倍。选择保存在当前浏览器，切档、续播和连播保持；播放器尽量保持音调。2 倍播放会更快消耗缓存，网络或转码速度不够仍会缓冲。

画质从画面右上角齿轮的“播放设置”中选择：

| 画质 | 含义 |
|---|---|
| 自动 | 需要视频重编且源高于 1080p 时，软件通常封顶 720p、硬件封顶 1080p |
| 原画 | 不施加自动分辨率上限；源格式不兼容时仍可能转码 |
| 1080p / 720p | 请求相应输出档位，减轻解码或网络负担 |

| 画质选择 | 可能的实际输出 |
|---|---|
| 自动/原画 + 浏览器可直放 | 原文件直发（direct） |
| 无需降分辨率，仅容器或音轨不兼容 | 重新封装（remux）或音频转码，视频保持原样 |
| 1080p/720p + 源分辨率高于所选档位 | 视频转码到所选上限，即使浏览器原本可以直放 |
| 源视频不兼容或字幕需要烧录 | 视频转码；自动按服务器能力封顶，原画按源尺寸编 |

选择高于源分辨率的档位不会放大视频。例如 720p 片源选择 1080p，实际输出仍不高于 720p。

Dolby Vision P5 的网页播放需要服务器专用硬件色彩转换，自动画质默认最多 720p；维护者验证服务器性能后可启用 1080p。自动档 1080p 持续处理不足且缓冲偏低时，会保留进度、音轨、字幕与倍速，降至 720p 一次。仍无法流畅处理或颜色信息不完整时，播放器停止并提供“复制直链”和已有兼容版本入口；可交给支持该片源的外部播放器。显式选择原画不能保证实时转码。

到“更多选项 → 播放信息”看实际输出与原因。切档可能重开会话、等待新分片，请等待加载完成。HDR 或杜比视界片源是否能原画播放，取决于片源、浏览器和服务器；颜色不正常时可尝试外部播放器。4K 直通持续掉帧时会弹出切换 1080p 的询问；取消或 10 秒不处理会保持原画，不自动记忆降档选择。

### 手机观看

手机窗口态暂停时，画面播放按钮略向下调整并避开右上工具与字幕；画面空间不足时可直接使用底栏播放按钮。

竖屏点全屏后，支持屏幕方向锁定的浏览器会尝试切到横屏；退出全屏时解除方向锁定。浏览器不支持锁定时会提示“旋转设备以横屏观看”。未自动转向时，可手动旋转设备，并检查系统的方向锁定设置。

### 投屏到电视

手机网页提供“电视内置投屏”和“jzmedia-tv App”两种接收方式，也可在桌面浏览器使用。手机、电视和 jzmedia 服务器应处于可互通的局域网；手机无需安装应用。

电视内置投屏使用 **DLNA 视频接收**，先开启电视的接收服务。设备由服务器搜索，搜索范围是服务器所在网络。Linux／NAS 部署需要自动发现时建议使用 [host 网络](../getting-started/deployment.md#host-network)；bridge 可能阻断组播搜索，但不代表已知设备无法控制或取流，可手动添加。

1. 打开电影或某一集的播放器，点击画面右上角的投屏图标。全屏时设备面板直接在全屏内打开。
2. 等待搜索完成，选择电视。搜索不到时可点击“重新搜索”，或在“手动添加电视”填写该电视的完整 DLNA 描述地址（例如 `http://192.168.1.20:49152/description.xml`），点击“添加电视”。单填 IP 地址不够；描述地址中的端口可能在电视重启后变化。网络配置排查见[投屏网络](../getting-started/deployment.md#dlna-投屏网络)。
3. 核对“电视可访问的服务器地址”。通常可沿用自动填写的地址；通过模拟器、端口转发或反向代理访问时，改为电视可访问的局域网 IP 和端口，例如 `http://192.168.1.10:8080`。
4. 点击“开始投屏”，手机先暂停并保留点击时的播放位置，再请求电视从该处续播。检查电视是否出现画面和声音；面板仍在等待电视或恢复进度时，起播尚未确认。明确发起失败后会恢复手机原先的播放状态与位置；请求超时或结果无法确认时，先查询电视状态。仍无法确认则保持手机暂停，可点击“重新检查投屏状态”，避免两端同时播放。

手动添加由服务器连接并验证电视，只在本次服务器运行期间保留；重启 jzmedia 后需重新添加。它可以绕过组播搜索，但服务器仍须能连接电视，电视也须能访问第 3 步填写的媒体地址。

内置投屏由电视解码。手机选择多音轨片源中的某条音轨时，NAS 会先准备只含所选音轨的完整 MP4：视频保持原样，声音转换为 AAC 双声道，不附带字幕。首次需等待整片处理，面板显示准备状态并允许取消；关闭手机页面仍会继续准备，完成后自动播放。它会占用播放缓存和一个处理名额，已有完整缓存可以复用。不能安全处理的片源会提示改用电视 App；只有一条音轨时仍直接发送原文件。

手机能播放，不代表电视内置接收器能解码同一文件。电视已有反应但长时间不出画面、格式不兼容、无声，或需要所选字幕时，推荐使用已安装的 jzmedia-tv：

1. 将服务端和电视 APK 均升级至 0.31.0 或更新版本。在目标电视打开 jzmedia-tv，连接与手机相同的服务器，并保持 App 在前台。
2. 手机投屏面板切到“jzmedia-tv App”，选择出现的电视。尚未出现时核对服务器地址并升级电视 App；不会自动选择其他电视。
3. 确认面板中的音轨、字幕选择，点击“在电视 App 播放”。App 自动打开该影片，从手机点击时的位置续播；若从正在播放的内置投屏切换，则先停止它并保留电视位置。

App 使用自身的播放能力与 NAS 播放决策，接收当前音轨及服务器字幕选择。文本字幕由 App 渲染；内嵌图片字幕仅在原文件直放且能准确匹配原生轨道时显示，否则关闭该字幕并提示，不自动烧录。手机临时加载的本地字幕不会上传给电视，需在 App 另选可用字幕。两端的观看模式都必须允许播放该内容，手机不会代替电视解锁。此入口不能唤醒后台或未打开的 App。

网页画质和倍速不随投屏传递。文件预览和花絮没有投屏入口。

通过“投屏控制”播放、暂停或停止，也可前后跳转 10 秒。拖动进度条选择位置，松开后请求电视跳转；已有进度缩略图时可查看对应画面，没有时仍可根据时间跳转。电视提供音量控制时，拖动音量滑条并松开即可设置；未上报的音量会明确显示为未知，不支持的能力可改用电视遥控器。

开始投屏后，服务器会等待电视准备好，再请求恢复手机位置并核对电视回报。恢复期间显示“正在接续到”及目标时间，暂时不可跳转或切换播放／暂停，仍可停止投屏或返回手机；电视不支持跳转或未能确认恢复时会提示可能从头播放，以电视实际画面和上报进度为准。

关闭投屏面板、播放器或手机页面，电视会继续播放。App 接收时需保持 jzmedia-tv 在电视前台；按电视 Home、退出 App 或断连会结束该接收会话。隐私模式退出或锁定会撤销该模式的播放权限，并停止对应投屏；切换观看模式前也会结束当前播放。有效的持续播放不会触发隐私模式的 15 分钟闲置锁定，暂停或停止后恢复闲置计时。模式与密码说明见[儿童模式与隐私模式](settings.md#儿童模式与隐私模式)。

服务器依据电视实际上报的进度记录断点；电视不报位置时显示“电视未上报进度”，不会推算进度。重新打开相同影片可回到投屏控制。“结束投屏，手机播放”先停止电视，再从最近已知位置在手机播放；尚在恢复且电视没有有效位置时，保留手机发起投屏时的位置。停止失败时保留电视控制，避免两端同时播放。当前不提供投屏自动连播，观看下一集时需自行选择该集。

#### 用安卓模拟器测试

雷电、MuMu、夜神等桌面模拟器可以测试手机网页和接口联调。安装新版 jzmedia-tv 并连接服务器后，可测试“jzmedia-tv App”接收入口；这不会使模拟器成为 DLNA 接收设备。测试电视内置投屏仍需要 DLNA 接收器。

接收端联调还需确认模拟器网络能被服务器访问，并能返回 SSDP 组播搜索。虚拟 NAT、访客网络或防火墙可能阻挡发现；根据模拟器版本检查桥接网络配置。先在接收端访问服务器局域网地址，再从手机面板搜索和播放。模拟器通过仍需真实电视检查发现、声音、解码、字幕和长时间播放。

## 完成后检查

看“更多选项 → 播放信息”确认实际输出，而不只看所选画质。有有效断点时自动续播，并提供继续观看／从头开始提示；约 10 秒未选择、进入全屏或手动跳转进度后，提示会收起。

播放达到总时长的 95%，或已看至少 80% 且剩余不超过 5 分钟，会被视为已看完，不再作为未完成断点显示。例如 10 分钟短片不会仅因进入最后 5 分钟就算看完，至少需看到 8 分钟。剧集自动连播仍等当前视频真正播放结束；手动跳到片尾前或自动标记已看都不会提前切集。

## 常见问题

播放等待时有加载提示，失败可重试；浏览器阻止自动出声时点中央播放键。4K 持续掉帧提示降到 1080p 时可选择切换；取消或 10 秒无操作保持原画。
