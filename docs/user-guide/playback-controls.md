# 播放、续播与调整画质

目标：控制播放进度和速度，选出适合当前网络与设备的画质。

## 准备

从电影详情选择版本，或从剧、季、集详情打开播放。

## 操作步骤

<DocFigure src="../assets/screenshots/player-settings.webp" alt="播放器底部控制键与展开的设置面板" caption="点击底部齿轮调整设置；播放信息显示实际输出。" />

进度条单独一行，显示已播和缓冲范围。下排左侧为播放、±10 秒、静音/音量和时间；右侧为倍速、设置、全屏。移动端缩小控件，窄屏可能只显示当前时间。单击画面播放/暂停，双击画面切换全屏；全屏控件闲置自动隐藏，暂停、跳转、设置打开或有错误时常显。

| 按键 | 操作 |
|---|---|
| 空格 | 播放/暂停；当前聚焦按钮、下拉框等控件时保留控件自身行为 |
| ← / → | 快退/快进 10 秒；输入/选择控件中不抢按键 |
| ↑ / ↓ | 音量增减 |
| Esc | 先关设置；全屏时由浏览器退出全屏，窗口态可关播放器 |
| Tab / Shift+Tab | 切换播放器控件，键盘聚焦时全屏控件保持可见 |

浏览器阻止自动带声播放时，点画面中央的播放按钮。等待期有加载提示，失败时可从错误卡片重试。

### 选择倍速与画质

点倍速或齿轮，在“播放速度”选择 0.5、0.75、1、1.25、1.5、2 倍。选择保存在当前浏览器，切档、续播和连播保持；播放器尽量保持音调。2 倍播放会更快消耗缓存，网络或转码速度不够仍会缓冲。

| 画质 | 含义 |
|---|---|
| 自动 | 需要视频重编且源高于 1080p 时，软件通常封顶 720p、硬件封顶 1080p |
| 原画 | 不施加自动分辨率上限；源格式不兼容时仍可能转码 |
| 1080p / 720p | 请求相应输出档位，减轻解码或网络负担 |

| 画质选择 | 可能的实际输出 |
|---|---|
| 任意档 + 浏览器可直放 | 原文件直发（direct） |
| 任意档 + 容器/音轨不兼容 | 重新封装（remux）或音频转码 |
| 自动/降档 + 需重编 | 按档位上限输出；原画则按源尺寸编 |

到“更多选项 → 播放信息”看实际输出与原因。切档可能重开会话、等待新分片，请等待加载完成。HDR 或杜比视界片源是否能原画播放，取决于片源、浏览器和服务器；颜色不正常时可尝试外部播放器。4K 直通持续掉帧时会弹出切换 1080p 的询问；取消或 10 秒不处理会保持原画，不自动记忆降档选择。

## 完成后检查

看“更多选项 → 播放信息”确认实际输出，而不只看所选画质。存在断点时可继续观看或从头开始；提示约 10 秒自动收起，接近结尾的断点可能被视作已看完。

## 常见问题

播放等待时有加载提示，失败可重试；浏览器阻止自动出声时点中央播放键。4K 持续掉帧提示降到 1080p 时可选择切换；取消或 10 秒无操作保持原画。
