# 播放器

[用户手册](README.md)

电影详情先选文件版本再播放；剧/季/集页播放对应集；花絮从所属详情进入。播放器按客户端实际能力决定直发、换容器、只转音频或视频转码，画质选择不等于固定播放方式。

## 控件与快捷键

进度条单独一行，显示已播和缓冲范围。下排左侧为播放、±10 秒、静音/音量和时间；右侧为倍速、设置、全屏。移动端缩小控件，窄屏可能只显示当前时间。单击画面播放/暂停，双击画面切换全屏；全屏控件闲置自动隐藏，暂停、跳转、设置打开或有错误时常显。

| 按键 | 操作 |
|---|---|
| 空格 | 播放/暂停；当前聚焦按钮、下拉框等控件时保留控件自身行为 |
| ← / → | 快退/快进 10 秒；输入/选择控件中不抢按键 |
| ↑ / ↓ | 音量增减 |
| Esc | 先关设置；全屏时由浏览器退出全屏，窗口态可关播放器 |
| Tab / Shift+Tab | 切换播放器控件，键盘聚焦时全屏控件保持可见 |

浏览器阻止自动带声播放时，点画面中央的播放按钮。等待期有加载提示，失败时可从错误卡片重试。

## 倍速和画质

点倍速或齿轮，在“播放速度”选择 0.5、0.75、1、1.25、1.5、2 倍。选择保存在当前浏览器，切档、续播和连播保持；播放器尽量保持音调。2 倍播放会更快消耗缓存，网络或转码速度不够仍会缓冲。

| 画质 | 含义 |
|---|---|
| 自动 | 需要视频重编且源高于 1080p 时，软件通常封顶 720p、硬件封顶 1080p |
| 原画 | 不施加自动分辨率上限；源格式不兼容时仍可能转码 |
| 1080p / 720p | 请求相应输出档位，减轻解码或网络负担 |

到“更多选项 → 播放信息”看实际输出与原因。切档可能重开会话、等待新分片，目前不是无缝 ABR 切档。HDR/DV 是否能原画直通取决于兼容基底、浏览器和硬件；DV P5 等无兼容基底的片源通常不能原画直通。4K 直通持续掉帧时会弹出切换 1080p 的询问；取消或 10 秒不处理会保持原画，不自动记忆降档选择。

## 快进与缩略图

鼠标悬停进度条会显示目标时间，已有预览图时显示附近采样节点。拖动时只更新预览，松手后跳转；触屏同样可拖动。连续按方向键会合并目标。缓冲或已产出片段范围内尽量直接定位，超出时可能要重新建立 HLS 会话。

首次使用：打开齿轮 → “更多选项 → 进度缩略图 → 生成预览”。任务会逐页生成，已有页可先用；可取消并继续。查看进度条本身不会自动启动抽帧。视频库的维护面板还可批量生成。默认本地每 10 秒、SMB/NFS 每 20 秒取一帧，不是逐帧预览。远程生成会读 NAS，建议空闲运行；批量任务遇在线转码会等待。图片有独立缓存限额，源文件变化或缓存淘汰后需重新生成。无兼容基底的 Dolby Vision 暂不生成预览。

## 音轨

多音轨时设置面板显示“音轨”。默认 fMP4 HLS 通过音轨 rendition 切换，一般不重开会话。原文件直发只支持默认音轨；选择非默认音轨而浏览器无原生 HLS 能力时，可能自动改为 remux。EAC3/AC3 等在 hls.js 环境下默认不直接复制，改走 AAC 转码，以避免无声；服务端放开 `AUDIO_COPY_SAFE` 之前应实测目标设备。

## 字幕

设置中可选内嵌/自动识别的外挂字幕或关闭字幕；已经压在视频画面里的“硬字幕”不能关闭。

| 来源/格式 | 处理方式 | 主要可调项 |
|---|---|---|
| SRT/VTT 等文本 | 自绘文本层，失败时尝试原生回退 | 延迟、背景、描边、字号和位置 |
| ASS/SSA | 浏览器端 JASSUB 渲染，尽量保留样式 | 延迟、兼容模式 |
| PGS | 浏览器端图片字幕，异常时可降级烧录 | 延迟 |
| VobSub/烧录降级 | 视频重编，字幕写入画面 | 切换时可能等待新会话 |

“字幕调整”中每次移动 0.5 秒；正值使字幕延后，负值提前，按版本记住。文本字幕“自动位置”在下黑边足够高时优先放黑边，否则在画面内。自绘文本字幕在浏览器画中画中不显示。ASS 缺中文字形时，可在数据目录 `fonts/` 投放有权使用的中文字体，或启用简化 VTT 兼容模式；后者会丢失 ASS 样式。

点击“加载字幕文件”可临时选 SRT/VTT/ASS/SSA，浏览器端解析，仅本次播放有效；换档、seek 仍保留，关闭播放器即失效，不写库。永久外挂文件放影片旁或一层 `subs/`、`字幕/` 目录，以同茎或可识别标题/语言后缀命名；重新打开后检查是否识别。

## 续播与预缓存

有有效断点时播放器自动续播，并给出继续观看/从头开始提示；约 10 秒未选自动消条，全屏或手动 seek 也会结束该提示。接近结尾的断点可能被视作已看完。详情页在“预缓存与转码”折叠区内，对适用的远程 remux/音频转码版本显示“预缓存到服务器”，把从 0 开始的播放结果缓存为静态成品；直发无需此项。缓存方案要与实际画质和烧录设置一致，受 24 小时 TTL 与总量限额约束，不是永久离线下载。

## 外部播放与诊断

“更多选项 → 复制播放直链”得到原文件地址，可交给 VLC/Kodi 等播放器；外部设备需能访问 jzmedia 并自行支持该格式，浏览器中的倍速、字幕样式/延迟不会带过去。播放问题可用“复制诊断信息”；分享前检查路径和环境信息。[播放排障](troubleshooting.md)。
