# 界面规范与验收

jzmedia 使用深色影音界面：海报与背景图承载内容，红色表示主要操作，中性灰组织管理工具。电影、剧集、合集共享浏览模式；设置和文件管理采用紧凑密度。统一的是同类控件、状态和操作语义，不要求所有页面使用同样的信息密度。

## 设计源与需求登记

仓库根目录 `design/` 是功能图标、品牌、语义颜色和跨端规格的唯一设计源。SVG 母版使用稳定语义 ID；图形修订、来源、光学校正版、替代关系及导出规格记录在资产清单中。Web 与 Android 的生成代码和品牌导出物随源码提交，不能直接修改。各端正常构建消费已提交产物，不需要设计工具或另一端的工具链。

需求记录与资产定义分开：每项使用需求关联实际功能、页面/组件、平台、操作含义、资产、尺寸、交互状态与可访问名称。设计网格、Web CSS px、Android dp、触摸区域和位图像素必须分别填写；电视的 1080p/4K 是目标显示环境，不是两套矢量母版。专用原生控件、动态图标和保留的文本表达也要登记，不能只清点普通按钮。

功能图标使用 24×24 网格、1.7 线宽、圆端点与连接。播放和评分等填充图形在清单中明确标记。SVG 使用路径、填充和描边，固定数字转路径；不依赖字体、外链或运行时几何变换。品牌采用 A「点映」（修订 3，2026-10-04）：红底与白色 J/播放一体轮廓，J 顶部向左延伸为片架横梁以平衡左上留白；16/32px 图标为关联的光学校正版，SVG favicon 同样使用 16px 版。图鉴按 16–48 CSS px 原尺寸、深浅背景核对，字标按 23/32px 核对；品牌字标的轮廓和来源在设计目录管理。

新增或改款流程：登记需求 → 修改母版/语义令牌 → 生成各端产物 → 检查同步 → 在隔离组件图鉴和实际页面验证。详细生成命令、依赖及清单结构见仓库 `design/README.md`。需求和来源可在组件图鉴中搜索，不增加面向普通用户的设计管理入口。

当前主题继续使用深色与红色强调。颜色通过语义令牌引用，主题与平台规格独立；本次没有新增应用主题切换。后续主题复用稳定的操作 ID，仅调整令牌或明确登记的图形变体。

## 样式的职责

- `frontend/src/styles/tokens.css`：载入由设计源生成的表面、文字、边框、状态色、字号、间距、圆角、控件高度和浮层层级，保留响应式规则。基本色为背景 `#141414`、表面 `#1c1c1c`、较高表面 `#262626`、正文 `#eee`、辅助文字 `#aaa`、主操作 `#e50914`。
- `styles/base.css`：原生表单、全局焦点、主导航、海报播放入口和已有共享卡片。基础选择器保持低权重；导航外观仅作用于 `.app-nav`，不能影响页内标签或面包屑。
- `JzButton`、`JzField`、`JzDialog`、`AppIcon`：控件的外观与行为。跨页面和 Teleport 到 body 后保持同样表现。
- `browse.css`、`mediaPages.css`、`settings.css`、`setup.css`、`online.css`：各类页面布局。组件 scoped 样式只管理自身结构和业务特例。

中文使用本地 PingFang SC / Microsoft YaHei，系统字体作为后备，不依赖外部字体下载。正文与辅助文字区分字号、明度；标题有明确层级，路径和长标题允许换行。圆角按控件、卡片、弹窗区分。常规控件 40px、管理页紧凑控件 36px、手机与触摸控件至少 44px；海报勾选标记等专门交互沿用自身规则。

## 主导航与跨端图标

导航沿用背景 `#141414`、表面 `#1c1c1c` / `#262626`、正文 `#eee`、辅助文字 `#aaa` 与强调色 `#e50914`。图标统一使用 24×24 视框、1.7 线宽、圆角端点与连接，颜色跟随文字；电影用胶片、剧集用屏幕、合集用叠放卡片、媒体库用书架、设置用齿轮、搜索用放大镜。Web 复用 `AppIcon`，电视用原生向量绘制相同路径，避免依赖字体符号或表情。

电视导航保持单行：搜索 → 首页 → 电影 → 电视剧 → 合集；支持在线能力的服务端在合集后显示“在线”，儿童模式隐藏。媒体库与设置靠右。搜索的图标和短标签常驻，品牌不占据搜索前的位置。普通项减轻底色，当前频道使用中性底色与红色短指示条，遥控器焦点使用白底深色图文；两种状态可同时辨认。方向键只移动焦点，确定键才进入页面。保持现有安全区，给聚焦缩放预留空间；长媒体库名称单行省略，完整名称保留在可访问语义中。详情继承实际来源频道，避免从搜索进入详情后误标成电影频道。

Web 保留现有浏览页和页内搜索，桌面将电影、剧集、合集和在线作为主要频道，媒体库、设置和帮助作为工具组。在线使用播放图标，儿童模式隐藏该频道；在线页面不带本地媒体库参数，也不显示媒体库切换。手机采用图标在上、文字在下的紧凑入口，媒体库选择单独一行；不超过 380px 时设置与帮助另起一行，为所有入口保留至少 44px 目标，不能为塞入图标而隐藏标签或缩小触摸区域。详情按所属频道保持选中，链接提供 `aria-current`；键盘焦点独立于选中状态，装饰图标不重复播报名称。

这次布局参考 [Netflix 电视新版的顶部入口](https://www.netflix.com/tudum/articles/netflix-new-tv-layout) 和 [Android TV 标签与焦点状态](https://developer.android.com/design/ui/tv/guides/components/tabs)（核对日期：2026-10-03）。搜索最左、工具靠右及沿用红色强调是 jzmedia 的具体设计选择，不把某一家应用的布局视为统一标准。

CSS 变量不能直接用于媒体查询条件；断点使用明确的 `700px` 等字面量，并在相应布局中维护。不要新增高权重祖先选择器来覆盖已有控件主题，应删除被新组件取代的旧声明。

## 组件约定

### JzButton

`variant="primary / secondary / danger / ghost"`，`size="default / compact"`；可设 `icon`、`iconOnly`。默认 `type="button"`，表单提交显式设 `type="submit"`。

`loading` 用统一加载图标替换动作图标，禁止重复点击并播报 busy。

`ref.el` 返回真实按钮，`ref.focus()` 用于恢复焦点。单一区域保留明确的主要操作。

### JzField

提供 `id`、`label`，可加 `hint` 或 `error`。插槽控件连接 `id`、`aria-describedby` 和 `aria-invalid`；组件不接管业务校验。

### JzDialog

提供标题或 `labelledby`；支持 `header`、内容和 `footer` 插槽。正文可滚动，操作放在常驻 footer。

`busy` 禁止关闭，`layer` 为 dialog / preview / auth；`presentation` 为 default / drawer / popover，共享同一个焦点陷阱。

保留业务二次确认，关闭后返回焦点。复杂播放器和文件预览保留专门生命周期，只复用视觉规则。

### AppIcon / PlayerIcon

使用同一份生成图标注册表；播放器保留尺寸及旧名称适配。`AppIcon.forward` 是右箭头，`PlayerIcon.forward` 是快进十秒，不得混用。纯图标按钮设置中文 `aria-label`。

### EmptyState

loading / error / empty / no-results；失败提供重试或明确下一步，首个请求完成前不能显示“没有内容”。

### BrowseToolbar

电影、剧集和在线共享搜索栏，通过 `filters` 插槽接入快捷筛选。搜索按钮位于输入框内，智能搜索是次要操作；请求、路由和播放业务留在页面。在线使用 `suggestionsEnabled=false`，输入框不声明联想列表或 combobox 语义，方向键与 Escape 保持普通输入行为。

`loading` 显示搜索按钮忙碌并阻止重复触发，`disabled` 禁用输入与搜索；`searchDisabled` 只停用搜索动作，输入仍可编辑。`inputId`、`maxlength` 可覆盖输入 ID 与长度，默认兼容已有页面。`embedded` 移除组件自身外边距，供来源选择与搜索组成工具栏时由外层安排间距。放入原生表单时由表单提交处理 Enter，并由页面检查是否可以提交，不再同时绑定 `enter` 发起相同请求。

### BrowseFilters / BrowseFilterSummary

类型、地区、年代、观看提供快捷面板，全部条件收进抽屉；手机保留类型、观看及全部筛选。面板使用独立草稿，应用才更新页面，关闭放弃草稿；已生效标签可单独移除，清空筛选保留搜索词。

### BrowseResultsHeader

统一结果标题、数量、排序及方向；电影关键词搜索时显示相关度说明，不能提供实际不生效的排序入口。

### 反馈、操作与触摸目标

错误反馈优先显示服务端提供的可读原因（字符串 `detail` 或 `message`），保留 HTTP 状态码供排查；长文本应截断并换行，不能撑破布局。失败、无结果与尚未加载必须明确区分。

导航、播放和常用工具使用图标加文字；保存、取消等普通表单动作可以只显示文字。不要为所有选项值、集号、键盘字符机械添加图标。按钮式链接保留链接语义，原生展开、树节点、海报覆盖播放和播放器控件保留专用结构，并遵循共享颜色、状态与焦点规则。

仅“扫描与整理”的页内工具切换在视口宽度不超过 `700px` 时采用紧凑显示：当前工具保留图标和文字，其他工具只显示图标，所有切换项保留完整中文可访问名称及至少 44×44 CSS px 的触摸区域。桌面所有工具保留图标与完整文字。“管理文件”保持独立动作，空间足够时共用一行，不足时换行。

扫描与整理的视频库选中态使用强调红色边框。同组纵向操作按钮应等宽，设置工具通过 `tool-action` 对齐，较长的清理操作使用 `tool-actions-wide`；宽度不超过容器，忙碌或确认文案切换时保持稳定，辅助按钮与进度提示按内容布局。

手机按钮至少提供 44×44 CSS px 的触摸区域。播放器在窄屏将时间单独排为一行，播放、前后跳转、音量、倍速与字幕/音轨六个底栏控件保持可用，设置、投屏和全屏放在画面右上角。视频与字幕继续根据实际控件预留高度定位。TV 使用平台 dp 和遥控器焦点规则，不能把网页触摸尺寸直接套到电视键盘上。

## 页面层级与响应式布局

### 播放器

标题栏以片名与关闭为主；设置、投屏、全屏使用画面右上角相邻白色图标，由一层共享的柔和顶部渐变承托。按钮默认透明，悬停、按下、键盘聚焦或展开时提供轻微底色，保留至少 44×44 CSS px 的点击区域。窗口与全屏保持同样的操作位置，退出全屏替换全屏图标，投屏状态提供可辨认反馈。文件预览沿用控件但没有投屏。

窗口态画外底栏保持可见，画内工具播放时约 3 秒无操作后与顶部渐变一起淡出；进入全屏先显示约 3 秒，上下控件与背景统一显隐。轻点画面、桌面移动鼠标和键盘操作重置显示计时，暂停、拖动进度、菜单打开、键盘聚焦、错误和投屏控制期间保持可见。手机首次轻点隐藏控件的画面只唤出控件，不同时暂停；隐藏的工具不可点击或聚焦。动画遵循减少动态效果偏好。

暂停按钮与提示文字分别定位，手机窗口态在右上工具与字幕之间略向下，桌面与全屏保持画面居中；空间不足时缩小到有效触摸尺寸或使用底栏播放，按钮的点击与双击单独处理并保护启动后的连续点击，避免误触画面。

底栏只放六个常用动作：播放、快退 10 秒、快进 10 秒、音量、倍速、字幕与音轨。手机不隐藏倍速或缩小触摸目标，进度和时间独立成行。倍速打开六档短菜单，轨道按钮打开音轨、字幕与本地字幕加载；画质、字幕延迟、外观、兼容与诊断保留在齿轮设置。

音量面板向上展开，使用竖向滑条、百分比和独立静音按钮；桌面悬停与点击都可打开，触屏点击打开。滑条热区保持可操作，受浏览器限制时显示系统音量键提示，不展示无法生效的调节入口。快捷面板与播放设置互斥，点击外部或 Escape 收起并恢复触发器焦点；打开、调节或键盘聚焦时控件保持可见。

全屏中的快捷菜单、播放设置和投屏设备面板必须位于全屏容器内；背景画面点击不能穿透面板触发播放或全屏。投屏时使用电视状态与控制，不能让手机倍速、音轨和字幕选项看似能调整电视。手机音量能力和真实接收端仍需分别验收。

投屏面板复用播放器进度条与已有缩略图，时间独立显示，音量以滑条调节；手机触摸区域至少 44×44 CSS px。电视未报位置时明确显示未知，禁用相对快进／快退；时长未知、正在恢复起点或请求忙碌时禁用进度提交。提交跳转后保留目标位置并标为待确认，电视实报位置单独显示；确认后恢复实报进度，失败或超时提供原因后恢复。关闭、换会话或进入忙碌状态时取消未提交的拖动，避免迟到操作控制另一段播放。

接收方式明确区分电视内置投屏与 jzmedia-tv App；方式与设备选择常驻，手动添加电视及服务器地址放入“连接设置与手动添加”，App 打开步骤放入“如何连接电视 App”折叠区。播放后以遥控器为主，其他说明按需展开。底部主要播放按钮独占一行、完整显示文案；正在搜索、未选择设备或所选字幕限制等禁用原因紧邻按钮，字幕限制注明所选字幕并提供切到 App 的入口。App 未打开／尚在查询／无设备／接口不支持分别说明，不自动选首台电视。格式或字幕不兼容时提供切到 App 的入口与打开步骤，保留当前进度，切换前确认旧接收器已停止；不能仅凭文件扩展名或单一编码断定电视不能播放。音轨整片准备使用有名称的原生 progress 区分已知比例和不确定状态，只有取消动作；App 等待确认与真实播放控件分开。面板显示即将传递的音轨／服务器字幕，手机临时字幕明确标为仅本机可用。

### 浏览与筛选

浏览页以片名、海报和播放入口为主。继续观看在桌面和手机都使用可横向滑动的紧凑卡片，显示标题与进度；筛选默认收起，已选条件仍可辨认。海报墙前统一显示结果数量与排序，不能让搜索、提示和按钮把第一排海报推离首屏。合集封面下分别显示名称与成员数量，手机使用两列。

电影和剧集的全部筛选在桌面使用右侧抽屉、手机使用全屏面板，正文滚动而重置与应用按钮常驻。类型、地区、年代、观看等分组显示已选摘要；长国家、年份及标签列表支持组内查找。选项数量标明“本库数量”，不冒充组合条件下的预估结果。

地区与具体国家互斥，切换模式清除另一组；年代与年份同时选择取交集并提示。评分来源和最低分属于同一组，剧集只提供实际支持的 TMDB、自评及连载状态。

路由或媒体库变化作废未应用草稿；返回海报墙恢复条件和位置，不自动重开抽屉。`browseFilters.js` 统一草稿复制、有效条件计数及标签移除。

### 详情与资料维护

在线海报墙先恢复已授权会话缓存，每 15 分钟仅检查当前可见页。后台检查不禁用海报、改变排列或抢焦点；发现变化在紧凑状态行显示“内容有更新 · 查看更新”，用户明确应用后保留锚点与焦点。检查失败保留旧墙并标明检查时间，不弹阻断对话框或循环重试。手动刷新只重试失败或缺失的图片，同路径成功海报不因集数备注更新而重新下载；权限或配置变化优先清除旧范围内容。

在线前台翻页、搜索或刷新保留旧墙时，在当前视口底部显示紧凑状态条，使用共享 `Spinner` 与操作文字，避让手机安全区；分页按钮按实际请求方向设置 `loading`。等待提示位于 busy 内容区外，使用非模态状态播报，不接管焦点、不阻止换源或离开页面；完成、失败、取消及权限清理均移除，打开弹窗或播放器时隐藏。后台检查、相关推荐、读取下一集和主机检查等局部状态使用较小的同款图标。初次目录、详情和记录读取使用 `OnlineSkeleton` 保留内容几何与一处可读状态；无来源、无结果和读取失败继续使用对应的 `EmptyState`，请求未完成前不显示空结果。

共享 `Spinner` 保留现有尺寸接口，由淡轨道与圆弧组成，约 200ms 后显示动画，减少短请求闪烁；减少动态效果偏好下使用静态图标。单张在线海报等待或重试时使用中性占位，不给每张卡片重复添加可见等待文字，最终失败或缺图时显示统一占位。在线播放器的起播、跳转和缓冲使用约 32px 圆环及一行准确状态，标题栏突出内容标题，全屏工具透明并由顶部渐变承托。播放中只有首帧后、未暂停且实际缺少可播放数据超过 300ms 才显示缓冲；恢复播放或进度推进、暂停、错误与关闭会清除反馈，等待期间控件保持可见。

在线页沿用电影墙的内容宽度、海报比例和卡片文字层级，进入后自动浏览当前来源的最近更新；来源分类来自实际目录，不用本地样例冒充推荐热度。搜索与来源选择组成紧凑工具栏，连接诊断在工具栏内默认折叠。目录浏览时在搜索下方显示最近 12 项继续观看，关键词搜索时收起；无记录隐藏横排，失败保留重试入口。横卡采用桌面约 280×112 CSS px、手机约 260×112 CSS px 的布局，海报为 64×96 CSS px，显示标题、集名、来源与进度；横向滚动区域不放会被裁切的更多菜单。

“我的记录”打开在线页内的独立视图，使用 `view=records` 与 `tab=continue|favorites|history`，每页 20 项。继续观看和历史使用海报信息卡，收藏使用竖版海报墙；详情与续播保持独立入口，取消收藏与清除记录收进“更多”。未知时长只显示已观看时间，完成项标为“已看完”，不可用来源保留记录及原因。横排和完整记录的请求、取消与分页状态各自独立，播放和记录变更后同步更新；清除末项后回到有效分页。详情返回保存来源、完整浏览条件、记录页签、分页、滚动和触发器焦点，跨来源或相关推荐不能覆盖最初返回目标；锁定或切换观看身份清理旧请求与返回目标。

封面只使用经过图片用途网络策略校验的同源路径，不让浏览器直接访问来源 URL。记录海报由服务端在成功详情读取时保存受控快照，读取记录时按当前配置重新生成图片入口；旧记录、缺图或失效快照使用占位，下次打开详情自然补全，不因读取历史逐条查询外部目录。线路和分集继续使用独立控件。来源管理复用设置分区、字段、按钮和离开草稿保护；新增来源默认勾选启用，基础连接提供直连或填写代理，按用途分别配置收进高级选项。查询尚未完成、无来源、无结果与请求失败分别展示，取消或换来源后不能显示旧请求结果。只有实际支持的播放项可用，不支持的项保留原因说明。

在线分类按来源父子关系组织为频道与具体分类，常用频道包含短剧；完整分类通过可查找的共享弹窗选择，窄屏不铺成长横向滚条。频道负责导航，综合条目不能冒充跨子类汇总；结果标题显示实际分类与已加载年份。年份仅在来源明确声明支持时出现，近年选项不冒充来源的完整枚举，其他年份可手动输入；关键词搜索清除分类和年份。切换失败时旧墙保留并提示，分页暂停直到重试成功，避免新条件使用旧总数。 分类树属于来源导航资料，筛选响应缺失或暂时为空时，保留同一来源、完整配置及观看范围内已取得的真实分类；非空新树替换旧树，换来源、配置或权限后清理。暖缓存及过期条目的导航恢复同样保留分类，不因恢复旧页而复活已删除的分类或过期条目。海报更新备注和详情资料按实际值呈现，展示分类不改变既有播放身份。

在线详情把海报、片名、来源资料和主要播放入口组织在紧凑头部，收藏作为次要操作；手机以小海报与标题并排，主要播放入口独占下一行。线路与选集合为同一区域，先于长简介和演员资料。详情、详情加载及错误状态隐藏上方浏览工具与记录区，但保留其条件和海报 DOM，返回恢复原位置。长简介复用实际溢出检测的展开控件，元资料按需展开，许可归因仍可访问。主要播放入口在观看记录读取期间保持忙碌，读取失败后仍可明确选集播放；可用的未完成记录按完整身份恢复原线路，用户主动换线后优先其选择，迟到状态不能把线路切回去。

在线详情发现未允许媒体主机时，在当前页面主动打开共享确认对话框；每个来源、内容、配置及观看范围在页面生命周期内只自动提醒一次，关闭后保留手动检查入口。仅已有管理权限或未启用保护时自动读取候选；验证由用户明确触发，认证对话框拥有焦点时暂停下层焦点陷阱。候选只展示精确域名，勾选后明确确认才写入，对本服务此来源生效；取消不写，保存忙碌时不能关闭。添加成功后刷新来源配置及当前详情，保留原线路、独立进度与浏览位置，不自动播放；保存成功与刷新失败须区分，不能用旧报告重复提交。返回、换片、来源或观看范围变化会作废候选及迟到回调。

在线长列表按来源原序每 50 个条目分组，一次最多渲染 50 个条目按钮；范围表示条目位置，不能用它改写番外等原始名称。正倒序只作用于显示副本，原始列表及同线连续播放顺序保持。当前播放和上次观看以完整身份标记，默认显示相应组但不抢焦点；明确定位才切组、滚动和聚焦，不触发播放。跨线定位须明确恢复该线路，换片、换线及身份变化会作废待执行定位。选择器有可访问标签，禁用项保留原因，窄屏操作目标至少 44px。

在线详情的相关内容放在选集之后，依次为“同系列其他季”“相关推荐”“名称相关”，使用可横向浏览的紧凑海报行与共享海报、按钮。其他季按明确季号排序，仅有明确季号时标出当前季；不得把无季号条目补成第一季。季关系注明根据片名与季号整理，同类推荐说明来自当前来源，低置信名称关联单列并说明可能并非同一系列。空分组隐藏，不借用本地评分或 TMDB 关系。海报点击只打开同一来源的稳定条目详情并更新路由身份，保留原海报墙条件与位置；不自动播放、合并收藏或进度，也不跨季连续播放。手机保留至少 44px 操作目标，横向海报行不得撑宽整页。

仅明确声明支持推荐的来源发起相关查询，详情与当前条目状态读取完成后才延迟启动独立请求。推荐的加载、暂缓、失败与重试只作用于推荐区域，不能挡住选集或改变播放器状态；部分查询失败时先展示可用卡片并明确提示，手动重试期间、失败或暂缓时保留同一内容的已有卡片，新的有效结果再替换。错误按固定代码区分超时、上游限流等原因，不显示上游原始正文或地址；不循环重试。播放前先取消推荐，换片、换来源、换线路、返回、离开页面或观看权限变化同样作废旧请求与迟到结果。临时会话验证中止推荐并清除其图片，保留当前详情和有效播放器；验证恢复后可重新查询，正在播放时不启动推荐。实际权限或身份变化清除推荐状态，不复用旧保护范围的结果。

电影、剧、季、集详情在手机上将小海报或剧照与标题并排，播放等主要操作先于简介。简介按实际溢出展开，季页分集使用剧照加文字的紧凑行；演员与类似影片可横向浏览。未匹配电影或整部剧先显示状态和“匹配资料”入口，点击后才展开原有搜索与建议表单。已有匹配的维护操作继续放在“更多操作”，不能因视觉改动自动触发匹配或资料写入。

### 设置与表单

设置页用一个分区标题和说明组织内容，作用范围紧邻标题：全部媒体库、选中的视频库或当前浏览器。分组标题保持 14px、600 字重；靠间距和明度区分层级，避免重复标题与多层边框。手机将“设置”、分类选择器和新手入口放在紧凑顶栏，让表单尽早出现。用户教程与引导采用同一导航名称，例如“在线资料服务”。

概览先呈现按视频库定位的待办，再显示电影/剧集统计、可展开的存储详情与快捷入口。媒体库连接用可展开条目显示连接、路径、状态与视频库，不以宽表格承载整套编辑表单。共享表单采用上置标签，桌面按字段关系分列，手机单列；可选配置折叠，主要保存操作与作用范围保持可见。TMDB 区分凭据、可选配置和保存/验证结果，“凭据已配置”不能冒充连接检查成功。AI 限额、超时及密钥移除收在可选配置，保留用途说明、用量与明确确认。

### 设置草稿与离开保护

需要显式保存的设置表单通过 `useSettingsDraft` 注册区块、修改状态、操作忙碌状态和放弃动作。`Settings.vue` 统一拦截区块/路由离开及刷新/关页；新表单应接入已有机制，避免各自弹出原生确认框。

`SettingsLeaveDialog` 默认聚焦“继续编辑”，Escape 保留草稿；保存或连接操作进行中不能通过放弃跳过。确认放弃后仍需等整条导航成功再清理，兼容文件变更等其他守卫。

共享表单在向导中没有此注册表时沿用原生命周期。同 ID 的数据刷新不能覆盖未保存字段，失败保存不能清草稿。即时保存的显示偏好、后台维护任务与临时测试输入不需要配置草稿提醒。回归入口为 `node scripts/smoke_settings_ui.mjs --drafts-only`。

### 新手向导

新手向导保留四步与当前步数，已完成步骤显示勾号；手机通过“添加方式”选择已有视频库、添加视频库或存储位置。第三步先明确目标，再选择扫描服务器文件或从当前设备上传；第四步将登记数量、匹配待办与详情入口分开。缩短说明不能省掉目录检查、写入权限或完成条件。

### 文件管理

文件管理区分“当前行”和“勾选项”：单击或方向键只定位，复选框区域或空格才改变勾选。浅灰底表示当前行，勾选色表示批量操作对象；预览不改变勾选。工具栏的复制、剪切、改名和删除操作勾选项，右键菜单显示自身操作对象，不能为操作另一文件而暗改勾选。清除勾选保留当前行，表头支持半选态，手机复选框点击区域至少 44px。

手机文件行将大小、类型和匹配状态放在文件名下，长文件名最多显示两行；名称、大小、修改时间、类型和匹配状态五种排序仍通过“文件排序”和方向按钮提供。复制、剪切、改名和删除收在“更多”，不能因隐藏桌面列或按钮丢掉功能。

## 弹窗与焦点

`useFocusTrap` 按最上层弹窗处理键盘，首个弹窗打开时锁定背景滚动，最后一个关闭时恢复原来的 `body` overflow。嵌套弹窗关闭不能解锁仍有弹窗的背景。`ActionMenu` 在执行菜单动作前收起菜单并将焦点交回可见触发器，使后续弹窗关闭时能回到“更多操作”等入口，而不是已隐藏的菜单项。

上传弹窗把开始、取消、重试和后续整理操作放在 footer；长文件队列只滚动正文。不同阶段保留原有禁用、取消和预览确认逻辑，不能把关闭弹窗当作取消后台写入。验收需覆盖鼠标与键盘打开菜单后进入弹窗、Escape、关闭后焦点恢复、嵌套弹窗及页面滚动恢复。
