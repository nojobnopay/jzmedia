# 体验审查实施与验收

实施日期：2026-09-27。

## 已完成

- 播放入口使用共用 SVG 图标；手机导航两行、文字不拆分，继续观看与合集创建表单适应窄屏。
- 电影和剧集墙都有添加、扫描、上传入口；扫描明确到视频库并与设置工具共享任务状态。上传前后端校验类型、启用和可写状态；TV 默认文件夹，散文件指定剧与季，登记后补全资料、显示待核对结果，目录整理仍须预览和确认。
- 列表按媒体库、筛选和排序保存已加载页及海报锚点；返回后恢复位置，再刷新内容。全局回到顶部尊重减少动画偏好，避让批量栏，在弹窗及播放器打开时隐藏。
- 剧、季、集详情切库返回目标剧集墙。上下集和所有剧集连播入口统一调用服务端版本/多集区间规则；季页有版本选择和去重集数。
- 电影详情分开编辑、匹配、更新资料；合集操作位于所属合集区域；直链移到版本行；资料文件修复统一选择 NFO、海报或两者。合集推荐及维护默认折叠。
- 概览增加剧集、季、分集与待办，待办入口指向具体视频库。

## 浏览器验收

使用 Linux Chromium、临时数据库和临时媒体文件，未修改真实媒体目录。

- 375、390、768、1440px 检查电影墙、剧集墙、合集创建和概览：页面无非预期横向溢出，导航文字保持一行。
- 电影墙加载 240 部、剧集墙加载 85 部后，浏览器返回和页面返回恢复原卡片。最终刷新逻辑复测：240 部电影和 86 部剧集在 2200px 位置返回，卡片顶边坐标前后一致，后台刷新无错误。
- 从剧、季、集详情切库均回到 `/tv?media=目标库`，内容与顶栏选择一致。
- 手机上传弹窗显示正确类型的视频库，TV 默认文件夹，空闲按 Esc 关闭；回到顶部在减少动画模式下立即到顶并隐藏。
- 真实上传验证成功文件与季号冲突文件的部分失败、电影文件保存、传输取消、资料来源失败提示与离线缓存补全成功。后端临时本地/模拟 SMB 测试覆盖文件夹、散文件、只读、停用、跨库、未知编号、重复文件、并发同名提交及中断清理。
- 临时 H.264/AAC 视频在 390px 视口成功播放（时间持续推进、未暂停），播放器无横向溢出，关闭后移除。
- 版本、多集区间、超过 500 集的分页边界与跨季导航由后端回归覆盖；连续播放从当前播放集继续的逻辑有前端回归。

尚未在 Safari、Windows 字体环境及真实 NAS 网络上传场景实测；相关布局与存储行为分别由 Chromium 和隔离后端测试验证。
