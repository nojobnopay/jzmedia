# 后续开发计划

面向维护者与开发人员。此目录只记录**尚未完成或尚待人工验收**的事；已实现能力以 [用户手册](../user-guide/README.md) 和 [开发者文档](../developer/README.md) 为准。下表是 2026-09-26 根据代码、旧台账和文档整理后的候选顺序，不构成发布日期承诺。

| 状态 | 含义 | 本次结论 |
|---|---|---|
| 待验收 | 已有实现，但依赖真实浏览器/片源场景复核 | 播放器全格式及 NAS 手工验收 |
| 候选开发 | 旧台账指出的未落地能力，尚未确定排期 | 设置未保存提示、健康接口磁盘余量、播放实验、NFS 直读、logo |
| 发布前待决策 | 与公开分发直接相关，维护者需决定 | 许可证及发布渠道/支持边界 |
| 已完成 | 代码已有实现，不列为未来工作 | TVmaze、完整剧集管理、剧集目录整理、倍速与缩略图 |

待办、播放器人工验收清单、判定不做的理由和文档改版验收记录集中在 [待办与验收条件](backlog.md)。旧历史台账（`legacy-backlog.md`）已删除：未完成项并入现表，"不做"理由与历史文档回溯说明见其对应章节。

2026-10-03 新增 [Android TV 客户端计划](android-tv.md)：已确定同仓独立 `android-tv/` 工程、独立构建与发版；已接入原生能力、多设备会话及连接/浏览/观影代码，开发验证进行中；红米真机验收和家庭正式分发尚未完成。

## 维护规则

- 每项新计划描述当前证据、预计变更范围、验收方式和风险，优先级只是建议，不为未确认工作写确定发布日期。
- 开始实施时在对应项注明负责范围和验证结果；完成后更新手册、架构文档及本清单，再从当前待办移到已完成记录。
- 遇到实现与文档不符，先核对代码和测试；不能仅按旧台账把已完成能力重新标为“待实现”。
- 本仓库目前没有 CI、公开 issue 平台或 `LICENSE`；计划中不得假定它们已存在。
