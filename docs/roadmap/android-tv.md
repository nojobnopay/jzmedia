# Android TV 待验收与发布

本页只维护尚未完成的事项与影响交付的限制，不进入公开帮助站。构建、安装见 [README](../../android-tv/README.md)，操作检查见[测试指南](../../android-tv/docs/testing.md)，打包规则见[发布指南](../../android-tv/docs/releasing.md)。核对日期：2026-10-04。

连接、浏览、搜索、播放和独立会话已实现。当前版本以根 [version.properties](../../version.properties) 为准，与 Docker 镜像统一发布；协议仍为 1。此前 `0.5.2` / `versionCode=10` 的 Debug/未签名 Release 构建、JVM/Lint 与 API 28 软件模拟器检查已有记录；这些结果不等于红米真机验收，也不代表统一发行版本已重新验证。

## 影响安装与发布的限制

**部分历史试装包的调试密钥尚未找到，当前包不能直接覆盖这些安装。** 已记录的 `0.5.1` 与 `0.5.2` 使用同一调试签名；更早的统一设计系统试装包和其重建包使用另一签名。升级前需核对具体新旧包的证书，不能仅按版本判断。不应建议用户先卸载来绕过签名问题，因为会丢失本机连接和偏好。找回原密钥后需以更高版本重新交付，并验证覆盖安装保留配置；若最终不能找回，应另行确定迁移方案。

正式 Release 签名及同签名升级尚未验收。正式密钥须保存在仓库外并备份；首次正式发布还须确定最低服务端发行版本。不能假定服务器与所有电视同时升级，也不能用 APK 版本号替代[协议握手](../../android-tv/docs/protocol.md)。

## 尚未完成

### 首台红米电视与最低系统

**当前缺口：** `minSdk=23` 是构建下限，尚无实际型号/API 记录。

**完成条件：** 记录设备和 API，验证安装、电视桌面入口、完整遥控地址输入、令牌与中文搜索，再声明支持范围。

### 家庭遥控观影闭环

**当前缺口：** 代码/JVM/模拟器已有覆盖，实际遥控器、输入法和音频未验收。

**完成条件：** 无鼠标完成连接、选片、字幕/音轨、seek、续播、真正结束后的下一集；退出、Home、待机、断网后无残留声音。

### 真实解码、音频与显示

**当前缺口：** 软件模拟器关闭音频，不能证明硬件能力。

**完成条件：** 逐台记录 MP4/MKV、H.264/HEVC、文本/图片字幕、多音轨、direct/HLS；4K/HDR/Dolby 仅按实测声明，失败可返回/兼容播放。

### 多设备与满额

**当前缺口：** 独立 sid、共享任务和 429 已有自动回归，缺家庭多端实播。

**完成条件：** 两端同片播放，一方跳转/切档/关闭不打断另一方；429 可重试/返回，网页与电视进度可续播。

### 界面补验

**当前缺口：** `0.5.2` 模拟器已检查主要页面；演员页、筛选/选择/全文对话框组合未完成运行复验。

**完成条件：** 补查上述页面在正常/1.3 倍字号下的布局和返回焦点；真机核对远距离阅读。

### 正式签名与升级

**当前缺口：** 正式密钥、Release 签名和覆盖安装未验收。

**完成条件：** 按发布指南生成签名包，校验签名/哈希，同签名升级保留配置，并记录协议/服务端/设备兼容范围。

### 验收记录要求

每项验收记录 APK/服务端版本、设备/API、操作、结果与证据。模拟 API、真实后端合成媒体、软件模拟器、物理电视分开记录，不为验证操作真实媒体的扫描、整理或删除。长期跨端布局证据见[设计验收清单](../../design/acceptance/2026-10-03.json)；旧版本测试计数和修复过程保留在 Git 历史，不再逐轮追加。
