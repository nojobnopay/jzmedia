# Android TV 状态与发布

本页维护当前验收状态与影响交付的限制，不进入公开帮助站。构建、安装见 [README](../../android-tv/README.md)，操作检查见[测试指南](../../android-tv/docs/testing.md)，打包规则见[发布指南](../../android-tv/docs/releasing.md)。核对日期：2026-10-07。

连接、浏览、搜索、播放和独立会话已实现。当前版本以根 [version.properties](../../version.properties) 为准，与 Docker 镜像统一发布；协议仍为 1。

## 真机验证已通过

2026-10-07，用户确认电视真机验证 OK，客户端真机验收状态更新为已通过。依据是用户实际使用反馈；网页隔离截图与自动检查仍按各自来源记录。

设备型号、Android/API、实际安装的 APK/服务端版本及逐项片源记录待补充。`minSdk=23` 仍是构建下限；其他设备和 4K/HDR/Dolby 等格式的支持范围按实测记录声明。多设备独立播放、429 满额恢复、换 IP 重新发现及大字号等专项需要具体结果时，沿用[测试清单](../../android-tv/docs/testing.md#真机检查清单)记录。

## 影响安装与发布的限制

**部分历史试装包的调试密钥尚未找到，当前包不能直接覆盖这些安装。** 已记录的 `0.5.1` 与 `0.5.2` 使用同一调试签名；更早的统一设计系统试装包和其重建包使用另一签名。升级前需核对具体新旧包的证书，不能仅按版本判断。不应建议用户先卸载来绕过签名问题，因为会丢失本机连接和偏好。找回原密钥后需以更高版本重新交付，并验证覆盖安装保留配置；若最终不能找回，应另行确定迁移方案。

正式 Release 签名及同签名升级尚未验收。正式密钥须保存在仓库外并备份；首次正式发布还须确定最低服务端发行版本。不能假定服务器与所有电视同时升级，也不能用 APK 版本号替代[协议握手](../../android-tv/docs/protocol.md)。

## 验收记录要求

每项验收记录 APK/服务端版本、设备/API、操作、结果与证据。模拟 API、真实后端合成媒体、软件模拟器、物理电视分开记录，不为验证操作真实媒体的扫描、整理或删除。长期跨端布局证据见[设计验收清单](../../design/acceptance/2026-10-03.json)；旧版本测试计数和修复过程保留在 Git 历史，不再逐轮追加。
