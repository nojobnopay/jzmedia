# Android TV 客户端

核对日期：2026-10-03。状态：工程、服务端原生能力、多设备会话及连接/浏览/观影代码已接入；构建、回归与关键电视模拟器联调已通过，可交付开发试装包。红米真机技术验收与家庭正式分发均未完成。本页为仓库内开发计划，不进入公开帮助站或搜索索引。

## 已确定的方向

在同一 Git 仓库新增 `android-tv/` 独立 Android 工程，采用 Kotlin、Compose for TV，播放使用 Media3/ExoPlayer。电视安装 APK，通过 HTTP API 连接家中的 jzmedia 服务；后端继续负责资料、存储访问和必要的转码。

APK 独立构建与发版，使用 `android-tv-vX.Y.Z` 标签，不跟随服务器版本号。客户端与后端联动工作统一跟踪，发布时分别记录版本兼容范围及验收结果；不能假定家中各设备同时升级。当前仓库没有 CI 或公开 issue 平台，不把它们作为实施前提。

首版覆盖观影：继续观看、最近加入、媒体库切换、电影与电视剧及合集浏览、搜索与筛选排序、电影版本和季集选择、花絮、暂停与快进快退、倍速、画质、音轨、字幕大小与延迟、断点续播和下一集。扫描、整理、匹配、上传与文件管理继续在网页端操作。

默认只支持家庭局域网，全家共享现有观看进度，同片同时观看以最后保存为准。首版不增加成员账户、投屏、语音助手或应用商店发布，不依赖 Google Play 服务。

## 当前实现与待核实事项

- 现有后端已有列表、详情、搜索、版本、进度和下一集接口，以及 `direct/remux/audio_transcode/video_transcode` 四档播放决策，可复用业务数据。
- 已增加 `android_tv` 客户端和原生容器/HLS/音轨/HDR/字幕能力，贯穿版本推荐、播放决策、会话和预缓存；旧网页默认行为保持。APK 结合 Media3 解码器及片源的规格检测能力，握手协议为 1。详见 [客户端协议](../../android-tv/docs/protocol.md)。
- 多设备会话隔离已实现：每次播放独立 sid，相同产物原子共享底层任务，预缓存也持有独立引用；最后持有者退出才终止 FFmpeg。不同产物以完整哈希目录隔离，名额覆盖进程生命周期，满额 429，清理跳过活动任务。已有并发、回收与真实合成片回归。
- 观影代码已区分 HLS 的 `media_start` 与 `initial_time`；WebVTT 按源时间显示，ASS/SSA 使用兼容文本，图片字幕服务端烧录。合成片直连、HLS 续播、字幕、真实结束后下一集及 Home 清理已有模拟器证据；实际 FastAPI 的动态 HLS 从头起播和同 sid 音轨切换也已联调，红米真机仍待检查。
- `0.4.0-dev` 体验改进覆盖暂停意图保留、短片完成判定、同次连播偏好、紧凑详情首屏与默认播放焦点、按行加载的季海报/选集和固定选集说明、独立首页重试、翻页/失效条目焦点恢复，以及本机搜索历史/最近演员。服务器和网页同步完成规则，无迁移或重扫；收藏/想看保留为后续能力。验收细节以 Android 工程说明的本版记录为准。
- `0.5.0-dev` 主导航将搜索放至最左，频道及工具均使用文字与线性图标；当前频道标记独立于遥控器焦点，详情保留来源频道，媒体库长名称保持单行。与 Web 导航共用图标路径和状态语义，沿用现有协议；具体构建、模拟器及真机边界见 Android 工程说明。
- 家中电视均为红米安卓电视，但型号与 Android 版本暂不清楚。暂以 Android 6.0/API 23 为最低基线，须由真机核实；这不是所有红米电视均兼容的承诺。

首台红米电视未完成安装和基础交互验证前，不把最低系统版本及设备播放能力视为定案。早期 M0 的构建结果不能替代当前观影代码验收；本轮构建、单元测试和模拟器证据记录在 [工程说明](../../android-tv/README.md)，真机结果再更新本页。API 28 电视模拟器用于开发验证，不计入 M1 的家庭红米电视验收，也不据此完成 M3。

遥控器交互统一为：方向键移动焦点；播放控件隐藏时左右进入快进预览、上下唤出控件；确定键激活选项或暂停/继续，并确认快进位置；返回依次关闭菜单或取消预览、隐藏控件、退出播放、返回上页，最终可退出应用。音量沿用系统控制。

验收至少覆盖：

- 全程无鼠标完成连接、中文搜索、媒体库切换、选片选集、音轨字幕切换、跳转和退出；详情返回恢复海报焦点与滚动位置。
- MP4/MKV、H.264/HEVC、多音轨、文本和图片字幕，以及原文件与 HLS 转码路径；4K/HDR 按每台电视实测能力记录。
- 正常结束后连播，不能将接近片尾的进度上报误当播放结束；退出、Home、待机和网络失败后无残留声音。
- 两台设备播放同片，一方跳转、切档或关闭不打断另一方；转码资源不足可理解、可返回；旧网页播放回归通过。
- 令牌启用/未启用、服务器不可达、媒体离线、播放失败均有可聚焦的提示与返回/重试入口，不无限加载。

主要风险是未知电视的解码与 HDR 能力、服务端并发转码资源，以及旧客户端升级兼容。构建、模拟 API 与模拟器结果分别记录，不作为真实电视播放效果的证据。
