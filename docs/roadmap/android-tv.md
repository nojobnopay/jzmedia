# Android TV 待验收与分发

核对日期：2026-10-03。当前 APK 为 `0.5.0-dev`、`versionCode=8`、协议 1。工程、连接/浏览/搜索/播放和独立会话已实现；本页只跟踪剩余验收和发布事项，不进入公开帮助站。

当前功能、构建与安装见[工程说明](../../android-tv/README.md)，接口见[客户端协议](../../android-tv/docs/protocol.md)。[历史验证记录](../../android-tv/docs/validation-history.md)和[设计系统验收](../../design/acceptance/2026-10-03.json)包含构建、合成媒体与 API 28 软件模拟器证据，不能作为红米真机验收。

## 尚未完成

| 事项 | 当前证据与缺口 | 完成条件 |
|---|---|---|
| 首台红米电视与最低系统验证 | `app/build.gradle.kts` 设置 minSdk 23；尚无实际型号、Android/API 与设备能力记录 | 记录型号/API，验证安装、电视桌面入口、完整遥控地址输入、令牌验证和中文搜索；再确认支持范围 |
| 家庭遥控观影闭环 | 浏览、选季选集、焦点恢复、播放和连播已有代码/JVM/模拟器验证；实际遥控器、输入法与听感未验收 | 全程无鼠标完成连接、选片、字幕/音轨、seek、续播、真正结束后的下一集及退出；Home、待机、断网后无残留声音 |
| 真实解码、音频与显示 | `NativeCapabilities.kt` 检测原生容器、解码器和 HDR；软件模拟器关闭音频，不能证明实际硬件表现 | 逐台记录 MP4/MKV、H.264/HEVC、文本/图片字幕、多音轨、direct/HLS 的结果；4K/HDR/Dolby 仅按实测声明，失败能返回或兼容播放 |
| 多设备与资源满额实测 | `tests/test_stream_multiclient.py` 已覆盖独立 sid、共享 FFmpeg、最后引用退出及满额；尚无家庭多台设备实播证据 | 两端同片并发，一方跳转/切档/关闭不打断另一方；429 可理解且能重试/返回，网页与电视进度可相互续播 |
| 正式签名和家庭分发 | Gradle Release 仍无签名配置；同签名 Debug 覆盖升级已有证据，正式密钥与覆盖升级未验收 | 仓库外保管并备份正式密钥；同签名正式版升级保留配置；记录 APK 校验值/签名、服务器与协议兼容范围、支持设备和限制 |
| 电视收藏/想看是否立项 | 当前仅有本机搜索历史、最近演员和共享观看进度，电视没有收藏/想看入口 | 维护者确认是否开发及数据归属后再列实施方案，当前不承诺排期 |

首次正式发布时确定最低服务端发行版本，不能以界面版本号代替 `client-info/client-check` 握手。APK 独立构建和发布，标签使用 `android-tv-vX.Y.Z`；服务器与各台电视不假定同步升级。

验收只使用有权测试的片源，不为测试执行真实媒体扫描、整理或删除。每项记录 APK/服务器版本、设备/API、操作、通过/失败和复现证据；模拟 API、真实后端与合成媒体、模拟器和物理电视分别记录。
