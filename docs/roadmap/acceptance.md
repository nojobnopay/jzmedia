# 播放器人工验收清单

[开发计划](README.md)

此清单用于补齐自动化无法覆盖的真实浏览器/硬件/片源检查，**尚未整体验收完成**。执行前使用有权测试的片源，不对真实媒体库做目录整理；记录浏览器版本、操作系统、片源编码、部署方式和后端转码检测结果。

| 场景 | 操作与预期 |
|---|---|
| 原文件直发 | 打开普通 H.264/AAC MP4；可播放、音画同步、暂停与关闭后无残余声音 |
| remux 与音频转码 | 打开受测 MKV、非安全音频轨；播放信息显示与决策一致，切音轨可听见对应语言 |
| 视频转码与硬件回退 | 选择超出客户端能力的片源；起播有等待反馈，硬件失败后软件重试且无僵尸进程 |
| HDR/DV | 分别检查兼容基底与无基底片源；颜色、错误原因与外部直链提示合理 |
| 字幕 | 测内嵌/外挂 VTT、ASS、PGS 和需烧录轨；暂停、seek、换档、全屏后仍对齐；缺字体时有可用降级 |
| 本地临时字幕 | 加载 SRT/VTT/ASS，seek 和切画质后仍存在，关闭播放器后消失 |
| 续播、seek 与缓存 | 有断点时查看继续/从头开始；跨缓冲区跳转、预缓存成品续播与字幕时间轴正确 |
| 倍速与音调 | 六档逐一切换，切画质/下一集后恢复速度；录音语音音调没有明显异常 |
| 预览图 | 未生成时仅时间，生成中部分节点有图，结束/取消/续做后时间与采样节点对应；源文件变化后失效 |
| 窗口/全屏/手机 | 鼠标和键盘能进入设置，自动隐藏符合预期；320px/390px 下控件不重叠，长错误可见重试 |
| 关闭与异常网络 | 起播或跳转进行中关闭播放器，后台会话及时回收；恢复页面后无残留音频或迟到 video 挂载 |

在每行记录“通过/失败/未测”与复现数据后再称完成。现有自动化可辅助但不替代 NAS、Safari 和真实 ASS/PGS 片源验收。开发过程禁止用测试脚本对真实媒体库执行整理或删除。
