# jzmedia

把本地硬盘或 NAS 中的电影、剧集整理成可搜索、可播放的私人影视库。

jzmedia 提供海报墙、自动匹配元数据、多版本管理、目录整理和浏览器播放。支持本地目录、SMB 直读及 NFS 挂载；可以导入现有 NFO，也可以把元数据和图片写回媒体目录，供其他媒体软件使用。

## 主要功能

- **电影与剧集**：海报墙、搜索筛选、详情、演员作品、观看记录；剧集提供剧、季、集页面及连播。
- **入库与匹配**：扫描、待确认清单、手动绑定、NFO 离线导入、TMDB 和可选外部元数据来源。
- **文件管理**：电影多版本、合集、上传、文件浏览、归档预览与执行、剧集整理审计及撤销。
- **播放**：按浏览器能力选择直发或转码，支持硬件转码、多音轨、字幕、续播、六档倍速、进度缩略图及预缓存。

## Docker 快速启动

先取得项目源码，并在项目根目录执行；没有公开仓库地址或预构建镜像的假定。

```bash
cp .env.example .env
mkdir -p media data
# 编辑 .env：设置媒体/数据目录，以及有目录权限的 UID、GID。
docker compose -f docker-compose.yml up --build -d
```

打开 `http://localhost:8080`。到「设置 → 媒体库」添加电影或剧集视频库，检查连接后扫描。完整的路径、权限和首次使用步骤见 [部署教程](docs/getting-started/deployment.md)。已有 `.env` 时请保留它，不要重复覆盖。

显式指定 `-f docker-compose.yml`，避免自动载入用于本机热重载的 `docker-compose.override.yml`。

## 使用边界与项目状态

应用以家庭或受信任网络中的单实例部署为目标。可选令牌保护 API 写操作，读取与媒体直链仍开放；它不是多用户登录或完整访问权限系统。媒体内容由使用者自行提供。

技术栈为 FastAPI、SQLite、Vue 3、Vite 和 FFmpeg；服务必须以单个应用 worker 运行。[参与开发](docs/developer/development.md)。
